# 无限降雪特效 + 吹雪特效 Ver.1.1

製作：そぼろ

这是让雪降下、以及进行其他粒子表现的特效。

与以往的东西不同，无论离设置场所多远，显示都不会中断。
实际上，显示区域会跟随相机移动。

通过附带的控制器，可以更改粒子数、范围、速度、倾斜、粒子尺寸、噪波、旋转速度等。

WorldSnow 是不带模糊（blur）的，WorldBlizzard 是带模糊的粒子特效。请按用途分别使用。

WorldBlizzard 为了降低负载，不支持通过控制器切换纹理。

## 使用方法

* 在 MMD 中读取 WorldSnow.x
* 将描画顺序设定为最后
* 读取 WorldParticleController.pmd
* 将 WorldSnow.x 挂到控制器的骨骼上
* 读取示例动作（サンプルモーション）
* 调整参数

## 操作方法

* Si：粒子尺寸
* Tr：粒子透明度
* Y：显示下限
  低于特效用附件 Y 位置的粒子会消失。
* Rx、Ry、Rz：落下方向
  通过附件的旋转，可以指定粒子流动的方向。
  挂到控制器的骨骼上会更容易操作。
