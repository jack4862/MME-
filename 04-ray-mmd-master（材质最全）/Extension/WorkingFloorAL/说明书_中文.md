# WorkingFloorAL.fx ver0.0.7

## 用途

这是把 WorkingFloor2、WorkingFloorX 对应到 AutoLuminous（そぼろ氏 作）的镜像描画效果。

如果不使用 AutoLuminous，本效果只会增加无谓的处理，因此照以往那样直接使用 WorkingFloor2、WorkingFloorX 会更好。

## 运行环境

只要 AutoLuminous 能正常运行的环境应该就没问题。

※本 FX 文件若不是 MMEver0.33 以上则无法正确运行。

## 基本使用方法（以 AutoLuminous 对应模型、AutoLuminous 本体均已设置完毕为前提说明）

1. 把 WorkingFloorAL.fx 开头的参数设置为与 AutoLuminous.fx 相同的设置。
2. 把 WorkingFloorAL.x 载入 MMD。
3. 描画顺序推荐为：背景舞台 → AutoLuminous.x → WorkingFloorAL.x → 其他对象。
   若 WorkingFloorAL.x 排在 AutoLuminous.x 之前，发光部分会描画出晚一帧的内容。
4. 在「MMEffect」→「效果分配」的 AL_EmitterRT 标签页中选择 WorkingFloorAL.x，并应用 AL_WorkingFloor.fx。
   这样只要有 AutoLuminous 对应模型，镜面描画的对象也会自动发光。
   另外，若把 AL_WorkingFloor.fx 复制到 AutoLuminous 的文件夹中，并在 AutoLuminous.fx 的 AL_EmitterRT 定义的选择器指定处追加

   ```
   "WorkingFloorAL.x = AL_WorkingFloor.fx;"
   ```

   则此步骤会在载入 AutoLuminous.x 时自动完成。
5. 在 MMD 的附件参数中进行以下修改并注册关键帧。
   - Tr：镜面的反射率
   - 影：相对于反射率的发光强度会变化。当 Tr 较小时若觉得发光偏弱，请将其设为 ON。
   - 其他参数用来设定镜面的描画范围。
     关闭效果时，WorkingFloorAL.x 的白色板多边形内部即为描画范围。
6. WorkingFloorAL.fx 默认设定为对所有对象进行镜像描画。
   对于不想镜像化的模型、已设置效果而不应描画的对象等，请在「MMEffect」→「效果分配」的 WorkingFloorRT、WF_EmitterRT 标签页中选择隐藏。
   或者在 WorkingFloorAL.fx 内的 WorkingFloorRT、WF_EmitterRT 定义的规定位置编辑对象选择。

## 关于 MikuMikuMoving

本效果也支持 MikuMikuMoving。

请把 WorkingFloorAL.fx 与 WorkingFloorAL.x 两者都载入 MikuMikuMoving 使用。

离屏设置针对 WorkingFloorAL.x 进行。

在 MMM 中，镜面描画的反射率用 WorkingFloorAL.fx 的 α 值调节，发光的镜面反射用 WorkingFloorAL.x 的 α 值调节。

※在 MMM 中似乎无论采用怎样的描画顺序，发光部分都会延迟一帧描画。

## ObjectLuminous 方式的发光方法

使用 Option\OL_Selector 文件夹中的选择器效果，可以让所指定模型·材质的镜像发光。

1. 在 AL_EmitterRT 标签页中，对想要发光的模型·材质应用 OL_Select.fx。对象自身会发光。
2. 在 WF_EmitterRT 标签页中，对相同的模型·材质应用 OL_MirrorSelect.fx。对象的镜像会发光。
3. 发光强度、发光颜色请分别用各选择器开头的参数调整。
4. 若想对多个模型·材质以不同参数应用，请把选择器文件以别的名称复制后再做同样设置。

## 关于遮罩功能

AutoLuminous 的对象发光遮罩功能，在镜像描画中也可以进行。

1. 请进行 AutoLuminous 的遮罩功能设置（处于 MME 标签页中已追加 AL_MaskRT 的状态）。
2. 在 WorkingFloorAL.fx 的开头参数中把遮罩功能设为 ON。MME 标签页中会追加 WF_MaskRT。
3. 在 WF_MaskRT 标签页中选择想要遮罩的对象，应用 Option\AL_Mask 文件夹中的 WF_BlackMask.fx。
4. 在 AL_MaskRT 标签页中选择 WorkingFloorAL.x，应用 AL_WorkingFloorMask.fx。
   这样镜面描画的对象其发光也会被遮罩。
   另外，若把 AL_WorkingFloorMask.fx 复制到 AutoLuminous 的文件夹中，并在 AutoLuminous.fx 的 AL_MaskRT 定义的规定位置追加

   ```
   "WorkingFloorAL.x = AL_WorkingFloorMask.fx;"
   ```

   则此步骤会在载入 AutoLuminous.x 时自动完成。

## 纹理发光

与 AutoLuminous 的 AL_Texture.fx 效果同等的处理，在镜像描画中也可以进行。

在 WF_EmitterRT 标签页中，对想要纹理发光的材质应用 Option 文件夹中的 WF_TextureEmit.fx。

## 关于 X 阴影描画

可以进行与 WorkingFloorX 同等的 X 阴影描画。默认状态下是隐藏的。

想要显示时，请在 WorkingFloorAL.fx 的开头参数中把 X 阴影描画设为 ON。

X 影会描画在 WorkingFloorAL.x 的高度（附件参数 Y 的高度）上。不会与镜面的倾斜联动。

## 其他

把 WorkingFloorAL.x 替换成其他形状的模型，即可制作任意形状的镜面（仅限平面）。

默认请以 XZ 平面（Y=0）制作。

本效果通过用 MMD 的附件参数改变位置和倾斜，不仅可作地面，还能成为可对任意平面做镜像的镜面效果。

若要直接组入附件中，则需要修改各效果文件的参数。

本效果不仅对发光，对镜像的对象描画也支持 AutoLuminous 的 HDR 渲染。

在 MMD 标准描画的加法合成中，超过 1 的颜色会作为高照度信息（包含镜像描画在内）传递给 AutoLuminous，成为发光对象。

不过，由其他效果进行的加法不会反映到镜像上，因此不在对象之列。

## 注意事项

请注意，如果载入多个 WorkingFloorAL.x，将无法正常运行。

在部分显卡上，模型的镜像可能无法正常描画（模型变成黑色或白色）。
此时请修改 WorkingFloorAL.fx 的开头参数 FLG_EXCEPTION 后使用。

## 关于 TrueCameraLX 的支持

本效果在 TrueCameraLX（そぼろ氏 作）下，勉强也能对应镜像的模糊与景深。

1. 描画顺序推荐为：背景舞台 → TrueCameraLX.x → WorkingFloorAL.x → 其他对象。
   若 WorkingFloorAL.x 排在 TrueCameraLX.x 之前，发光部分会描画出晚一帧的内容。
2. 在 WorkingFloorAL.fx 的开头参数中把 TrueCameraLX 使用设为 ON。MME 标签页中会追加 WF_DVMapDraw。
3. 在 DVMapDraw 标签页中选择 WorkingFloorAL.x，应用 TCLX_WorkingFloor.fx。
   这样镜面描画的对象也会被加上模糊和景深。

※实际上，镜面的模糊&景深能够正常描画仅限于镜面为完全反射（Tr=1）时（因为施加效果所需的深度与速度信息，在半透明时只能把镜像或地面其中一方的信息传给 TrueCameraLX）。

在半透明描画时，若地面的模糊&景深变得不自然，或许在 WF_DVMapDraw 标签页中把背景模型隐藏掉会更好。
