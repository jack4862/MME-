# ikSoftfocus（使画面模糊的效果）

## ■ 使用方法

　将 ikSoftfocus.x 或 ikEdgeBlur.x 拖入 MMD。

　ikSoftfocus.x 是 使整个画面模糊 + 使明亮部分模糊 + 使边缘模糊。
　ikEdgeBlur.x 是 仅使边缘模糊。

### 调整方法

　通过 Accessory 改变设定。
　　Si：模糊的强度。0.0～10.0
　　Tr：调整整个效果的施加程度。0.0～1.0

　　X,Y,Z：调整模糊的颜色。-1.0～1.0
　　Rx,Ry,Rz：边缘模糊的颜色。-1.0～1.0

　修改 .fx 文件内部。
　ikEdgeBlur.fx 是将 ikSoftfocus.fx 中仅使边缘模糊的处理设为有效的版本。
