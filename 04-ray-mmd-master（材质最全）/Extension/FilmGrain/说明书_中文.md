# FilmGrain

###### [English](https://github.com/MikuMikuShaders/FilmGrain/blob/master/README.md) 　 [中文文档](https://github.com/MikuMikuShaders/FilmGrain/blob/master/README_chs.md)

## 用途

FilmGrain 是一个为了 MikuMikuDance 编写的图像效果，该方法主要使用 3D 的噪音纹理去快速创造电影噪点，并且同时可以用于解决[色带](https://en.wikipedia.org/wiki/Colour_banding)问题。这是一个非常快速的手法去生成电影噪点、暗角、黑边、色彩分离等等，来帮助产生更加真实的同时也很不错的电影效果。

[![link text](./Screenshots/preview.png)](https://raw.githubusercontent.com/MikuMikuShaders/FilmGrain/master/Screenshots/preview.png)

## 需求

* MikuMikuDance (Only tested on 926 version x64)
* MikuMikuEffect (Only tested on 037 version x64)
* Direct3D 9 With Shader Model 3.0 (ps_3_0)

## 快速开始

* 从 Github 的页面下载压缩包文件，并且解压该文件
* 放置该目录中的 `FilmGrain.x` 到 MMD 的窗口
* 放置该目录中的 `FilmGrainController.pmx` 到 MMD 的窗口
* 拖拽表情栏中的 `FilmGrain` 到 0.3

## 参数设置

* `FilmGrain` — 控制在屏幕中产生噪点的强度。
* `FilmLineX` — 控制在屏幕的 X 轴方向添加扫描线的数量
* `FilmLineFadeX` — 控制 X 轴方向扫描线的透明度
* `FilmLineY` — 控制在屏幕的 Y 轴方向添加扫描线的数量
* `FilmLineFadeY` — 控制 Y 轴方向扫描线的透明度
* `FilmBordersX` — 在屏幕的上下添加黑色边框
* `FilmBordersY` — 在屏幕的左右添加黑色边框
* `Vignette` — 在屏幕的角落添加影晕
* `Dispersion` — 控制在屏幕上产生色彩分离的力度
* `DispersionRadius` — 控制在屏幕中心不产生色彩分离的半径
* `FilmLoop` — 对整个屏幕平铺
* `FilmLoopX` — 对屏幕的 X 轴方向平铺
* `FilmLoopY` — 对屏幕的 X 轴方向平铺

# FilmGrain

###### [English](https://github.com/MikuMikuShaders/FilmGrain/blob/master/README.md) 　 [中文文档](https://github.com/MikuMikuShaders/FilmGrain/blob/master/README_chs.md)

## 用途

FilmGrain 是为 MikuMikuDance 制作的图像效果，其方法是使用 3D 噪波纹理（3D noise texture）来生成胶片颗粒，并且能够解决[色带（color banding）](https://en.wikipedia.org/wiki/Colour_banding)问题。这也是一种非常快速的实现胶片颗粒、暗角、黑边、色差（chromatic aberration）等效果的技术，它有助于增添更多真实感，同时也能产生更好的效果。

[![link text](./Screenshots/preview.png)](https://raw.githubusercontent.com/MikuMikuShaders/FilmGrain/master/Screenshots/preview.png)

## 需求

* MikuMikuDance（仅在 926 版 x64 上测试过）
* MikuMikuEffect（仅在 037 版 x64 上测试过）
* Direct3D 9 且支持 Shader Model 3.0（ps_3_0）

## 快速开始

* 从 github 页面下载 zip 压缩包。
* 解压该压缩包。
* 把 `FilmGrain.x` 拖入 MMD 窗口。
* 把 `FilmGrainController.pmx` 拖入 MMD 窗口。
* 把 `FilmGrain` 拖到 0.3。

## 效果参数

* `FilmGrain` — 控制在画面上添加噪波的强度。
* `FilmLineX` — 在整个屏幕的 X 轴方向添加扫描线。
* `FilmLineFadeX` — 控制扫描线与整个屏幕纹理混合时的透明度。
* `FilmLineY` — 在整个屏幕的 Y 轴方向添加扫描线。
* `FilmLineFadeY` — 控制扫描线与整个屏幕纹理混合时的透明度。
* `FilmBordersX` — 在屏幕 X 轴方向周围添加黑色边框。
* `FilmBordersY` — 在屏幕 Y 轴方向周围添加黑色边框。
* `Vignette` — 在屏幕四角添加黑色边框（暗角）。
* `Dispersion` — 控制模拟屏幕上色彩偏移的偏移量。
* `DispersionRadius` — 控制在屏幕中心不产生该效果的半径。
* `FilmLoop` — 控制平铺整个屏幕纹理的循环次数。
* `FilmLoopX` — 控制在整个屏幕 X 轴方向平铺纹理的循环次数。
* `FilmLoopY` — 控制在整个屏幕 Y 轴方向平铺纹理的循环次数。
