# ikRaindrops2

## 概要

本文档说明 MikuMikuEffect 用效果「ikRaindrops2」的使用方法。

ikRaindrops2 是用于表现附着在窗户上的雨滴的效果。

与简易版相比表现力有所提升，但取而代之也有一些劣化的部分（后述）。

## 使用方法

请在 MMD 的附件中添加 "ikRaindrops2.x"。

请把附件放置在想要附着雨滴的窗户附近。

勾选附件的「影」，附着雨滴的范围就会作为蓝色半透明面板被可视化显示。
（打开/关闭附件的「影」会重置雨的状态。）

可以用附件的 Tr 控制雨量。
0 为无雨，1 为 100%。不过即使设为 0，雨滴也不会立即消失。

由于这是透明效果，并且会渲染环境贴图，因此根据附件的显示顺序，外观可能会变得不正常。
- 把不需要映照到水滴上的模型从 MME 的 RefractRT 标签页中排除，有时可以让外观变好。
- 把 ikRaindrops.x 从相性不好的效果中排除，有时可以改善外观。

## 可在效果文件内设置的项目

**ParticleSize**

水滴的大小。即使改动附件的 Si，雨滴的大小也不会改变。

**LifetimeMin**

水滴落下之前的最短时间（秒）

**LifetimeFluctuation**

水滴落下之前的浮动幅度（秒）

雨滴会在出现后 LifetimeMin ～ LifetimeMin + LifetimeFluctuation 之间落下。

**DropSpeedRate**

水滴的落下速度

**NumRaindropInTextureW / NumRaindropInTextureH**

贴图上有多少个雨滴图案？这是给想自己改动雨滴图案的人准备的。

**STOP_IN_EDITMODE**

是否在编辑模式中停止下雨。

**RESET_AT_START**

是否在播放 0 帧时清除雨。

**BUFFER_SIZE**

工作用贴图的大小。把它调大到 2048 或 4096 等，有时可以改善水滴的外观。相应地会消耗显卡内存。

（介绍视频中设置为 2048。）

## 相较于简易版改善的点。限制。

- [简易版] 雨重叠时外观会变得不自然。
  → [通常版] 高度变得可以重叠了。但不支持因表面张力或重力而产生的水滴变形。

- [简易版] 通常雨滴重叠时会融合，但彼此之间不会相互干涉。
  → [通常版] 当雨滴位于自己下方时，会像被牵引着一样落下。
  有时看起来像重叠却被忽略。也有外观上并未重叠却受到影响的情况。

- [简易版] 雨滴流过的痕迹呈直线状。
  → [通常版] 改为蜿蜒行进。由于雨滴是以点而非线来描画的，因此若让其高速落下，有时会看起来呈虚线状。

- [简易版/通常版] 只能表现从窗玻璃内侧向外看的情况。

- [通常版] 由于把简易版的雨滴粒子先描画到工作用贴图上，因此每一粒的分辨率下降了。

## 关于雨滴贴图的注意

以黑白表现水滴的高度。黑＝无水。白＝有水。
