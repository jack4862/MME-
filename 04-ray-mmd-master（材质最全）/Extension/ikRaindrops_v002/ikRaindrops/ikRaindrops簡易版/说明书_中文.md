# ikRaindrops

## 概要

本文档说明 MikuMikuEffect 用效果「ikRaindrops」的使用方法。

ikRaindrops 是用于表现附着在窗户上的雨滴的效果。

由于是简易版，到处都有不自然的部分（后述）。

## 使用方法

请在 MMD 的附件中添加 "ikRaindrops.x"。

请把附件放置在想要附着雨滴的窗户附近。

勾选附件的「影」，附着雨滴的范围就会作为蓝色半透明面板被可视化显示。
（打开/关闭附件的「影」会重置雨的状态。）

可以用附件的 Tr 控制雨量。
0 为无雨，1 为 100%。不过即使设为 0，雨滴也不会立即消失。

由于这是透明效果，并且会渲染环境贴图，因此根据附件的显示顺序，外观可能会变得不正常。
- 把不需要映照到水滴上的模型从 MME 的 RefractRT 标签页中排除，有时可以让外观变好。
- 把 ikRaindrops.x 从相性不好的效果中排除，有时可以改善外观。

## 可在效果文件内设置的项目

**ParticleSize**

水滴的大小。即使改动附件的 Si，雨滴的大小也不会改变。

**LifetimeMin**

水滴落下之前的最短时间（秒）

**LifetimeFluctuation**

水滴落下之前的浮动幅度（秒）

雨滴会在出现后 LifetimeMin ～ LifetimeMin + LifetimeFluctuation 之间落下。

**DropSpeedRate**

水滴的落下速度

**NumRaindropInTextureW / NumRaindropInTextureH**

贴图上有多少个雨滴图案？这是给想自己改动雨滴图案的人准备的。

**STOP_IN_EDITMODE**

是否在编辑模式中停止下雨。

**RESET_AT_START**

是否在播放 0 帧时清除雨。

## 限制

- 雨重叠时外观会变得不自然。
- 通常雨滴重叠时会融合，但彼此之间不会相互干涉。
- 雨滴流过的痕迹呈直线状。
- 只能表现从窗玻璃内侧向外看的情况。

## 关于雨滴贴图的注意

法线贴图的 alpha 通道是遮罩。
