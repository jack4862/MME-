# LocalShadow.fx ver0.0.3

## 用途

这是局部进行独自设置的自阴影（self shadow）描画的阴影生成效果。

它可以把落在模型脸上的阴影与通常的光照方向错开，以更好看的方式投下阴影，也就是用效果来制作所谓「假影（嘘影）」一类的效果。

※当然，对于模型一侧已做了假影设置（设置为不落自阴影）的模型，本效果无效。

作为应用，也可以用其覆盖整个模型，制作任意的空间固定贴图（map），从而进行无闪烁的阴影生成。

## 运行环境

必须使用支持 SM3.0 的显卡。

已在 MMEv0.37、MMEv0.37x64、MMMv125a、MMM64v125a 上确认可运行。在旧版本上可能无法运行。

## 使用方法［MME 的情况］

1. 根据需要修改 LocalShadow_Header.fxh 的开头参数。
2. 把 LocalShadow.pmx 载入 MMD。刚载入后会显示控制用模型。
3. 把 LocalShadow.pmx 的描画顺序排在进行阴影生成的目标模型之前。
4. 把 LocalShadow.pmx 的中心骨骼，外部父级注册到目标模型进行阴影生成的位置的骨骼（通常是头部骨骼）上。
5. 从「MMEffect」→「效果分配」的「LSMapRT 标签页」中选择目标模型，应用 LocalShadow_ShadowMap.fxsub。
6. 从「MMEffect」→「效果分配」的 Main 标签页中把要描画的目标模型展开子集（subset），
   选择要生成阴影的材质（通常是脸部的材质），然后应用 full_LocalShadow.fx。
7. 用 LocalShadow.pmx 的骨骼·表情栏（表情滑块）的各项可以进行以下控制。控制用模型会随之变形，
   请据此找感觉进行调节。

   ［骨骼］
   - センター（中心）：调整进行阴影生成的位置的中心。旋转骨骼即可调整光照方向（红色箭头为光照方向）。

   ［表情栏］
   - 目（眼）：范围缩小、范围扩大 → 调整阴影贴图范围，「田」字形边框内部即为生成阴影贴图的范围。
     最好把范围缩小到刚好覆盖要生成阴影的范围，以提高贴图的分辨率。
     X 范围扩大、Y 范围扩大 → 分别调整阴影贴图范围的 XY，在制作局部空间固定贴图时很方便。
     距离近、距离远 → 调整生成阴影贴图的深度范围，黄球为 Near 的位置，绿球为 Far 的位置。
   - ﾘｯﾌﾟ（唇）：Lt陰影連動 → 调大后，模型阴影的施加方式会受标准光照方向的影响。
     Lt遮影連動 → 调大后，模型遮蔽影的施加方式会受标准光照方向的影响。
     Lt影濃調整 → 调大后，模型的遮蔽影浓度会随标准光照方向变化。在逆光时想消除阴影等情况下使用。
     ※把 Lt陰影連動、Lt遮影連動、Lt影濃調整 调节得当，就能在保留好看观感的同时，也联动于照明操作。
   - まゆ（眉）：影ぼかし → 调整软阴影（soft shadow）的模糊程度
     影薄く、影濃く → 调整阴影的浓度。
   - その他（其他）：透明 → 所有设置完成后，在此把控制用模型设为不显示后再使用。

8. 若要应用到多个模型，请对每个模型分别执行上述 (2)～(7) 步骤。请注意描画顺序弄错，以及
   特别是离屏 LSMapRT 标签页会存在多个，若把各自的应用位置搞错就无法正常描画。

## 关于各着色器效果的种类

- full_LocalShadow.fx：为让舞力介入P 的 full.fx 对应本效果而做的改修版，MME 专用
- full_LocalShadow_MMM.fx：为让 Mogg 氏的 SampleBase.fxm 对应本效果而做的改修版，MMM 专用

## 其他着色器效果的改修方法

要让现有的着色器效果对应本效果，需要修改该着色器效果文件。

1. 把 LocalShadow_Header.fxh 复制到该着色器效果的文件夹中。开头参数请与本体保持一致。
2. 在过着色器效果中进行与 full_LocalShadow.fx、full_LocalShadow_MMM.fx 的改修处相同的修改。
   关于修改处，full_LocalShadow.fx、full_LocalShadow_MMM.fx 的注释中已有写明，请作为参考。

## 关于模型内置版

除了本效果（通常版）的方法之外，还可以把阴影生成所需的信息预先组入模型一侧，
使用「模型组入版」文件夹中的一整套效果文件，从而把繁琐的初始设置自动化。

详情请参考「模型组入版」文件夹中的「readme_モデル組込版.txt」。
