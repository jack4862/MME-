PAToon2.96  Readme


【概要】
HAToon2と以下の合成シェーダーです。
・HAToon2／ミーフォ茜様
・法線が回せるシェーダー／わたり様
・DirectionalSphere／Caeru様
・LocalShadow／HgShadow／PlanarShadow／針金Ｐ

ファイルの書き換えと利用にご協力いただいた皆様に改めて感謝いたします。
絶対壁、嘘パース、嘘視野角などに対応したものはPAToonβ版をダウンロードしてください。


【確認】
このデータの改変・再配布については改変元の規約に準じます。
このデータを使用したことによる損害の賠償には応じかねます。

コンテンツツリー登録は必須ではありませんが、
ミーフォ茜様のHAToon2と針金PのLocalShadowと併記登録を推奨しています。
（概要にあるそれ以外ももちろん登録して構いません）


【注意】
・PMDモデル非対応
・MikuMikuMoving非対応（一応使えなくはないのですが要検証）

【PAToonの分類】

・PAToon　　　通常版。とりあえず適用すれば嘘影になります。
　　　　　　　モデル丸ごとか特定材質１つだけを嘘影にしたい場合に推奨。

・PAToonKey   モデルの材質設定で反射強度を「～.039」の数値にした材質にだけ嘘影が効きます（要PMXE設定）。
　　　　　　　モデルの設定をちゃんとしてあればシェーダーかけ分けが不要なので一番楽ちんです！
　　　　　　　嘘影以外の材質はExcellentShadowかHgShadowを読み込むことで綺麗になります。

・PAToonLite　セルフ影の嘘影なし。色調できるHAToon2シェーダー+α。（セルフ影以外の嘘影設定は可能です）
　　　　　　　ExcellentShadowかHgShadowに対応しているので読み込むと影が綺麗になります。
　

・PAToonRT　　コントローラーを読み込んでモデルより描画順を上にしないとセルフシャドウが効かない。
            　RTタブで必要ないシャドウマップを非表示にしないとダメ。　
　　　　　　　サブセット展開して材質ごとにかけ分けた時にRTタブが必要以上に増えないという利点があります。
　　　　　　　細かい複雑な設定をしたい人向きです。（使い方次第）


・～_シェーダー　　シェーダー側で指定しているトゥーン色が優先されます。
・～_モデル　　　　モデル材質で指定しているトゥーン色が優先されます。（材質設定で材質ごとにトゥーン色を変えられます）


・～_～_標準　　　　　　特に追加設定なし。よくわからないなら標準を使ってください。
・～_～_ハンドルエッジ　シェーダーで独自にエッジを描画します。パースや半透明材質の影響を受けにくくなります。
・～_～_傾向色なし　　　シェーダー側の色調が少なくなり素直な色調になります。（材質設定を工夫する必要が増えるかも）

・～_～_濃い目　　　　　トゥーンの色が濃い目になります。～_シェーダーの設定例です。

【使い方】

準備）モデルに「埋め込み用ボーン」を埋め込む（推奨）。
　　　PAToonKey（推奨）を使う場合は嘘影適用材質の反射強度の小数点以下を「～.039」にする。

※準備なしでもお手軽に使えますが、モデル設定した方が断然楽です。

①MMEタブからPMX形式のモデルに「PAToon～.fx」(または他のシェーダー）を適用する。

②「PAToonコントローラー.pmx」を読み込む。
　
③「照明方向/影範囲」ボーンを操作する
　　　回転　→　照明方向が変わる
　  　移動　→　セルフ影のかかる範囲が動く

④ExcellentShadowかHgSHadowを読み込むとLocalShadow適用以外の影が滑らかになります。
　同梱の「ExcellentShadow2_CTR」「HgShadow_CTR」フォルダに入っているExcellentShadowかHgShadowを読み込むと、
　追加コントローラーを読み込むことでExcellentShadow、HgShadowでも影方向を嘘影設定することが可能です。（PAToon2.96以降）



※モデルにボーンを埋め込んだ場合でも外部コントローラーは有効です。
　外部コントローラーはシェーダー適用モデルすべてに、モデルに埋め込んだボーンはそのモデルだけに効きます。

※ハンドルエッジ用のモデル設定について
　2.97からハンドルエッジ設定専用のPMXEプラグインを同梱しました。
　モデルの材質側のエッジ設定が以下のように反映されます。

　材質設定によってハンドルエッジの太さ、色、透明度、エッジオフを指定できます。
   反射強度（小数点第4位）
　　例　～.0391、～.0001 etc　・・・　１にした材質はハンドルエッジがオフになる
　　例　～.0392、～.0002 etc　・・・　２にした材質は反射色と環境色に設定した色設定や太さが適用される

　反射色（R,G,B、小数点第3位～第5位）
　　例　R 0.00045、G 0.0002、B 0.0003　・・・　～.000001から～0.00100が0.1～1.0に対応していてRGBで色設定できる。
　　　　　　　　　　　　　　　　　　　　　　　　例は（R 0.45、G 0.2、B 0.3）。反射強度0.002のフラグがないと反映されない。

　環境色（R,G　、小数点第3位～第5位）　・・・　～.000001から～0.00100が0.1～1.0に対応していてαとサイズが調整できる。
　　例　R 0.5006、G 0.5006　　　　　　　　　　　例はRがエッジ非透過度0.6、Gがエッジ太さ0.6に相当。
　　　　　　　　　　　　　　　　　　　　　　　　反射強度0.002のフラグがないと反映されない。



◆影傾向マップ
UVマップを元に影が出やすいところと出にくいところを指定します。
中間色のグレー(0.5, 0.5, 0.5)をベース（傾向なし）にして、
黒(0,0,0）に近づくほど影が出やすく、白(1,1,1）に近づくほど影が出にくくなります。


◆ノーマルマップ
UVマップを元に材質に法線設定をします（影やスフィアの出方が変わります）。
詳しくは既存の解説サイトをご覧ください。


◆使い方
用意した影傾向マップとノーマルマップを指定する方法は３通りあります。
１．シェーダーfx側で外部テクスチャを指定（材質をかけ分けする場合）
２．モデル材質のサブテクスチャに指定
３．モデル材質のToonテクスチャに指定

２と３の場合はモデル材質の環境色設定の小数点第５～６位に以下のフラグを設定します。

・小数点第５位が１ならサブテクスチャを影傾向テクスチャに使う
・小数点第５位が２ならサブテクスチャをノーマルマップに使う

・小数点第６位が１ならトゥーンマップを影傾向テクスチャに使う
・小数点第６位が２ならトゥーンマップをノーマルマップに使う

トゥーンマップの右上1ドットが白(1,1,1)の場合はトゥーンが優先されて追加マップ設定は無視されます。
追加マップの左下1ドットのトゥーン色は有効なのでそこに色を乗せれば使えます。
サブテクスチャを指定した場合、その材質にスフィアは使えません。

モデル材質に追加マップを指定するとデフォルトがおかしくなりますがシェーダーを適用すれば問題はありません。


◆使い方のアドバイス
PAToon無印かPAToonLiteを使ってfx側からマップを外部指定した方が楽です。
嘘影のない材質に追加マップを使う場合はPAToonLiteに追加マップをfx側で外部指定した方がいいです。

PAToonKeyを常用する場合に材質側に追加マップを使うことを想定しています。
追加マップとスフィアを併用したい場合にトゥーンマップを使うことになると思います。

ノーマルマップや影傾向マップをオンにすることによってMME側でエラーが出る時、
ExcellentShadowフラグをオフにしてHgShadowを使うことで解決する場合があります。
（シェーダー側で使えるテクスチャ数の制限を超えてしまっていることが原因です）

　エッジ RGB　　　　移動　　エッジ色（X→赤, Y→緑, Z→青）


〈モーフ名〉　　　　　　　〈効果〉　▲はあまり使えない

　範囲拡大　　　　　　　　　セルフ影マップを大きくする（セルフ影のかかる範囲が大きくなる）

　X範囲拡大　　　　　　　　 セルフ影マップをX軸に拡大する▲
　Y範囲拡大　　　　　　　　 セルフ影マップをY軸に拡大する▲

　距離近　　　　　　　　　　セルフ影の出る距離を近くする▲
　距離遠　　　　　　　　　　セルフ影の出る距離を遠くする▲

　Lt陰影連動　　　　　　　　シェーダー影方向を標準照明に連動させる
　Lt遮影連動　　　　　　　　セルフ影方向を標準照明に連動させる

　Lt影濃度調整　　　　　　　影の濃度を調整する（無効）▲

　影ぼかし　　　　　　　　　セルフ影の境界をぼかす
　影薄く　　　　　　　　　　影を薄くする
　影濃く　　　　　　　　　　影を濃くする（無効）▲

　エッジ太　　　　　　　　　エッジを太くする
　エッジ細　　　　　　　　　エッジを細くする
　エッジ透明度　　　　　　　エッジを透明にする

　ｽﾌｨｱ追従ｵﾌ　　　　 　　　 スフィアのＺ軸回転追従機能をオフにする

　透明　　　　　　　　　　　コントローラーを透明にする
　表示　　　　　　　　　　　コントローラーを表示する（ボーン埋め込み版）
