LocalShadow.fx ver0.0.3

局所的に独自設定のセルフシャドウ描画を行う影生成エフェクト。
モデルの顔面に落ちる影を通常のライト方向と変えて、見栄えの良い影の落とし方をする
いわゆる｢嘘影｣のような効果をエフェクトで作成出来ます。
※当然ですがモデル側で嘘影設定をしている(セルフ影が落ちないようになっている)モデルには効果はありません。
応用でモデル全体を覆うことで任意の空間固定マップを作成して、ちらつきのない影生成を行うことも出来ます。


・動作環境
SM3.0対応グラフィックボードが必須になります。
MMEv0.37, MMEv0.37x64，MMMv125a，MMM64v125aで動作確認を行っています。旧バージョンでは動作しない可能性があります。


・使用方法[MMEの場合]
(1)必要に応じて LocalShadow_Header.fxh の先頭パラメータを変更してください。
(2)LocalShadow.pmxをMMDにロードしてください。ロード直後はコントロール用モデルが表示されています。
(3)LocalShadow.pmxの描画順序を影生成を行う対象モデルの直前にします。
(4)LocalShadow.pmxのセンターボーンを対象モデルの影生成を行う位置のボーン(通常は頭ボーン)に外部親登録します。
(5)｢MMEffect｣→｢エフェクト割当｣の｢LSMapRTタブ｣より対象モデルを選択して LocalShadow_ShadowMap.fxsub を適用します。
(6)｢MMEffect｣→｢エフェクト割当｣のMainタブより描画する対象モデルをサブセット展開して、
   影生成する材質(通常は顔の材質)を選択してから full_LocalShadow.fx を適用します。
(7)LocalShadow.pmxのボーン・表情バーのそれぞれの項目で以下の制御が可能です。コントロール用モデルが変形するので
   これでアタリを付けて調整してください。

   [ボーン]
     センター：影生成する位置の中心を調整します。ボーンを回転させることでライト方向を調整します(赤矢印がライト方向)。
   [表情バー]
     目    ：範囲縮小,範囲拡大 → シャドウマップ範囲を調整、｢ 田 ｣形状の枠内がシャドウマップを生成する範囲になります。
                                  影生成する範囲ぎりぎりまで小さくしてマップの解像度を上げた方が良いです。
             X範囲拡大,Y範囲拡大 → シャドウマップ範囲をXY個別調整、局所的な空間固定マップを作成する時に便利です。
             距離近,距離遠 → シャドウマップ生成する奥行きの範囲を調整、黄玉がNear,緑玉がFarの位置になります。
     ﾘｯﾌﾟ  ：Lt陰影連動 → 大きくするとモデルの陰影の掛かり方が標準のライト方向の影響を受けるようになります。
             Lt遮影連動 → 大きくするとモデルの遮蔽影の掛かり方が標準のライト方向の影響を受けるようになります。
             Lt影濃調整 → 大きくすると標準のライト方向によってモデルの遮蔽影濃度が変化します。逆光時に影を消したい時などに使用します。
             ※Lt陰影連動,Lt遮影連動,Lt影濃調整をうまく調整すると見栄えの良さを残しつつ、照明操作にも連動させることが出来ます。
     まゆ  ：影ぼかし → ソフトシャドウのぼかし度を調整
             影薄く,影濃く → 影の濃度を調整します。
     その他：透明 → 全ての設定が済んだら、ここでコントロール用モデルを非表示にして使用します。

(8)複数のモデルに適用する場合は上記の(2)～(7)手順を個々のモデルに対して行います。描画順序の間違いや、
   特にオフスクリーンLSMapRTタブが複数存在するのでそれぞれ適応箇所の間違えると正常に描画されなくなるので注意してください。


・使用方法[MMMの場合]
(1)必要に応じて LocalShadow_Header.fxh の先頭パラメータを変更してください。
(2)LocalShadow.pmxとLocalShadow.fxをMMMにロードして、メインのエフェクト割り当てでLocalShadow.pmxにLocalShadow.fxを適用します。
(3)描画順序を LocalShadow.pmx→LocalShadow.fx→対象モデル の順にしてください。順序が違うと正常に描画されません。
(4)LocalShadow.pmxのセンターボーンを対象モデルの影生成を行う位置のボーン(通常は頭ボーン)に外部親登録します。
(5)LocalShadow.fxのオフスクリーンLSMapRTタブより対象モデルを選択してリスト内にある LocalShadow_ShadowMap.fxsub を適用します。
(6)full_LocalShadow_MMM.fxをMMMにロードして、メインのエフェクト割り当より描画する対象モデルをサブセット展開して、
   影生成する材質(通常は顔の材質)に full_LocalShadow_MMM.fx を適用します。
(7)LocalShadow.pmxのボーン・表情バーのそれぞれの項目で以下の制御が可能です。コントロール用モデルが変形するので
   これでアタリを付けて調整してください(エフェクトのプロパティは使いません)。

   [ボーン]
     センター：影生成する位置の中心を調整します。ボーンを回転させることでライト方向を調整します(赤矢印がライト方向)。

             距離近,距離遠 → シャドウマップ生成する奥行きの範囲を調整、黄玉がNear,緑玉がFarの位置になります。

     まゆ  ：影ぼかし → ソフトシャドウのぼかし度を調整
             影薄く,影濃く → 影の濃度を調整します。
     その他：透明 → 全ての設定が済んだら、ここでコントロール用モデルを非表示にして使用します。

(8)複数のモデルに適用する場合は上記の(2)～(7)手順を個々のモデルに対して行います。
   LocalShadow.pmx,LocalShadow.fxは個々のモデルに対して個別のロードが必要です(full_LocalShadow_MMM.fxは
   全モデルで共有できるので1回だけロードすればよい)。
   描画順序の間違いや、特にLSMapRTタブがLocalShadow.fx毎に存在するので、それぞれ適応箇所の間違えると正常に
   描画されなくなるので注意してください。



・各シェーダエフェクトの種類について
   full_LocalShadow.fx     : 舞力介入Pの full.fx を本エフェクトに対応させるため改変、MME専用
   full_LocalShadow_MMM.fx : Mogg氏の SampleBase.fxm を本エフェクトに対応させるため改変、MMM専用



・他のシェーダエフェクトの改変方法
  既存のシェーダエフェクトに対応させるには、シェーダエフェクトファイルの変更が必要になります。
   ①LocalShadow_Header.fxhをシェーダエフェクトのフォルダにコピーします。先頭パラメータは本体のものと同じにしてください。
   ②full_LocalShadow.fx,full_LocalShadow_MMM.fxの改変箇所と同じ変更を各シェーダエフェクトで行います。
     変更箇所についてはfull_LocalShadow.fx,full_LocalShadow_MMM.fxのコメントに書いてあるので参考にしてください。



・モデル組み込み版について
本エフェクト(通常版)の方法以外に影生成に必要な情報を予めモデル側に組み込み、
｢モデル組込版｣フォルダ内にあるエフェクトファイル一式を使うことで、煩雑だった初期設定を自動化することが出来ます。
詳細は｢モデル組込版｣フォルダ内にある｢readme_モデル組込版.txt｣を参照ください。
