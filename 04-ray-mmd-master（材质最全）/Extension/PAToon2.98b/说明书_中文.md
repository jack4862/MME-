# PAToon2.96 Readme

## 概要

这是 HAToon2 与以下合成着色器的合成品。
- HAToon2／ミーフォ茜 様
- 法線が回せるシェーダー（可旋转法线的着色器）／わたり 様
- DirectionalSphere／Caeru 様
- LocalShadow／HgShadow／PlanarShadow／針金Ｐ

再次感谢协助文件改写与利用的各位。
对应绝对壁、假透视、假视野角等的版本请下载 PAToonβ 版。

## PAToon 的分类

- PAToon　　　通常版。总之应用上去就会变成假影。
　　　　　　　想把整个模型或某一个特定材质做成假影时推荐。

- PAToonKey   只对在模型材质设定中把反射强度设为「～.039」数值的材质生效假影（需要 PMXE 设定）。
　　　　　　　只要模型设定做好，就不需要分开着色器，最省事！
　　　　　　　假影以外的材质通过载入 ExcellentShadow 或 HgShadow 会变得漂亮。

- PAToonLite　无自阴影的假影。可调色调的 HAToon2 着色器+α。（自阴影以外的假影设定可行）
　　　　　　　对应 ExcellentShadow 或 HgShadow，载入后阴影会变漂亮。

- PAToonRT　　载入控制器并且绘制顺序排在模型之上，自阴影才会生效。
            　不在 RT 标签页中把不需要的阴影贴图设为非显示就不行。
　　　　　　　其优点是子集展开（Subset 展开）并按材质分开着色器时，RT 标签页不会增加到超出必要。
　　　　　　　适合想做细致复杂设定的人。（视用法而定）

- ～_シェーダー　　优先使用着色器侧指定的 Toon 色。
- ～_モデル　　　　优先使用模型材质中指定的 Toon 色。（可在材质设定中按材质更改 Toon 色）

- ～_～_標準　　　　　无特别追加设定。不太明白的话请使用标准版。
- ～_～_ハンドルエッジ　由着色器独自绘制边缘。较不易受透视和半透明材质影响。
- ～_～_傾向色なし　　　着色器侧色调减少，色调变得素直。（可能需要多在材质设定上下功夫）

- ～_～_濃い目　　　　　Toon 颜色变浓。是 ～_シェーダー 的设定例。

## 使用方法

准备）向模型嵌入「埋め込み用ボーン」（嵌入用骨骼）（推荐）。
　　　使用 PAToonKey（推荐）时，把假影适用材质的反射强度小数点以下设为「～.039」。

※无需准备也可轻松使用，但做好模型设定绝对更省事。

①从 MME 标签页对 PMX 格式的模型应用「PAToon～.fx」（或其他着色器）。

②载入「PAToonコントローラー.pmx」。

③操作「照明方向/影範囲」骨骼
　　　旋转　→　照明方向改变
　  　移动　→　自阴影波及的范围移动

④载入 ExcellentShadow 或 HgShadow 后，除 LocalShadow 适用以外的阴影会变得平滑。
　载入同梱的「ExcellentShadow2_CTR」「HgShadow_CTR」文件夹中的 ExcellentShadow 或 HgShadow，
　并通过载入追加控制器，即可在 ExcellentShadow、HgShadow 中把阴影方向设为假影设定。（PAToon2.96 以后）

※即使已向模型嵌入骨骼，外部控制器也有效。
　外部控制器对应用了着色器的所有模型生效，嵌入模型的骨骼只对该模型生效。

※关于手柄边缘用的模型设定
　从 2.97 起同梱了手柄边缘设定专用的 PMXE 插件。
　模型材质侧的边缘设定会按以下方式反映。

　根据材质设定，可以指定手柄边缘的粗细、颜色、透明度、边缘偏移。
   反射强度（小数点第 4 位）
　　例　～.0391、～.0001 etc　・・・　设为 1 的材质，手柄边缘被关闭
　　例　～.0392、～.0002 etc　・・・　设为 2 的材质，适用反射色与环境色中设定的颜色设定及粗细

　反射色（R,G,B，小数点第 3 位～第 5 位）
　　例　R 0.00045、G 0.0002、B 0.0003　・・・　～.000001 到 ～0.00100 对应 0.1～1.0，可用 RGB 设定颜色。
　　　　　　　　　　　　　　　　　　　　　　　　例中为（R 0.45、G 0.2、B 0.3）。没有反射强度 0.002 的标志则不会反映。

　环境色（R,G，小数点第 3 位～第 5 位）　・・・　～.000001 到 ～0.00100 对应 0.1～1.0，可调整 α 与尺寸。
　　例　R 0.5006、G 0.5006　　　　　　　　　　　例中 R 相当于边缘非透明度 0.6，G 相当于边缘粗细 0.6。
　　　　　　　　　　　　　　　　　　　　　　　　没有反射强度 0.002 的标志则不会反映。

### ◆阴影倾向贴图

以 UV 贴图为基础，指定容易出阴影和不容易出阴影的地方。
以中间色的灰（0.5, 0.5, 0.5）为基准（无倾向），
越接近黑（0,0,0）越容易出阴影，越接近白（1,1,1）越不容易出阴影。

### ◆法线贴图

以 UV 贴图为基础对材质设定法线（阴影和球面的表现方式会改变）。
详情请参阅既有的解说网站。

### ◆使用方法

指定准备好的阴影倾向贴图与法线贴图有 3 种方法。
１．在着色器 fx 侧指定外部贴图（分开着色器材质时）
２．指定到模型材质的子贴图（Sub Texture）
３．指定到模型材质的 Toon 贴图

２和３的情况，在模型材质的「环境色」设定的小数点第 5～6 位设定以下标志。

- 小数点第 5 位为 1，则把子贴图用作阴影倾向贴图
- 小数点第 5 位为 2，则把子贴图用作法线贴图

- 小数点第 6 位为 1，则把 Toon 贴图用作阴影倾向贴图
- 小数点第 6 位为 2，则把 Toon 贴图用作法线贴图

当 Toon 贴图右上 1 点为白（1,1,1）时，Toon 会被优先，追加贴图设定被忽略。
追加贴图左下 1 点的 Toon 色是有效的，在那里乘上颜色即可使用。
若指定了子贴图，该材质便无法使用球面（Sphere）。

向模型材质指定追加贴图后默认会变得不正常，但应用着色器后就没有问题。

### ◆使用建议

使用无印 PAToon 或 PAToonLite，从 fx 侧外部指定贴图会更轻松。
对没有假影的材质使用追加贴图时，最好在 PAToonLite 的 fx 侧外部指定追加贴图。

常用 PAToonKey 时，设想的是在材质侧使用追加贴图。
想并用追加贴图与球面时，大概就会用到 Toon 贴图。

开启法线贴图或阴影倾向贴图导致 MME 侧报错时，
关闭 ExcellentShadow 标志并使用 HgShadow，有时可以解决。
（原因是超出了着色器侧可使用的贴图数量限制）
