# 全屏 Bug 回避示例

这是在与 HgSAO_v001 及其他后处理效果并用时，使画面不出现 Bug 的效果示例。
详情请参阅 http://seiga.nicovideo.jp/seiga/im4389805。

## ・SoftLight

　这是对そぼろ氏制作的 Diffusion7 进行改変的色调补正效果。
　X 指定模糊范围（0～20 左右），Si 指定亮度（0～15 左右），Tr 指定滤镜强度。

## ・HgSAO_FullScreen

　这是仅用于回避全屏时或输出时画面 Bug 的效果。
　如果在意会浪费一整屏资源，请在 MME 的 Main 标签中将 HgSAO_FullScreen.x 设为不显示。
　只要在 MMD 的 Accessory 操作面板中处于显示状态，Bug 回避效果似乎就会持续。（反之则不行）
