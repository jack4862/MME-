# AutoLuminous Ver.3.6（自发光效果）

制作：そぼろ

这是继 KeyLuminous、ObjectLuminous 之后的第三弹发光效果。
可以让指定的部位看起来像是在发光一样地被绘制出来。

## 运行环境

支持着色器模型 3.0 以及浮点纹理 mipmap 的显卡（推荐 DX10 世代以后）

- MikuMikuEffect 0.27 及可运行它的 MikuMikuDance
- MikuMikuEffect x64 0.32 及 MikuMikuDance x64
- MikuMikuMoving 1.1.8.1 以后

测试环境：
　Win7 x64 + Phenom II X6 + GTS450
　Win7 x64 + Core i7 2677M + Intel HD Garphic

## 使用方法

### 指定发光部分

本效果通过改造模型或附件来指定发光部分。

指定方法是：把想要发光的材质的镜面反射色（反射色）设为黑色 (0,0,0)，把镜面反射强度（反射强度）设为 100 以上。
这个组合通常不会被使用，所以发生非预期发光的可能性很低。

镜面反射强度的标准值是 110。
想先让它亮起来的话，请使用这个值。
在此值上下调整时，发光强度会与「镜面反射强度减去 100 的值」成比例地上下变化。

发光色会根据漫反射色和环境色自动决定。

### 载入 MMD

在载入按上述方式改造过的模型之后，载入 AutoLuminous.x 并加载效果，指定部分就会发光。

如果是 MMM，则载入的是 AutoLuminous.fx。

### 参数操作

通过修改 AutoLuminous.x 作为附件的数值，可以操作效果参数。

如果视频中要始终使用固定设置，直接输入数值即可；如果要动态变化，推荐挂到假骨骼（DummyBone）上。

・**Si：发光强度**

指定发光部分的光的强弱。

・**Tr：模糊强度**

指定发光部分模糊的强弱。
无法调大。
这是因为原本的模糊强度已经被设定得相当大了。
即便如此仍想调大的话，需要直接编辑效果文件。

--------------------------

・**X：光芒方向数**

指定眩光延伸的方向数。
请注意，每个方向同时也会向相反方向延伸光芒。
例如指定 3，就会延伸出 6 条光芒。
适当值约为 0～9。
请注意数量越多负荷越大。
此外，增加数量时有时会比预想的更亮。

・**Y：原画面辉度**

增减原屏幕画面的亮度。
适当范围约为 -100～100。
设为 -100 时，原屏幕会完全变成全黑。

・**Z：发光强度**

只是指定数值的方式不同，效果与 Si 相同。
适当范围约为 -100～500。
-100 与 Si=0、100 与 Si=2 具有相同的效果。
这是为想从假骨骼操作发光强度的情况而设计的。

--------------------------

・**Rx：光芒角度**

将眩光的角度偏移指定的角度。

・**Ry：光芒长度**

增减眩光的长度。
适当范围约为 -100～100。
拉得太长会出现条纹。

・**Rz：闪烁周期**

让发光闪烁。输入的数值直接作为以秒为单位的闪烁周期。
正数时以正弦波闪烁，负数时以矩形波闪烁。
设为 0 则停止闪烁。

## 用法的扩展

### ObjectLuminous 兼容功能

AutoLuminous 可以像 ObjectLuminous 一样应用以下用法。

・使用选择器效果（Selector Effect）
・对个别材质应用单色效果
・从 MME 标签页对材质进行「解除」

各项详情请参阅 ObjectLuminous 的 Readme 及各种解说。
ObjectLuminous 用的选择器效果可以直接使用。

### 与 KeyLuminous 的兼容功能

与 KeyLuminous 相同，可以指定画面上的键色（KeyColor）使其发光。
由于必须编辑效果文件，详情在上級編中解说。

### 直接编辑效果文件

有一部分参数必须直接编辑效果文件才能修改。
这需要一定程度的特效知识。

这些参数包括：模糊范围、采样数、背景色等。
各项目的说明记载在效果文件当中。

特别是采样数，在以全高清级大分辨率输出时，
标准的采样数完全不够、会出现条纹，因此必须把值调大。
不过采样数增加后自然也会变重。

### 通过追加 UV 进行逐顶点发光控制

仅限 PMX，通过使用追加 UV 功能，可以更灵活地进行逐顶点的发光控制。
详情在上級編中解说。

## 轻量效果「AutoLuminousBasic」

AutoLuminousBasic 是在 AutoLuminous 太重跑不动时，
只使用最小限度功能的轻量版效果。
虽然大幅变轻，但功能和绘制质量都受到限制，
也无法与其他效果联动。
质量大致相当于 ObjectLuminous。

请把它理解为只能简单地让 AL 对应模型发光。

## AutoLuminous 基本结构

AutoLuminous 的实质是 HDR 绘制引擎。
颜色信息全部以浮点数处理，可以处理 0～1 超出范围的颜色。并且，超过 1 的颜色会作为高辉度部分被进行泛光（Bloom）和眩光（Glare）处理。

AL_EmitterRT 不过是为刻意附加高辉度部分而设的前端。

## 键色发光

与 KeyLuminous 相同，可以指定键色（KeyColor）使其以任意颜色发光。
打开效果文件，编辑以下 3 个参数。

・**KeyThreshold**
　用于颜色判定的阈值。

・**KEYCOLOR_NUM**
　键色的数量。
　指定 0 则键色发光无效。

・**KeyColors**
　键色的数组。
　按照注释文字，追加键色、核心色、发光色这 3 个。
　必须按 KEYCOLOR_NUM 指定的数量进行设定。
　不过 KEYCOLOR_NUM 为 0 时该参数本身会被忽略，
　所以怎样写都 OK。

## 通过表情进行个别发光控制

如果是 PMD 或 PMX 模型，通过在模型中编入以下名称的假表情，
就可以按模型个别地控制发光。
也可以只选需要的加入。

・LightUp
・LightOff
・LightBlink
・LightBS
・LightUpE
・LightDuty
・LightMin

"LightUp" 和 "LightOff" 可以调整光量。
LightUp 最大可以变亮到 3 倍。
LightOff 在 MAX 时发光会完全消失。

使用 "LightBlink" 和 "LightBS" 这两个假表情，
可以按模型个别控制发光的闪烁。
"LightBlink" 是正弦波闪烁，LightBS 是矩形波闪烁。
最大间隔为 10 秒。

"LightUpE" 中，亮度会以指数函数上升。
最大上升到 400 倍。
"LightDuty" 可以改变闪烁的开启与关闭的比率。
"LightMin" 可以设定闪烁时的最小亮度。

这些假表情只有在通过 AL_Object.fxsub 利用镜面反射强度或顶点发光功能指定发光时才可以使用。

## 顶点发光功能

仅限 PMX，可以使用追加 UV 进行逐顶点的发光控制。
虽然比材质指定更灵活，但改造和数据管理会变得繁琐。

・**追加 UV1**
　・X:0.2, Y:0.7
　　这是表示其为 AutoLuminous 用追加 UV 数据的识别码。
　　该值是固定的。

　・Z:闪烁周期
　　以秒为单位指定闪烁周期。
　　负数值时为矩形波闪烁。

　・W:标志
　　指定标志。从以下项目中把想指定的项目相加。
　　该值在用于某一面的所有顶点上必须相等。

　　・1 的位：纹理模式
　　　・0 : 标准（纹理乘法）
　　　・1 : 无纹理乘法
　　　・2 : 高辉度抽取。在 UV2 中指定 (1,1,1,1) 则等同于 AL_Texture。
　　・10 的位：颜色模式
　　　・00 : 标准（RGB 指定）
　　　・10 : 把 UV2 的 XYZ 从 RGB 改为 HSV。

・**追加 UV2**
　・X:红, Y:绿, Z:蓝
　　指定发光色。

　・W:发光强度
　　指定发光强度。基准是 1。

・**追加 UV3**
　・X:纹理减色
　　从纹理颜色中减去该值。若结果为 0 以下则向上取整为 0。

　・Y:闪烁相位
　　以秒为单位指定闪烁的相位。

　・Z:弹出（Popup）
　　按指定的值把发光部位沿法线方向推出并绘制。
　　使用这个功能可以隐藏发光用的对象。

　Options 文件夹中同梱了用于在 PMDE 中批量修改所选顶点追加 UV 的脚本。
　请从「插件 > CSSScript」载入，适当改写数值后执行。

　另外，从 Ver.3.1 起，附带了可以用 GUI 设定顶点发光的插件「AutoLuminousSetter」。
　它以压缩状态放在 Options 文件夹中，请解压后放入 PMDE 的插件文件夹中使用。
　在 Win7 上需要解除锁定（ブロックの解除）。

## 遮罩功能

可以设定让特定对象不受发光影响。
首先，打开效果文件，把 MASK_ENABLE 选项设为 1。
于是 MME 的设置标签页中会出现 "AL_MaskRT"，
选择不想受发光影响的对象并右键，
点击「解除」。

对正在发光的对象应用遮罩，
就会变成后光或光环（Aura）那样的表现。

## 残光功能

打开效果文件，把 AFTERGLOW 设为 0 以上的值，残光功能就会启用。
由于是帧混合方式，移动太快会出现不连续。
请通过提高输出 FPS 等方式应对。

## 纹理的各向异性过滤支持

让应用了复杂纹理的材质发光时，有时会因纹理缩小的影晌而使发光闪烁。
修改 AL_Object.fxsub 的 MIPMAPTEX_SIZE 即可启用各向异性过滤，
有时能缓和闪烁。
数值推荐与模型所使用的最大纹理尺寸大致相同，
但过大会变重。
另外有整体变模糊的副作用。

在 MMDx64 以及 MMM 中标准就支持各向异性过滤，
因此不需要使用这个功能。

## 纹理高辉度部分发光

当想发光的部分画在纹理上、无法作为材质分离出来时，
从 MME 的 AL_EmitterRT 标签页选择目标模型或材质，
应用附带的 AL_Texture.fx，就可以设定为只有纹理的明亮处发光。
不过，多数情况下需要细致的调整。

## 色调曲线变更

载入 ToneCurve.x 后，AutoLuminous 的色调曲线会被改变，
变得不易发生白飞（过曝）。
不过由于会降低原屏幕的对比度，
推荐在画面上存在较多高辉度部分时使用。

相反，如果画面较暗，低辉度的色调曲线仍是直线，
因此可以在不降低对比度的情况下使用。

把 SCREEN_TONECURVE 设为 1，可以强制开启色调曲线。

## 测试模式

载入 AL_Test.x 后 AutoLuminous 会进入测试模式，
只显示加入模糊之前的高辉度部分。

用 AL_Test.x 的 Si 可以操作亮度。

在对 AutoLuminous 的发光绘制不满意时，
可以把测试模式输出导入视频编辑软件进行辉光（Glow）处理。

## 通过加算合成附加高辉度

通过设定为加算合成的附件或模型，颜色超过 1 的部分通常只会被钳制为 1；
但在 AutoLuminous 中，通过变更渲染目标（Render Target），
即使是 MMD 侧的绘制也能处理超过 1 的信息，
从而被当作高辉度部分处理。

不过，在非加算合成的通常绘制中，由于数值会在着色器内被钳制，
所以例如把照明调得比平时更亮，也不会产生高辉度部分。
不过似乎只有加算球是例外。

如果替换为自定义着色器，则不受此限制。

## 与光源效果并用

MMD 屏幕上属于加算合成类型的效果，可以使其支持 HDR 处理。
例如 SpotLight、PanelLight、PostPointLight 等。
通常，SpotLight 照亮的地方如果过亮，该部分只会白飞；
但如果把绘制顺序排在 AutoLuminous 之前，
且中间不夹入其他（不支持 HDR 的）后期效果，
就可以作为高辉度部分给予泛光和眩光效果。

## 支持效果「LightSampling」

LightSampling 是抽取画面中超过 1 的高辉度部分
并将其传递给 AutoLuminous 的效果。
它提高 HDR 功能的自由度。
可以通过 Si 指定高辉度部分的发光强度，通过 Tr 指定视为高辉度部分的阈值。

推荐如下这样的效果排列顺序。

・支持 HDR 的后期效果、加算合成系的后期效果（PanelLight、PointLight 等）
　　　↓
・LightSampling
　　　↓
・不支持 HDR 的后期效果（Diffusion、SSAO 等）
　　　↓
・AutoLuminous
　　　↓
・不想受其他后期效果影响的后期效果（字幕等）

## 为了获得高画质

如果要追求高画质，
建议把采样数增加到大约两倍，
并尽可能以较大的尺寸输出后再缩小。

## MikuMikuMoving 支持

AutoLuminous 虽然还是临时的，但已支持 MikuMikuMoving。
在 MikuMikuMoving 中，载入的不是 AutoLuminous.x 而是 AutoLuminous.fx，
效果即可生效。

目前仍有一部分功能无法使用，也可能受 MMM 今后更新的影响，敬请谅解。
