# 地图效果 Ver.1.0（マップエフェクト）

制作：そぼろ

这是显示地图的效果。
请用于演出或作业辅助。

大概支持 MMM。

## 使用方法

首先加载 Map.x 或 PostMap.x（在 MMM 中为 PostMap.fx）中的任意一个。
之后再追加加载可选的假（dummy）配件。
详细内容如下。

### Map.fx

　显示地图的正方形板。
　与通常的配件一样操作。

### PostMap.fx

　始终显示在画面最前面的地图。
　可用 X 和 Y 改变位置，用 Si 改变大小。

### MapAreaSize.x

　用于指定地图显示区域大小的假配件。
　通过改变 Si 的值，可以变更地图中显示区域的大小。
　把 Tr 调小后，会改为强调显示进入相机视野内的部分。

### MapCenter.x

　默认情况下地图的中心是相机位置，
　但加载 MapCenter.x 后，那里就会成为地图中心。
　也可以安装到模型上或使其旋转。

### MapFrame.png

　用于绘制地图显示框与中心标记的纹理。
　这张图片可以自由替换，没有问题，
　但请不要忘记把地图部分正确地做成透明。

### MapDraw.fxsub

　实际用于地图绘制的着色器。
　通过编辑本效果，有几个可以指定的参数。
　代表性的如下。

- MapAreaSize
- MapAreaDepth

　指定默认显示区域的宽度与高度。

- MAP_TYPE

　可以进行高度显示或线框显示等。

## 只在地图上显示的对象

　将 alpha 设为 0、高光（Specular）的 R 设为 0、高光的 G 设为 1、高光强度设为 0
　这样指定的对象，在 MMD 中由于 alpha 为 0 而不会被绘制，
　但在地图上会以高光的 B 作为 alpha 的替代来显示。

　同捆了 sample1.x，请参考一下。
