# 超高品质自阴影效果 Ver.1.1（超高品質セルフシャドウエフェクト）

制作：そぼろ

这是面向「只要能获得漂亮的阴影，无论怎么折腾显卡都无所谓」这一取向用户的高品质阴影效果。

它将 MMD 标准的透视阴影贴图、近景用固定阴影贴图、远景用广域固定阴影贴图这 3 张动态混合，
再通过后期处理加入模糊，从而实现了前所未有的出色（excellent）阴影。

## 使用环境

- MME 0.27 以后
- 支持 SM3.0 以及浮点纹理 mipmap 的显卡
- 推荐 VRAM：1GB 以上

## 使用方法

1. 加载 ExcellentShadow.x。此时什么都不会发生。
2. 对所有的模型、配件应用 full_ES.fx。
3. 启用模型、配件的自阴影。

ExcellentShadow.x 的位置会成为阴影贴图的中心。
另外，由 ExcellentShadow.x 的 Si 决定阴影贴图的大小。

把阴影贴图调大，就能在更广的范围内产生自阴影，
但相应地细微的阴影会被压溃，边缘也会变脏。
请在远景、近景中好好调整。
即使是默认状态，也能覆盖ゲキド街（激怒街）的一半左右。

由于本效果也会利用 MMD 标准的阴影，
如果在关闭效果时的阴影上也多加留意，就能获得更好的结果。

通过 ExcellentShadow.x 的 Tr 可以调整阴影的浓度。
Tr 调小则阴影变浓。

该效果在默认情况下对 PMD 模型只会较弱地适用。
（这是为了防止人物模型的阴影变得过浓）
想对 PMD 模型也适用时，请编辑 full_ES.fx，
将 PMD_SHADOWPOWER 的值调大。

通过配件的 X 旋转可以增减阴影的模糊强度。
范围为 -100～100。
骨骼安装的影响会被忽略。

## 轻量化

打开 ExcellentShadowCommonSystem.fx，
将 EXCELLENT_SHADOW_FULL 注释掉，就会变成降低品质的轻量模式。

如果过于沉重而无法正常运行时，请试一试。

## 着色器效果的 ExcellentShadow 支持

基于 full.fx 的着色器效果，
可以比较简单地使其支持 ExcellentShadow。

如果效果的内容相对 full.fx 有大幅改动，
用这种方法有时会不顺利。
另外，无法适用于顶点变化系、增殖系的效果。

- 首先，把目标效果另存为别的名字。
  在末尾加上「_ES」之类会更容易分辨。

- 用编辑器打开效果，参考 full_ES.fx，
  将以下所指示的 4 处复制粘贴追加进去。

```
/////////////////////////////////////////////////////////////////////////////////////////
/////////////////////////////////////////////////////////////////////////////////////////
// ■ ExcellentShadow系统　从这里↓

XXXX

// ■ ExcellentShadow系统　到这里↑
/////////////////////////////////////////////////////////////////////////////////////////
/////////////////////////////////////////////////////////////////////////////////////////
```

另外，用这种方法改造的效果，在未使用 ExcellentShadow 时，
可以显示 MMD 通常的阴影。
