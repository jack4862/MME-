# AbsoluteShadow（绝对自阴影效果）

制作：そぼろ

这是为「只要能得到漂亮的阴影，不管需要多少作业时间和机器性能都无所谓」的人准备的高品质阴影效果。

## 使用环境

支持 SM3.0 以及浮点纹理 mipmap 的显卡
推荐 VRAM：1GB 以上

## 使用方法

１．载入 AbsoluteShadow.x。此时什么都不会发生。
２．对所有模型・附件应用 full_AS.fx。
３．启用模型・附件的自阴影。

AbsoluteShadow.x 的位置会成为阴影贴图的中心。
另外，AbsoluteShadow.x 的 Si 决定阴影贴图的大小。

把阴影贴图调大可以让更广的范围产生自阴影，
但相应地细致的阴影会被压溃，边缘也会变脏。
请在远景、近景之间好好调整。
作为参考标准，Si=1.0 约为标准舞台全域，Si=10 约为垃圾街（ガレキ町）全域的程度。

可以通过 AbsoluteShadow.x 的 Tr 调整阴影的浓度。
把 Tr 调小，阴影会变浓。
这个效果在标准状态下不会应用于 PMD 模型。
（这是为了防止人物模型的阴影变得过浓）
想对 PMD 模型也应用时，请编辑 full_AS.fx
把 PMD_SHADOWPOWER 的值调大。

    float comp = saturate(dot(IN.Normal,-LightDirVec)*Toon);

        // シャドウバッファ内
        
        ////VSM法の実装
        float2 depth = GetZBufSample(TransTexCoord);
        depth.y += 0.00002;
        float sigma2 = depth.y - depth.x * depth.x;
        float comp2 = sigma2 / (sigma2 + IN.ZCalcTex.z - depth.x);
        comp2 = saturate(comp2) + (comp2 < 0);

    }
    
    return lerp(ShadowColor, Color, comp);

## 技术解说

MMD 标准的自阴影使用的是被称为透视阴影贴图（Perspective Shadow Map）的技法。
它根据光源方向与视点方向的关系动态改变阴影贴图范围来获取分辨率，
但存在移动摄像机时阴影轮廓会沙沙地动、阴影忽有忽无、极其不擅逆光等弱点。

本效果通过高分辨率的固定阴影贴图＋方差阴影贴图（Variance Shadow Map）技法，
使阴影完全不受摄像机影响，阴影轮廓会呈晕开状。

代价是：把阴影贴图调大会让细致的阴影消失、
负荷会大幅增加等缺点。

另外，还需要按场景手动调整最优的阴影贴图大小，比较费事。
