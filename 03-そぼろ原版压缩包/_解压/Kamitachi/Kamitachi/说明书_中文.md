# かま○たち之夜风剪影着色器（かま○たちの夜風シルエットシェーダ）

制作：そぼろ

把它应用到任意的模型上，就会变成某游戏风格的半透明剪影。
与单纯改动材质的 alpha 不同，重叠的多边形（如头发等）不会透出来。

需要把绘制顺序设在其他模型之后，这一点与一般的半透明材质相同。

颜色与透过度可以通过编辑效果、变更 SilhouetteColor 来改变。

由于使用了模板缓冲（Stencil Buffer），
有可能会与使用其他模板缓冲的效果发生干涉。

这种情况下，请适当地插入另行发布的「StencilClear」。
