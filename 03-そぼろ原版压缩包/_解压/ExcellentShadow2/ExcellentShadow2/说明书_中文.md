# ExcellentShadow Ver.2.4（超高品质自阴影效果）

制作：そぼろ

这是为「只要能得到漂亮的阴影，不管怎么折磨显卡都无所谓」的人准备的高品质阴影效果。

它把 MMD 标准的透视阴影贴图（Perspective Shadow Map）、近景用固定阴影贴图、远景用广域固定阴影贴图这 3 张动态混合，再通过后期处理加入模糊，实现了前所未有的卓越阴影。

## 使用环境

- MikuMikuEffect Ver.0.27 以后
- MikuMikuMoving Ver.1.1.8.2 以后

支持 SM3.0 以及浮点纹理 mipmap 的显卡
推荐 VRAM：1GB 以上

## 使用方法

１．载入 ExcellentShadow.x。此时什么都不会发生。
２．对所有模型・附件应用 full_ES.fx。
３．启用模型・附件的自阴影。

ExcellentShadow.x 的位置会成为阴影贴图的中心。
请把 ExcellentShadow.x 配置在想要拍摄的对象附近。

ExcellentShadow.x 的 Si 决定阴影贴图的大小。
把阴影贴图调大可以让更广的范围产生自阴影，
但相应地细致的阴影会被压溃，边缘也会变脏。
请在远景、近景之间好好调整。
默认状态下也能覆盖约半个激ド街（ゲキド街）的范围。

由于本效果也利用 MMD 标准的阴影，
如果在关闭效果时也注意阴影，就能得到更好的结果。
Ctrl+G 扩大阴影缓冲也有效果。

可以通过 ExcellentShadow.x 的 Tr 调整阴影的浓度。
把 Tr 调小，阴影会变浓。

这个效果在标准状态下对 PMD 模型只会微弱地生效。
（这是为了防止人物模型的阴影变得过浓）
想对 PMD 模型也应用时，请编辑 full_ES.fx
把 PMD_SHADOWPOWER 的值调大。

可以通过附件的 X 旋转增减阴影的模糊强度。
范围是 -100～100。
骨骼安装的影响会被忽略。

## 材质表情对应

在 MMD＋MME 中，对于使用了材质表情的 PMX 模型，
请用 full_ES_pmx.fx 代替 full_ES.fx 来应用。

## 轻量化・详细设置

・**质量等级**

打开 ExcellentShadowCommonSystem.fx，
通过 EXSHADOW_QUALITY 的数值可以设定质量等级。
初始值被设定为中质量。

如果太重无法正常运行时，请尝试把值调低。

・**MMD 标准阴影的使用/不使用**

打开 ExcellentShadowCommonSystem.fx，
修改 MMDSHADOW_USING 的值，即可设定是否利用 MMD 标准的阴影。
不使用时，由于 ExcellentShadow 内部的阴影没有被透视化，影响是在俯视时的阴影容易出现锯齿（Jaggy），但阴影的轮廓不会再「扭来扭去」地动。

・**多采样阴影**

打开 ExcellentShadowCommonSystem.fx，
修改 MULTISAMPLING 的值即可启用多采样阴影功能。
内容大致与ビームマンP的简易软阴影相同。
再对它进一步模糊，就能得到锯齿更少的阴影。
会稍微变重。

・**应用阴影的 alpha 值阈值**

本效果中，低于一定 alpha 值的对象
会在阴影处理中被忽略。
打开 ExcellentShadowCommonSystem.fx，
修改 ShadowAlphaThreshold 的值即可更改这个阈值。

## MikuMikuMoving 对应

从 Ver.2.3 起，已支持 MikuMikuMoving。
使用方法是：载入 ExcellentShadow.fx，对模型应用 full_ES_mmm.fxm。
不过，存在以下限制。

・MMDSHADOW_USING 会被强制关闭，
　只使用 ExcellentShadow 内部的阴影贴图。

・不支持 MMM 的多个光源。第 2 光源以后不会产生阴影。
　基本上请用 1 个光源使用。

・在 MMM 中无法按模型个别设定是否投影。
　所有对象都会被施加自阴影。
　作为例外，alpha 值 0.98 的材质不投影这一 MMD 的规格，
　已在 ExcellentShadow 内部重现。

## SSAO 联动

载入同梱的 ExShadowSSAO 效果后，
SSAO 信息会被传递给 full_ES 着色器侧，
进行非后期处理的 SSAO 绘制。
虽然差别不太容易看出来，但它可以考虑到材质和阴影的信息，
因此感觉会稍微自然一些。
举个例子，照明照射到的部分的 SSAO 效果会变弱。

ExShadowSSAO 的内容与 SvSSAO 大致相同，
但它会把阴度贴图（陰度マップ）传递给 ExcellentShadow，
因此不能单独使用。

## 让着色器效果对应 ExcellentShadow

基于 full.fx 的着色器效果，
可以相对简单地对应 ExcellentShadow。

如果效果的内容相比 full.fx 有大幅改动，
用这种方法有时会不顺利。
另外，无法应用于顶点变化系、增殖系的效果。

・首先，把目标效果另存为别的名字。
　在末尾加上 "_ES" 之类会比较容易分辨。

・用编辑器打开效果文件，参考 full_ES.fx，
　按下面指示的 4 个位置复制粘贴并追加。

```
/////////////////////////////////////////////////////////////////////////////////////////
/////////////////////////////////////////////////////////////////////////////////////////
// ■ ExcellentShadowシステム　ここから↓

XXXX

// ■ ExcellentShadowシステム　ここまで↑
/////////////////////////////////////////////////////////////////////////////////////////
/////////////////////////////////////////////////////////////////////////////////////////
```

另外，用这种方法改造过的效果，在未使用 ExcellentShadow 时
可以显示 MMD 通常的阴影。

## 注意事项

・与 AbsoluteShadow 没有兼容性。
・由于机制上的原因，半透明对象的阴影会有点可疑。
