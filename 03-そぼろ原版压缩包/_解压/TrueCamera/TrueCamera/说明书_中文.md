# TrueCamera

被写界深度（景深）＋动态模糊＋鱼眼镜头　效果
Ver.2.0

制作：そぼろ

这是为了进行接近真实摄像机的表现，而把 SvDOF.fx、MotionBlur.fx 以及 FishEye.fx 统合起来的效果。
非常沉重。
本以为比起各自单独使用会轻一些，但结果并没有太大差别。

假定以 30fps 使用。
用 Si 调节被写界深度，用 Tr 调节动态模糊。

鱼眼镜头属于特殊用途，因此默认处于关闭状态。
想使用时请把 FISHEYE_ENABLE 设为 1。

从 Ver.1.1 起，搭载了高品质 DOF 模式。
品质大致介于 SvDOF 与 SvDOF_HQ 之间。
把 DOF_HIGHQUALITY 设为 1 即可启用。
如果机器性能有余裕，推荐启用。

详细内容请参照各个效果的 Readme。

- MME 0.27 以降
- 支持着色器模型 3.0 以及浮点纹理的显卡

测试环境：Win7 x64 + Phenom II X6 + GTS450

## 使用方法

- 读取 TrueCamera.x。
- 把 TrueCamera.x 关联到想要对焦处的骨骼上。
- 用 Si 调节模糊强度。

对焦基本上在 TrueCamera.x 所在的位置合上。
需要精细调整时，关闭 MME 会更容易看出它在哪里。
用 Si 值可调节模糊强度。
初始设定相当强，请按喜好调整。
