# Party_{最大粒子数}_circle.pmx
圆形粒子

## 使用方法
将**全ての親**骨绑定外亲到需要运动的骨骼
### 普通主渲
* Main栏直接设置Party_{最大粒子数}_circle.fx
### ray渲
* Main栏直接取消
* MaterialMap栏设置ray/Party_material_{最大粒子数}_circle.fx
* OutlineMap栏设置ray/Party_outline_{最大粒子数}.fx
### ikBokeh
* 主渲同上
* LinearDepthMapRT栏设置ikBokeh/Party_depth_{最大粒子数}.fx

## 参数说明
### 边缘颜色参数
* EdgeColorR+: 边缘红色增加
* EdgeColorG+: 边缘绿色增加
* EdgeColorB+: 边缘蓝色增加
* EdgeHueNoise+: 边缘色相随机偏移
### 中心颜色参数
* CenterColorR+: 中心红色增加
* CenterColorG+: 中心绿色增加
* CenterColorB+: 中心蓝色增加
* CenterHueNoise+: 中心色相随机偏移
### 透明参数
* Hollow+: 空心
* Alpha-: 整体透明度降低
* Alpha--: 中心向边缘透明度逐渐降低
### 其它参数
* Brightness+: 亮度增加
* Count-: 粒子数减少
* LifeTime+: 粒子寿命增加
* LifeTime-: 粒子寿命减少
* Size+: 粒子大小增加
* PosNoise+: 粒子位置随机偏移
* Restart: 清空缓存, 使用ray渲或ikBokeh时, 上完材质后, 将该值调成1, 等个1秒钟, 然后恢复成0, 不要K帧

# Party_{最大粒子数}_texture.pmx
纹理粒子

## 使用方法
将**全ての親**骨绑定外亲到需要运动的骨骼
### 普通主渲
* 自行修改Party_{最大粒子数}_texture.fx的**COLOR_TEX_SRC**段为你的粒子纹理图片路径
* Main栏直接设置Party_{最大粒子数}_texture.fx
### ray渲
* 自行修改Party_material_{最大粒子数}_texture.fx的**COLOR_TEX_SRC**段为你的粒子纹理图片路径
* Main栏直接取消
* MaterialMap栏设置ray/Party_material_{最大粒子数}_texture.fx
* OutlineMap栏设置ray/Party_outline_{最大粒子数}.fx
### ikBokeh

* G+: 绿色增加
* B+: 蓝色增加
### 调色参数
* HueNoise+: 色相随机偏移
* Hue+: 色相增加
* Hue-: 色相减少
* Saturation+: 饱和度增加
* Saturation-: 饱和度减少
* Value+: 亮度增加
* Value-: 亮度减少
* Gamma+: 伽马增加
* Gamma-: 伽马减少
### 透明参数
* Alpha-: 整体透明度降低
* Alpha--: 中心向边缘透明度逐渐降低
### 其它参数
* Brightness+: 亮度增加
* Count-: 粒子数减少
* LifeTime+: 粒子寿命增加
* LifeTime-: 粒子寿命减少
* Size+: 粒子大小增加
* PosNoise+: 粒子位置随机偏移
* Rotate+: 粒子旋转(逆时针)
* RotateNoise+: 粒子旋转随机偏移
* Restart: 清空缓存, 使用ray渲或ikBokeh时, 上完材质后, 将该值调成1, 等个1秒钟, 然后恢复成0, 不要K帧
