# ottoToon Ver 1.0

此 MME 由 ElyMeteor 制作，因操作简单「轮椅」（即极易上手），故命名为 ottoToon【禁止转载/二配】

## 使用方法

载入【ExcellentShadow2】之后，在 Main 栏给人物附上 Main.fx 材质，并展开模型子集，分别给：

- 皮肤附上 Skin.fx
- 面部附上 Face.fx
- 头发附上 Hair.fx
- 眼睛附上 Eye.fx
- 金属材质附上 Metal.fx
- 丝袜附上 Stocking 文件夹中的 BlackStocking.fx（适用深色丝袜）或 WhiteStocking.fx（适用浅色丝袜）

## 注意事项

此 MME 使用 Alternativefull(less) 制作，有参考其它 Toon 渲染，禁止商业化使用。

如果你使用了【ExcellentShadow2】，那么请在借物表中加上【そぼろ】的名字。

请遵守此 ReadMe 文件以及【ExcellentShadow2】里的 ReadMe 文件。

使用时请在借物表写上 ElyMeteor/less
