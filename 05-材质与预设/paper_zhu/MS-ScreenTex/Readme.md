#MS-ScreenTex#

    版本 1.0.0
    
##使用方法:
* 载入MS-ScreenTex.x,将其放为附件最上层
* 使用附件操作栏控制效果

###效果控制
* Si控制红点闪烁频率，数值代表每秒闪烁次数
* Tr控制电量，1-100% 0.83-83% 0.31-31% 0.01-1%
** 其中电量为1%时，会自动闪烁，Ry控制闪烁频率，数值代表每秒闪烁次数
