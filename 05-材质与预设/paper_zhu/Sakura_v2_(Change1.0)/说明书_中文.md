# --樱吹雪效果_ver2--

随着 TexSnowLite 的公开，作为改変效果的樱花也进行了版本升级。

- 作者：ビームマンP（ロベリア / Robelia）
- 改変来源：TexSnowLite.fx（そぼろ 様）

## -基本用法-

**MMD**

1. 载入 Sakura_v2.x。总之这样应该就会飘落了。
2. 载入 Controller_0.pmd。
3. 用控制器的 X、Z 坐标决定风向，并从表情（モーフ）进行各种设置。
4. 把 Sakura.x 的影子（影）打开，就会显示影子。

・备注
变更「速度」表情时整体会闪烁，这是计算上的规格。
请在场景转换等时候巧妙地掩饰过去。

## -应用性用法-

改写 sakura.png，就可以用于其他演出。
那种情况下，请把左上、右上、左下、右下这 4 种图像全部改写。

**MMM**

请载入 .fx，而不是 Sakura_v2.x。
另外，MMM 版的影子功能无法运行……
