# SoftSmoke

由闪闪发光特效改造而成的烟雾特效

- 作者：ビームマンP
- 改造来源：TexSnowLite.fx（そぼろ 氏）

## 基本用法

1. 读取 SoftSmoke.x。先用这个应该就能出效果。
2. 读取 SS_Controller_0.pmx。
3. 读一下 コントローラ用オススメ設定.vmd（控制器推荐设置）可能会不错。
4. 用控制器的 X,Z 坐标控制风向，通过表情 morph（表情变形）进行各种设置。

## 备注

更改「速度」morph 时整体会闪烁，这是计算上的规格。
请在场转换等时候好好掩饰过去。
