# SeriousShaderM.fx v0.21 【Shader 3 以后】

## 【约定】

无法提供任何保证，请自行负责使用。

使用了以下代码。
- 大元（基础来源）：full.fx（舞力介入P）
- 软阴影：SpotLight2（そぼろ 氏）
- Mipmap 各向异性过滤：MipmapTexture & AnisotropicFilter（Furia 氏）

## 【概要】

这是改变 MMD 氛围的效果（着色器）。
MMD 标准为了表现出动画风格的画面，会让漫反射（Diffusion）计算溢出等等，从而尽量不让画面产生立体感。
这个着色器通过认真地做那些计算，来产生立体感。

1) 正常地进行兰伯特（Lambert）光照计算。（MMD 标准中压缩到近 70 度）
2) 在带有自阴影的地方也保留兰伯特光照计算。
3) 加入来自光源反方向的较弱光照。
4) 模仿皮下散射，让与视线平行的面稍微变亮。

通过进行以上处理，让法线的影响始终显现出来。

`SeriousShaderM.fx` 是把 Mipmap、各向异性过滤合并到 `SeriousShader.fx` 中的版本。
会变得更重。

另外，搭载了软阴影（9 点采样 VSM）。

## 【使用方法】

请把 `SeriousShader.fx`（或 `SeriousShaderM.fx`）分配给模型。
从[MMEffect]菜单选择[效果分配]，在对话框中选中模型，然后分配效果文件。

## 【效果的自定义】

改写 `SeriousShader.fx` 开头附近的内容，即可调整参数。

### <共通>

`#define ShadowDarkness 0.6`　// 自阴影的最大暗度
自阴影的浓淡程度。
把这个数值调小，自阴影中的立体感会变淡，并产生浓重的自阴影。

`#define UnderSkinDiffuse 0.2`　// 皮下散射
这是相对于视线，把多么平行的面变亮的数值。
调大后，即使是与视线垂直的面也会变亮。

`#define ToonPower 1.5`　// 阴影的暗度
在 MMD 标准中，模型阴影最暗的部分由色调色（Toon 色）指定。
这是它的影响程度。数值调大后，阴影最暗的部分会变得更暗。为 1 时与 MMD 标准差不多。

`#define OverBright 1.2`　// 冒着白化的危险把画面调亮。
这是把因颜色变浓而容易变暗的图像强行调亮的参数。
有白化（变成纯白、色彩变淡）的可能，所以最好不要调得太大。

### <仅 SeriousShaderM.fx>

`#define TEXBUFFWIDTH 512`
`#define TEXBUFFHEIGHT 512`
这是用于改善质感的贴图缓冲。
使用比 512x512 更大的贴图时，请根据需要调大。
调得太大就会很重。

### <共通>

```
// ソフトシャドウ 補正係数
#define SOFTSHADOW_DISTANCE 0.1	// ソフトシャドウを打ち切る距離(小さいほど遠い)
#define SOFTSHADOW_THRESHOLD 0.0005 // ソフトシャドウ補正値 大きいほど影が薄い
```
`SOFTSHADOW_DISTANCE`：截断软阴影的距离（越小越远）
`SOFTSHADOW_THRESHOLD`：软阴影修正值，越大阴影越淡

```
// シャドウマップサイズ
#define SHADOWMAP_WIDTH 2048
#define SHADOWMAP_HEIGHT 2048
```
使用 Ctrl-G 的高精细自阴影时，请设为 4096。
