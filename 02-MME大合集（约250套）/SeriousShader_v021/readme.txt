【概要】
MMDの雰囲気を変えるエフェクト(シェーダ）です。
MMD標準では、アニメ調の絵柄を出すために、ディフュージョン計算をオーバーフローさせるなどして、あまり立体感を出さないようにしています。
このシェーダは、それらの計算を真面目にやることで、立体感を出すようにしています。

1) ランパート照明の計算を普通にやる。(MMD標準では70度近くまで潰している)
2) セルフシャドウの掛かっているところでも、ランパート照明計算を残す。
3) ライトの逆方向からの光を弱めに加える。
4) 皮下散乱を模して、視線に平行な面をやや明るくする。

などを行い、常に法線の影響が出るようにしました。

SeriousShaderM.fxは、SeriousShader.fxにMipmap、異方性フィルタをマージしたものです。
重くなります。

また、ソフトシャドウ(9点サンプリングVSM)を搭載しました。

【使い方】
モデルにSeriousShader.fx(または、SeriousShaderM.fx)を割り当ててください。
[MMEffect]メニューから、[エフェクト割当]を選び、ダイアログ上でモデルを選択して、エフェクトファイルを割り当てます。

【エフェクトのカスタマイズ】
SeriousShader.fxの先頭付近を書き換えることで、パラメータの調整ができます。

<共通>
#define ShadowDarkness 0.6		// セルフシャドウの最大暗さ
セルフシャドウの濃さです。
この数値を小さくすると、セルフシャドウの中の立体感が薄れ、濃いセルフシャドウがでます。

#define UnderSkinDiffuse 0.2	// 皮下散乱
視線に対し、どのくらい平行な面を明るくするかの数値です。
大きくすると、視線に垂直な面でも明るくなります。

#define ToonPower	1.5			// 影の暗さ
MMD標準では、モデルの影の一番くらい部分は、トーン色で指定します。
これの影響度合いです。数値を大きくすると、影の一番暗い部分がもっと暗くなります。1でMMD標準と同じくらいです。

#define OverBright	1.2			// 白飛びする危険性をおかして明るくする。
色を濃くすることで暗くなりがちな画像を、無理矢理明るくするパラメータです。
白飛び(真っ白になってしまって、色味が薄れる)する可能性がありますので、あまり大きくしないほうが良いかと。

<SeriousShaderM.fxのみ>
#define TEXBUFFWIDTH 512
#define TEXBUFFHEIGHT 512
質感改善用のテクスチャバッファです。
512x512よりも大きなテクスチャをお使いの場合、必要に応じて大きくしてください。
大きくし過ぎると重いです。

<共通>
// ソフトシャドウ 補正係数
#define SOFTSHADOW_DISTANCE 0.1	// ソフトシャドウを打ち切る距離(小さいほど遠い)
#define SOFTSHADOW_THRESHOLD 0.0005 // ソフトシャドウ補正値 大きいほど影が薄い

// シャドウマップサイズ
#define SHADOWMAP_WIDTH 2048
#define SHADOWMAP_HEIGHT 2048
Cntrol-Gで、高精細セルフシャドウをお使いの場合は、4096にしてください。
