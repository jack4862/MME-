# Wind_v2

作者：ビームマンP

## 使用方法

这是 Wind 的版本升级版。
绘制结果有少许变化，所以按喜好分别使用可能会不错。

### 新功能

追加了控制器（WindController_0.pmd）。
可通过控制器内的表情 morph，或各设置名骨骼的 X 坐标来控制参数。

作为示例，同梱了已设置好的数据。
- 表情 morph 用（WindCont_MorphSample.vmd）
- 骨骼用（WindCont_BoneSample.vpd）

请以这些为基础，去寻找自己喜欢的设置。
