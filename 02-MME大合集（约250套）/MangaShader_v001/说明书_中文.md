# MangaShader.fx ver0.0.1

把模型变成漫画风画面的着色器效果。
由舞力介入P氏的 full 修改制作而成。

## 使用方法

1. 对 PMD 或配件应用 MangaShader.fx。
   - GUI 的情况：从「MMEffect」→「エフェクト割当」（效果分配）的主标签页，给想应用的对象分配 MangaShader.fx。
   - 以文件名设定的情况：把 XXXXX.pmd 改为 XXXXX[MangaShader.fx].pmd，或者把 MangaShader.fx 改名为 XXXXX.fx 后载入。
2. 根据需要适当修改 MangaShader.fx 开头的参数。

本 FX 中自行进行了边缘（エッジ）的独立绘制：

- 配件 → 对非半透明的全部材质进行独立绘制
- PMD・PMX → 自阴影 ON 时使用 MMD 标准边缘绘制，自阴影 OFF 时使用 MMD 标准边缘绘制＋独立绘制

漫画风绘制时，模型材质中设为边缘 OFF 的地方也进行边缘绘制会更有那种感觉，所以请视情况切换自阴影 ON/OFF。
边缘设置得粗一些，我想会更有氛围。
