# rain/readme.txt

这是 MikuMikuEffect（ http://www.nicovideo.jp/watch/sm12149815 ）用的 fx 文件。需要 MME。

由 AMD RenderMonkey 1.82 的 "FireParticleSystem" rfx 文件转换并编辑而成。

如果需要更改参数，请在 fx 文件内修改：

```
<
   string UIName = "particleSystemXXXXXX";
   string UIWidget = "Numeric";
   bool UIVisible =  true;
   float UIMin = 0.00;
   float UIMax = 2.00;
> = float( NN );
```

修改 ( NN ) 处的 float 数值。

Enjoy!（祝使用愉快！）
