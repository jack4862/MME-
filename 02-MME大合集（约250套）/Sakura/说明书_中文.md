# 樱花吹雪效果（桜吹雪エフェクト）

作者：ビームマンP（ロベリア）
改编源：TexSnow.fx（そぼろ 氏）

## 基本用法

1. 读取 Sakura.x。这样姑且应该就会飘落了。
2. 读取 Controller_0.pmd。
3. 用控制器的 X、Z 坐标设定风向，用表情 morph 进行各种设置。
4. 把 Sakura.x 的阴影（影）打开就会显示阴影。但很吃性能。使用请有计划地来。
5. 粒子的最大数量在 Sakura.fx 内：

   ```
   #define CLONE_NUM 1024
   ```

   改写这里即可设定。
   最大初始状态为 4096。

### 备注

修改「速度」morph 时整体会闪烁，这是计算上的规格。
请在场影转换等时候巧妙地糊弄过去。

## 进阶用法

改写 sakura.png 也可以用于其他演出。
这种情况下，请把左上、右上、左下、右下 4 种图片全部改写。

## 「它不动！」的情况

把 Sakura.fx 内的

```
//乱数テクスチャ
texture2D rndtex <
    //string ResourceName = "random2048.bmp";
    string ResourceName = "random4096.bmp";
>;
```

改成

```
texture2D rndtex <
    string ResourceName = "random2048.bmp";
    //string ResourceName = "random4096.bmp";
>;
```

试试。
