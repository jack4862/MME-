***********************【概要】******************
景観アクセサリ(街クラスのアクセサリ)に特化した質感向上シェーダです。

1.景観アクセサリの樹木(テクスチャで葉を描いた物)の木陰を演出します。
  (α抜きテクスチャや材質に対応したセルフシャドウを描画します)
2.柔らかい影を演出します。(セルフシャドウをソフトシャドウ化します)
3.モアレを防止し、遠景のテクスチャを滑らかにします。
  (テクスチャの描画に異方性フィルタとMipmapを適用します。)
4.空気遠近法(遠くのものが霞んで見える)を用い、距離感を演出します。
  (MMD照明色に連動した距離フォグを描画します。)

グラフィックボードに相応の負荷を掛けますので、必要であればお使いのグラフィックボードの性能に合わせて、後述の設定を行ってください。
ソフトシャドウや距離フォグを使わなければ、シェーダ2でも動作するかと思います。

**********************【使い方】*****************
まず、ShadowMap.xを読み込み、風景などのアクセサリにDetailup_for_Landscape.fxを、モデルなどにModel_on_Landscape.fx、Serious_on_Landscape.fx、Brushed_on_Landscape.fxを適用してください。
[MMEffect]メニューから、[エフェクト割当]を選択し、エフェクト割当ダイアログを表示します。
[Main]タブで、風景などのオブジェクト(モデルやアクセサリ)を選択し、Detailup_for_Landscape.fxをドラッグ&ドロップします。
近距離のキャラクタなどにはModel_on_Landscape.fx等をドラッグ&ドロップします。
必要なだけ、エフェクトファイルを割り当てたら、OKボタンを押してください。

Bruhsed_on_Landscape.fxに関しては、材質毎に違うパラメータで適用したいかもしれません。
Brushed_on_Landscape.fxを材質単位で適用する場合について説明します。

まず、モデルをPMDエディタで開いて、起毛させたい材質の番号を確認します。
PMDエディタの材質タブや、PMDViewの[表示]-[頂点/材質マスキング]で、どの材質を起毛させたいか確認します。

次にMMDにモデルを読み込み、[MMEffect]-[エフェクト割当]の[Main]タブで、モデルを選択。右クリック-[サブセット展開]を選びます。
そのモデルの材質がsubset#(材質番号)で並びますので、先ほど確認した起毛させたい材質番号を選び、Brushed_on_Landscape.fxをドラッグ＆ドロップします。
これでその材質は起毛したように表示されるはずです。
OKボタンを押して、エフェクト割当ウィンドウを閉じてください。

この操作は、pmm(MMDのプロジェクト)上には記録されませんので、別に保存する必要があります。
エフェクト割当ダイアログ上の[ファイル]メニューから、[設定を保存]を選択し、オブジェクトに割当てたエフェクトを保存します。

これらの操作が終わったら、アクセサリに合わせて、ShadowMap.xのTrを設定します。
ShadowMap.xのTrは、影が映る最小値のアルファ値です。
Tr=1なら、完全不透明なもの以外全て影を落としません。
Tr=0なら、通常通り。完全透明でも影が落ちます。

景観アクセサリの大きさに合わせて、ShadowMap.xのX、Z、Siを設定します。
ShadowMap.xのXは、フォグが出ない距離です。
ShadowMap.xのZは、それ以上遠くは霞んで見えないという距離です。
ShadowMap.xのSiは、MMD照明に対するフォグの明るさです。
霞具合を弱めるには、ShadowMap.xのZを例えば20万にするなど極端な数値にするとよいでしょう。
また、フォグの出る範囲が0とか、マイナスになると、フォグが出ません。

MMDのセルフシャドウ距離などの設定も、シーンに合わせて使ってください。

*****************【ファイルの説明】**************
ShadowMap.x/ShadowMap.fx
シャドウマップです。pmmにひとつだけ置いてください。
(OFFSCREENRENDERTARGETを使って、シャドウマップを作っています。)
ShadowMap.xのTrで、影が映る最小値のアルファを設定できます。
Tr=1なら、完全不透明なもの以外全て影を落としません。
Tr=0なら、通常通り。完全透明でも影が落ちます。
また、機能的にはDetailUp_for_Landscape.fx側で持っていますが、距離フォグの設定もShadowMap.xのX,Y,Siで制御します。

ShadowDraw.fx
ShadowMap.fxから呼び出されるエフェクトで、シャドウマップを描画しています。
操作の必要はありません。

Detailup_for_Landscape.fx
異方性フィルタやミップマップを適用し、ShadowMap.fxのシャドウマップを使って影などを描画します。
また、透過素材の透過率で描画を打ち切り、所謂紳士枠効果(描画順序によって、半透明素材の後ろにある見えるべきオブジェクトが見えなくなる現象)を軽減します。
樹木などで半透明素材が複数集まっているような場合に、ミップマップを適用すると顕著に意図しない紳士枠効果が現れてしまうことがあります。
これの軽減策です。
遠景では効果的ですが、近景では違和感が出ます。

Model_on_Landscape.fx
異方性フィルタやミップマップを適用し、ShadowMap.fxのシャドウマップを使って影などを描画します。
Detailup_for_Landscape.fxとの違いは、透過素材の透過率では描画を打ち切らないことです。

Serious_on_Landscape.fx
Model_on_Landscape.fxをベースに、SeriousShader.fxをマージしました。
SeriousShader.fxは多少暗くなりますが、セルフシャドウの中でも多少の立体感を出し、照り返しを表現します。

Brushed_on_Landscape.fx
Model_on_Landscape.fxをベースに、Brushed.fxをマージしました。
Brushedは、服などに適用すると、起毛したかのような描画を行います。
肌に適用すると柔らかな感じが出るかもしれません。

config.h
後述の調整のためのパラメータを集めた部分です。

********【エフェクトファイルの書き換え-全般】*********
ver0.3から、全般の調整用のパラメータをconfig.hに集めました。
但し、config.hはMMEの自動更新には対応できませんので、書き換えた後は、[MMEffect]メニューの[全て更新]を選択してください。

// シャドウマップのサイズ
#define SHADOWMAP_WIDTH 2048
#define SHADOWMAP_HEIGHT 2048

シャドウマップのサイズを小さくすると、グラフィックボードの負荷が下がり、VRAMの使用量が下がります。その代わり、セルフシャドウが荒くなります。
グラフィックボードの負荷が上がることを覚悟の上なら、サイズを大きくすることもできます。その分細かい影を出せます。


// テクスチャバッファのサイズ(Mipmap/異方性フィルタ用)
#define TEXBUFFWIDTH 512
#define TEXBUFFHEIGHT 512

質感向上のためのテクスチャバッファのサイズです。
512x512よりも大きなテクスチャをお使いの場合、テクスチャが一旦縮小されてしまうことになります。
これを回避するためには、このサイズを大きくすると良いでしょう。
但し、その分重くVRAMを使用するようになります。


// 透過素材の透過率が高いものを切り捨てる割合 (1-255)
#define AlphaClipLimit 128

透過素材のうち、透過率の高い物を切り捨てることで、樹木などの描画順序による背後の透過を軽減します。
1～255の数値で、大きいほど切り捨てる割合が大きくなります。


///////////////////////////////////////////////
// ソフトシャドウのアルゴリズム
#define SOFTSHADOW_NONE 0		// ソフトシャドウなし
#define SOFTSHADOW_VSM_SMALL 1	// 9点 VSM ソフトシャドウ
#define SOFTSHADOW_VSM_LARGE 2	// 30点 VSM ソフトシャドウ
#define SOFTSHADOW_PCF_SMALL 3	// 9点 PCF ソフトシャドウ
#define SOFTSHADOW_PCF_UNJAGGY 4 // 4点近傍 PCF ジャギー軽減

// 上記の何れかを選択
#define SOFTSHADOW SOFTSHADOW_VSM_SMALL

ソフトシャドウ化をどの手法で行うかという設定です。
#define SOFTSHADOW SOFTSHADOW_PCF_SMALL
とすれば、PCF方式9点サンプリングで、ソフトシャドウを行います。

#define SOFTSHADOW SOFTSHADOW_NONE
とすると、ソフトシャドウを行いません。
距離フォグを使わなければ、この時に限り、シェーダバージョン2でも動作します。

VSM方式は、セルフシャドウを「影を落とすもの」と「影を表示するもの」の距離で影の濃さを計算します。
(1)シャドウマップの解像度を超えて綺麗にぼかします。
(2)２つの影が重なったとき、遠い方の距離を選択します。この結果、影の中により濃い影が表示されることがあります。
(3)顔にかかる髪の毛の影など、影を落とす物との距離が近いと薄い影になります。

PCF方式は、近隣の影との平均値で影の濃さを計算します。
(1)シャドウマップの解像度で、アンチエイリアスを掛けたような影ができます。シャドウマップの解像度の影響を、そのまま受けます。
(2)VSM方式のような影の中の影はできず、影を落とすものとの距離が近いことで薄くなったりもしません。
SOFTSHADOW_PCF_UNJAGGY(4点近傍)に関しては、実験途中でありSOFTSHADOW_NONEのほうがマシという感じです。

//////////////////////////////
// ソフトシャドウ 補正係数
#define SOFTSHADOW_DISTANCE 0.1	// ソフトシャドウを打ち切る距離(小さいほど遠い)
#define SOFTSHADOW_THRESHOLD 0.0005 // ソフトシャドウ補正値 大きいほど影が薄い

ソフトシャドウを用いた場合、特にセルフシャドウモード２の場合に、遠方で不自然な影ができてしまうことがあります。
（影がないはずのところに、100%ではない影が表示されることがあります）
遠方の影をソフトシャドウ化しても効果が薄い為、遠距離ではソフトシャドウの計算を打ち切ったほうがより自然な表現になります。
この打ち切りの距離が、SOFTSHADOW_DISTANCEです。
MMDのセルフシャドウ距離設定に連動して計算しますが、小さいほど遠いところまでソフトシャドウを掛けます。

ソフトシャドウは、影の縁がぼやけることで、結果的に「大きな影」に見えますし、影がないはずのところでも影ができてしまうことがあります。
これを緩和するために、SOFTSHADOW_THRESHOLDで、ソフトシャドウの計算に補正をかけ、影を薄くできにくくしています。
大きいほど、影ができにくくなりますが、不自然な形になりやすくなります。


///////////////////////////////////////////////
// テクスチャの透過を固定したい場合
// 以下をコメントを解除。(行頭の"// "を取る)
//#define ShadowMinTr 0.99

景観アクセサリに適するShadowMap.fxのTr値を毎回入力するのも大変なので、使用する景観アクセサリに合わせて固定にすることができます。
例えば、良さそうなTr値が0.98だと分かったならば、以下のように書き換えます。
#define ShadowMinTr 0.98

///////////////////////////////////////////////
// 距離フォグ関係
#define FOG_ENABLE 1 // 1:フォグを有効にする 0:フォグを無効にする

距離フォグを無効にしたい場合(グラフィックボードの負荷を下げたいなど)、この数値を0にしてください。
また、距離フォグとソフトシャドウを無効にすれば、シェーダ2.0でも動作します。

#define FOG_CONTROLER "ShadowMap.x"  // フォグ制御用コントローラ名

距離フォグのコントローラ名です。
ShadowMap.xの名称を変更したり、別のアクセサリを使って距離フォグを制御したい場合は、変更してください。

///////////////////////////////////////////////
// フォグの値を固定したい場合
// 以下のコメントを解除。(行頭の"// "を取る)
//#define FOG_BRIGHT 1.0 // フォグの明るさ(MMD照明に対する割合)
//#define FOG_NEAR 500.0   // フォグの無い距離
//#define FOG_FAR 15000.0 // これ以上遠くはフォグだらけで見えないという距離
//#define FOG_COLOR float3(0.3, 0.3, 0.3) // フォグの色 (定義すると、MMD照明との連動がはずれる

景観アクセサリに適するShadowMap.fxのX,Y,Sizを毎回入力するのも大変なので、使用する景観アクセサリに合わせて固定にすることができます。
また、フォグの色をMMDの照明連動ではなく、自由に設定したい場合は、FOG_COLORを定義することで、固定にすることができます。

********【エフェクトファイルの書き換え-Serious_on_Landscape.fx】*********
Serious_on_Landscape.fxの説明です。
パラメータはSeriousShader.fxと同様です。
Serious_on_Landscape.fxの先頭近辺にあるパラメータを書き換えてください。

#define ShadowDarkness 0.7		// セルフシャドウの最大暗さ
セルフシャドウの濃さです。
この数値を小さくすると、セルフシャドウの中の立体感が薄れ、濃いセルフシャドウがでます。

#define UnderSkinDiffuse 0.2	// 皮下散乱
視線に対し、どのくらい平行な面を明るくするかの数値です。
大きくすると、視線に垂直な面でも明るくなります。

#define ToonPower	1.5			// 影の暗さ
MMD標準では、モデルの影の一番くらい部分は、トーン色で指定します。
これの影響度合いです。数値を大きくすると、影の一番暗い部分がもっと暗くなります。1でMMD標準と同じくらいです。


********【エフェクトファイルの書き換え-Brushed_on_Landscape.fx】*********
Brushed_on_Landscape.fxの説明です。
パラメータはBrushed.fxと同様です。
Brushed_on_Landscape.fxの先頭付近にあるパラメータを書き換えてください。

#define TargetMaterial "0-"		// 対象となる材質
エフェクト割り当てを用いる場合、特に変更する必要はありませんが、モデルに固有のエフェクトとしてカスタマイズする場合は、材質番号を記述してください。
基本的に","区切りで材質番号を並べます。連続する材質番号は、"-"で範囲を指定できます。
6番、9番、10番、11番、12番、20番を指定する場合
#define TargetMaterial "6,9-12,20"
とします。

//#define SkinColor float3(0.3,0.3,0.3)		// 地肌の色 定義しなければ材質・テクスチャの色 RGB
地肌の色です。
行頭に//をつければ、無指定ということで材質・テクスチャの色になります。
この場合は、FurColorを設定してください。
白系の材質は、SkinColorを暗めの色で指定するとよいでしょう。

#define FurColor float3(1,1,1)	// 毛の色 定義しなければ材質・テクスチャの色 RGB毛の色です。
行頭に//をつければ、無指定ということで材質・テクスチャの色になります。
この場合は、SkinColorを設定してください。
通常はこちらを白系の色に設定すると、淡い感じになります。

#define FurPower 0.2			// 毛の長さ?
毛の長さというか、毛の見える量です。
SkinColorを暗めの色で指定した場合、この値が小さいと真っ黒に見えます。
SkinColorを指定する場合10程度、FurColorを指定する場合0.1程度が良いかと思います。
