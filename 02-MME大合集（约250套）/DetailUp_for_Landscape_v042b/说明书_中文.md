# 改造版 full.fx v1.2 ～MipmapTexture＆AnisotropicFilter&TextureAlphaClippingShadowMap～ by Furia

## 利用规约

　从 舞力介入P 大人那里借用了 full.fx。
　使用之际，在参考来源的源码作者以及我均不承担责任、
　且在自己的责任下使用的情况下，不会追加上述以外的限制。

## 必需条件

　能够使用自阴影
　MMEffect 0.22 以上
　　※用于生成 mipmap。

## 概要

　从播放的第 2 帧起，贴图的 Alpha 值会反映到自阴影上。
　这是使用了 mipmap 与各向异性过滤的 full.fx。
　只要应用，就会感觉远处细节提升＆摩尔纹减轻。

　载入同捆的 x 文件，切换效果的 on/off 来试试，会比较容易看出效果程度。

## 使用方法

　在 MME 的 GUI 上展开子集（サブセット）后，只对想应用的子集进行应用。

## 内部规格

　・mipmap 的生成方法
　　自 MME v0.22 起，渲染目标贴图也会生成 Mipmap，所以
　　通过在贴图描画前渲染到缓冲区来生成 Mipmap。

　・贴图分辨率
　　全部展开为 512*512 尺寸。
　　因为每次都会生成，所以使用效果时的内存消耗不会超过 1 张的量。

　　如果使用了 512*512 以上分辨率的贴图，大概细节会有些被压扁。

　・用 TextureAlpha 对自阴影进行抠图
　　在播放的第 1 帧，贴图的复制尚未进行，感觉 ZProt 时无法参照 Texture。
　　因此从第 2 帧起才会进行抠图。
　　（在 MME 上载入 Texture 的情况下不限于此，但出于便利性没有采用）
　　另外，由于需要参照上一次描画时的数据，大概不按材质单位应用的话会出现故障。

# DetailUp_for_Landscape.fx v0.42b【MME0.23 以后，着色器 3 以后】

## 【约定】

允许使用、再配布、改造、改造物的再配布。
一概不提供任何保证，请自行负责使用。

使用了 full.fx（舞力介入P）、full+TexAlphaClipShadow.fx（Furia 氏）以及 SpotLight.fx（そぼろ氏）的代码。已将 full+TexAlphaClipShadow.fx 附带的 Readme.txt 作为 Readme_Furia.txt 一并附上，请参阅。

## 【概要】

这是专门面向景观 Accessory（城市级别的 Accessory）的质感提升着色器。

1. 为景观 Accessory 的树木（用贴图绘制叶子的物体）营造树荫。
   （绘制对应 α 剔除贴图或材质的自阴影）
2. 营造柔和的阴影。（将自阴影软阴影化）
3. 防止摩尔纹，使远景贴图变得平滑。
   （在贴图绘制中应用各向异性过滤与 Mipmap。）
4. 使用空气透视法（远处的东西看起来朦胧），营造距离感。
   （绘制与 MMD 照明色联动的距离雾。）

会给显卡带来相应负载，如有需要，请配合所用显卡的性能进行后述的设定。若不使用软阴影与距离雾，我想着色器 2 也能运行。

## 【使用方法】

首先，载入 ShadowMap.x，对风景等 Accessory 应用 Detailup_for_Landscape.fx，对模型等应用 Model_on_Landscape.fx、Serious_on_Landscape.fx、Brushed_on_Landscape.fx。

从 [MMEffect] 菜单选择 [效果分配]，显示效果分配对话框。
在 [Main] 标签中，选择风景等对象（模型或 Accessory），将 Detailup_for_Landscape.fx 拖放上去。
对近景的角色等，拖放 Model_on_Landscape.fx 等。
按需分配效果文件后，按下 OK 按钮。

关于 Bruhsed_on_Landscape.fx，可能有人想按材质用不同的参数来应用。
下面说明按材质单位应用 Brushed_on_Landscape.fx 的方法。

首先，用 PMD 编辑器打开模型，确认想要起毛的材质编号。
通过 PMD 编辑器的材质标签，或 PMDView 的 [显示]-[顶点/材质遮蔽]，确认想让哪个材质起毛。

接着将模型载入 MMD，在 [MMEffect]-[效果分配] 的 [Main] 标签中选择模型。右键-[子集展开]。
该模型的材质会以 subset#（材质编号）的形式排列出来，因此选择刚才确认的想要起毛的材质编号，拖放 Brushed_on_Landscape.fx。
这样该材质应该就会显示为起毛的样子。
按下 OK 按钮，关闭效果分配窗口。

此操作不会被记录到 pmm（MMD 的工程）中，因此需要另行保存。
从效果分配对话框上的 [文件] 菜单选择 [保存设定]，保存已分配给对象的效果。

这些操作结束后，配合 Accessory 设定 ShadowMap.x 的 Tr。
ShadowMap.x 的 Tr 是阴影会映照的最小 alpha 值。
Tr=1 时，除完全不透明的东西以外全都不投下阴影。
Tr=0 时，与通常一样。完全透明也会投下阴影。

配合景观 Accessory 的大小，设定 ShadowMap.x 的 X、Z、Si。
ShadowMap.x 的 X 是不产生雾的距离。
ShadowMap.x 的 Z 是超过该距离就朦胧看不远的距离。
ShadowMap.x 的 Si 是相对于 MMD 照明的雾的亮度。
要减弱朦胧程度，可将 ShadowMap.x 的 Z 设为例如 20 万这样的极端数值。
另外，若产生雾的范围为 0 或为负数，则不产生雾。

MMD 的自阴影距离等设定也请配合场景使用。

## 【文件的说明】

### ShadowMap.x/ShadowMap.fx

这是阴影贴图。请在 pmm 中只放置一个。
（使用 OFFSCREENRENDERTARGET 来制作阴影贴图。）
可通过 ShadowMap.x 的 Tr 设定阴影会映照的最小 alpha。
Tr=1 时，除完全不透明的东西以外全都不投下阴影。
Tr=0 时，与通常一样。完全透明也会投下阴影。
另外，功能上虽然由 DetailUp_for_Landscape.fx 侧持有，但距离雾的设定也通过 ShadowMap.x 的 X,Y,Si 控制。

### ShadowDraw.fx

这是从 ShadowMap.fx 调用的效果，负责绘制阴影贴图。
无需进行操作。

### Detailup_for_Landscape.fx

应用各向异性过滤与 Mipmap，并使用 ShadowMap.fx 的阴影贴图绘制阴影等。
此外，会按透明素材的透过率截断绘制，减轻所谓的绅士框效应（因绘制顺序，本应可见的半透明素材后方的物体变得看不见的现象）。
在树木等半透明素材大量聚集的情况下，应用 Mipmap 有时会显著出现非预期的绅士框效应。
这是其减轻对策。
在远景中有效，但在近景中会产生不协调感。

### Model_on_Landscape.fx

应用各向异性过滤与 Mipmap，并使用 ShadowMap.fx 的阴影贴图绘制阴影等。
与 Detailup_for_Landscape.fx 的区别在于不会按透明素材的透过率截断绘制。

### Serious_on_Landscape.fx

以 Model_on_Landscape.fx 为基础，合并了 SeriousShader.fx。
SeriousShader.fx 会稍微变暗，但在自阴影中也能表现出一定的立体感，并表现反照。

### Brushed_on_Landscape.fx

以 Model_on_Landscape.fx 为基础，合并了 Brushed.fx。
Brushed 应用到衣服等上时，会进行仿佛起毛了一般的绘制。
应用到肌肤上或许能表现出柔和的感觉。

### config.h

这是汇集了后述调整用参数的部分。

从 ver0.3 起，将全般调整用的参数汇集到了 config.h。
但 config.h 无法对应 MME 的自动更新，因此在改写之后，请选择 [MMEffect] 菜单的 [全部更新]。

　　// 阴影贴图的大小
　　#define SHADOWMAP_WIDTH 2048
　　#define SHADOWMAP_HEIGHT 2048

减小阴影贴图的大小会降低显卡负载、减少 VRAM 使用量。代价是自阴影会变粗糙。
如果做好显卡负载上升的心理准备，也可以增大尺寸。相应地能产生更细致的阴影。

　　// 贴图缓冲的大小（Mipmap/各向异性过滤用）
　　#define TEXBUFFWIDTH 512
　　#define TEXBUFFHEIGHT 512

这是用于提升质感的贴图缓冲大小。若使用比 512x512 更大的贴图，贴图会先被缩小一次。要避免这一点，将此尺寸调大即可。但相应地会更重、占用更多 VRAM。

　　// 截断透过率较高的透明素材的比例 (1-255)
　　#define AlphaClipLimit 128

通过截断透明素材中透过率较高的部分，减轻树木等因绘制顺序导致的后方透出。为 1～255 的数值，越大则截断的比例越大。

　　///////////////////////////////////////////////
　　// 软阴影的算法
　　#define SOFTSHADOW_NONE 0		// 无软阴影
　　#define SOFTSHADOW_VSM_SMALL 1	// 9 点 VSM 软阴影
　　#define SOFTSHADOW_VSM_LARGE 2	// 30 点 VSM 软阴影
　　#define SOFTSHADOW_PCF_SMALL 3	// 9 点 PCF 软阴影
　　#define SOFTSHADOW_PCF_UNJAGGY 4 // 4 点邻近 PCF 减轻锯齿

　　// 选择上述任一项
　　#define SOFTSHADOW SOFTSHADOW_VSM_SMALL

这是设定用哪种手法进行软阴影化的。
若写成
`#define SOFTSHADOW SOFTSHADOW_PCF_SMALL`
则以 PCF 方式 9 点采样进行软阴影。

若写成
`#define SOFTSHADOW SOFTSHADOW_NONE`
则不进行软阴影。
只要不使用距离雾，仅在此情况下着色器版本 2 也能运行。

VSM 方式是用「投下阴影的东西」与「显示阴影的东西」的距离来计算阴影的浓度。
(1) 可以超出阴影贴图的分辨率进行漂亮的模糊。
(2) 两个阴影重叠时，选择较远的距离。其结果是阴影中有时会显示更浓的阴影。
(3) 像落在脸上的头发阴影那样，与投下阴影的东西距离较近时，阴影会变淡。

PCF 方式是用邻近阴影的平均值计算阴影的浓度。
(1) 会产生以阴影贴图分辨率进行抗锯齿般的阴影。直接受阴影贴图分辨率的影响。
(2) 不会产生 VSM 方式那样的阴影中的阴影，也不会因与投下阴影的东西距离近而变淡。
关于 SOFTSHADOW_PCF_UNJAGGY（4 点邻近），尚在实验途中，给人感觉还不如 SOFTSHADOW_NONE。

　　//////////////////////////////
　　// 软阴影 补正系数
　　#define SOFTSHADOW_DISTANCE 0.1	// 截断软阴影的距离（越小越远）
　　#define SOFTSHADOW_THRESHOLD 0.0005 // 软阴影补正值 越大阴影越淡

使用软阴影时，特别是在自阴影模式 2 的情况下，远处有时会产生不自然的阴影。
（在本来不应该有阴影的地方，有时会显示并非 100% 的阴影）
由于对远处的阴影做软阴影化效果也很微弱，在远距离截断软阴影的计算会得到更自然的表现。
这个截断的距离就是 SOFTSHADOW_DISTANCE。
它与 MMD 的自阴影距离设定联动计算，但越小则到越远的地方都会施加软阴影。

软阴影由于阴影边缘变得模糊，结果看起来像「更大的阴影」，并且在本来不该有阴影的地方也可能产生阴影。为缓和这一点，用 SOFTSHADOW_THRESHOLD 对软阴影的计算施加补正，使其不容易形成淡影。
越大则越不容易产生阴影，但容易变成不自然的形状。

　　//#define ShadowMinTr 0.99

想要禁用距离雾时（例如想降低显卡负载），请将此数值设为 0。
另外，若禁用距离雾与软阴影，着色器 2.0 也能运行。

`#define FOG_CONTROLER "ShadowMap.x"  // 雾控制用控制器名`

这是距离雾的控制器名。
若要更改 ShadowMap.x 的名称，或想用其他 Accessory 控制距离雾，请修改。

## 【改写效果文件 - Serious_on_Landscape.fx】

这是 Serious_on_Landscape.fx 的说明。
参数与 SeriousShader.fx 相同。
请改写 Serious_on_Landscape.fx 开头附近的参数。

`#define ShadowDarkness 0.7		// 自阴影的最大暗度`
这是自阴影的浓度。
减小此数值，自阴影中的立体感会变淡，并出现较浓的自阴影。

`#define UnderSkinDiffuse 0.2	// 皮下散射`
这是相对于视线，使多少平行的面变亮的数值。
调大后，即使是与视线垂直的面也会变亮。

`#define ToonPower	1.5			// 阴影的暗度`
在 MMD 标准中，模型阴影最暗的部分由 Toon 色指定。
这是其影响程度。调大数值后，阴影最暗的部分会变得更暗。1 时与 MMD 标准大致相同。

## 【改写效果文件 - Brushed_on_Landscape.fx】

这是 Brushed_on_Landscape.fx 的说明。
参数与 Brushed.fx 相同。
请改写 Brushed_on_Landscape.fx 开头附近的参数。

`#define TargetMaterial "0-"		// 成为对象的材质`
使用效果分配时无需特别更改，但若作为模型固有的效果进行定制，请记述材质编号。
基本上用「,」分隔排列材质编号。连续的材质编号可用「-」指定范围。
要指定 6 号、9 号、10 号、11 号、12 号、20 号时
`#define TargetMaterial "6,9-12,20"`
这样写。

`//#define SkinColor float3(0.3,0.3,0.3)		// 地肌的颜色 若不定义则为材质・贴图的颜色 RGB`
这是地肌的颜色。
在行首加上 // 即为无指定，也就是说采用材质・贴图的颜色。
这种情况下，请设定 FurColor。
白色系材质最好用较暗的颜色指定 SkinColor。

`#define FurColor float3(1,1,1)	// 毛的颜色 若不定义则为材质・贴图的颜色 RGB` 毛的颜色。
在行首加上 // 即为无指定，也就是说采用材质・贴图的颜色。
这种情况下，请设定 SkinColor。
通常将此项设定为白色系的颜色会有淡雅的感觉。

`#define FurPower 0.2			// 毛的长度？`
与其说是毛的长度，不如说是毛可见的量。
若 SkinColor 指定为较暗的颜色，此值较小时看起来会全黑。
指定 SkinColor 时 10 左右、指定 FurColor 时 0.1 左右比较好。
