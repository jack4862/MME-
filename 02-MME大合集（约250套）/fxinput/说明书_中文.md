# fxinput.exe Ver.0.08 2011/01/05

这是用于编辑 MME 所用效果文件的工具。
可以通过拖放打开 fx 文件。

它会拾取 FX Composer 等输出的文件中的变量，并准备用于输入的变量。
可以编辑 int、float、float2、float3、float4 的值。

只对带有以下注释（annotation）记述的变量进行操作。
   `bool UIVisible =  true;`

当以下记述作为注释存在时，会显示指定颜色的对话框。
   `string UIWidget = "Color";`

以下变量是为 fxinput 准备的。

   `string UIDefault = "初始值";`
   `string UIDescription = "说明文本";`
   `string UIDefaultX = "变量指定用配件文件的初始值";`
   `string UIDescriptionX = "变量指定用配件文件的说明文本";`

`UIDefault`、`UIDefaultX` 是在执行菜单的「设为初始值」操作时被设定的值的指标。
`UIDescription`、`UIDescriptionX` 是显示在 fxinput 上变量名旁边的字符串。

`UIMin`、`UIMax`、`UIStep` 分别是最小值、最大值、步进值。
作为拖动条的动作指标。

在保存当前值的部分，请按 `<变量类型> ( <值> );` 记述。
说白了，用于寻找变量的正则表达式如下。
`"float4\s+(\w+)\s+[^<]+<([^>]+)>\s*=\s*float4\s*\(\s*([0-9\., ]+)\s*\)";`

CONTROLOBJECT 指定的格式请参照调整了 kion 先生所制作内容的效果文件「深度フォグ{Main}.fx」。
