fxinput.exe Ver.0.08 2011/01/05

MMEで用いるエフェクトファイルを編集するツールです。
ドラッグ＆ドロップでfxファイルを開く事が出来ます。

FX Composer 等が出力するファイル中にある変数を拾って入力する変数を用意します。
int float float2 float3 float4 値を編集することが出来ます。

アノテーションとして以下の記述がされた変数のみ操作を行います。
   bool UIVisible =  true;

以下の記述がアノテーションとして存在する場合、色を指定するダイアログを表示します。
	string UIWidget = "Color";

以下の変数をfxinput用として用意しました。

   string UIDefault = "初期値";
   string UIDescription = "説明文";
   string UIDefaultX = "変数指定用アクセサリファイルの初期値";
   string UIDescriptionX = "変数指定用アクセサリファイルの説明文";

UIDefault、UIDefaultX はメニューの「初期値にする」操作を行った際に設定される値の指標です。
UIDescription、UIDescriptionX は fxinput 上の変数名に添えて表示される文字列です。

UIMin、UIMax、UIStep は各々最小値、最大値、ステップ値です。
ドラッグバーの動作指標としてます。

現在の値を保持する部分では、<変数型> ( <値> ); と記述してください。
ぶっちゃけ、変数を見つけている正規表現は以下の通りです。
"float4\s+(\w+)\s+[^<]+<([^>]+)>\s*=\s*float4\s*\(\s*([0-9\., ]+)\s*\)";

CONTROLOBJECT指定の書式はkionさんが作成された物を調整したエフェクトファイル「深度フォグ{Main}.fx」をご参照ください。
