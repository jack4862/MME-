# 雾效 4 种（带控制器）

是由舞力介入P 制作的、让 MikuMikuDance 可以使用效果文件的工具。

## ●文件内容与说明

readme.txt　本文件

是 4 种施加雾（=雾气）的效果文件。
可以通过饰品（アクセサリ）设定参数。

### [深度フォグ]（深度雾）

按到视点的距离施加雾。
由于使用深度，所以会均匀地覆盖画面。
雾的分界线会成为直线，因此在旋转视点时会稍微产生违和感。

- 效果文件本体
  - 深度フォグ{Main}.fx
- 控制器用饰品
  - 深度フォグ{RGBA}.x：可用坐标 X,Y,Z,Si 分别指定 RGBA。（以 0.0～1.0 指定）
  - 深度フォグ{range}.x：可用坐标 X,Y 指定范围。（X：开始距离　Y：范围）
- 控制器用 PMD
  - 深度フォグ{RGBA}.pmd：用于动画（仅中心骨骼的模型）
  - 深度フォグ{range}.pmd
- 用于不在画面上显示控制器用饰品的效果文件
  - 深度フォグ{range}.fx
  - 深度フォグ{RGBA}.fx

  - 距離フォグ{range}.pmd
- 用于不在画面上显示控制器用饰品的效果文件
  - 距離フォグ{range}.fx
  - 距離フォグ{RGBA}.fx

## ●使用方法

请将其放入与想要应用效果的模型文件（*.pmd、*.x）相同的文件夹，并按以下方式设置名称。

・把 距離フォグ{Main}.fx 用于 miku.pmd 时

```
miku[距離フォグ{Main}.fx].pmd
距離フォグ{Main}.fx
```

或者

```
miku.pmd
距離フォグ{Main}.fx → miku.fx
```

X 文件也相同。

・关于动画

通过给 PMD 模型的骨骼设置饰品，可以进行参数变更的动画。
请使用附带的 PMD，或者设置到喜欢的 PMD 模型上使用。
位置坐标 XYZ 的每一个都被分配为参数，因此通过移动来变更参数。
根据数值不同可能会飞到奇怪的位置，所以直接输入数值比较轻松。
请从模型操作中选择 PMD 模型，通过菜单的「骨骼编辑」→「数值输入」进行输入。

## ※注意事项※

务必让控制器用饰品先于应用效果的模型绘制。

另外，请将地面影（非自阴影）设为 OFF 后使用。

## ●限制事项

由于是以 MikuMikuEffect 的效果示例「Basic/full.fx」为基础，所以不支持 MMD ver7.08 追加的边缘颜色设定功能。
