# 被写界深度 ver1.4（景深）

- 种类：后处理效果
- 对应：MikuMikuEffect ver0.2x 用
- 作者：kion
- 更新日：2011.8.17

## 说明

这是添加景深（被写界深度）的后处理效果。

## 使用方法

载入 DOF.x。

- 自动
  从摄像机到 DOF.x 的距离乘以 Tr 的范围即为景深（不模糊的范围）。
  用 Rx 指定模糊的强度。
  - 设定例
    Rx=3
    Tr=0.3

- 半自动
  把 DOF.fx 文件内的 AUTO_SETTING 设为 1。
  从 DOF.fx 的位置到 Si（尺寸）指定的范围为止即为景深（不模糊的范围）。
  用 Rx 指定模糊的强度。
  - 设定例
    Rx=3
    Si=100
  默认设定为对 DOF.x 的位置对焦。

- 手动
  在 DOF.fx 的 AUTO_SETTING 中指定 0，即可固定对焦位置。
  这种情况下，Si（尺寸）即为对焦位置（距摄像机的距离）。
  用 Tr 以比例指定景深的范围。景深范围＝ Si×Tr
  - 设定例
    Rx=3
    Si=100 Tr=0.5
