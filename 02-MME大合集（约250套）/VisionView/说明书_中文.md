# 視錐台表示　支援エフェクト（视锥体显示 支援特效）Ver.1.1

制作：そぼろ

同时左右点击鼠标，即可记录该时点的相机信息，
并显示其视锥体。
这样可以更容易看清会在哪里进入镜头画面等。

播放中会变为不显示。
想在播放中也显示时，请编辑参数，设为
```
HideInPlaying = false;
```

鼠标左右同时点击的点子来自 データP。

## 使用方法

- 读取 VisionView.x
- 同时左右点击鼠标
- 将绘制顺序设为最后
- 用 Tr 调整透明度
