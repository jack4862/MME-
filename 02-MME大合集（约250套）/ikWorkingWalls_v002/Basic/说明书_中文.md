# 合わせ鏡エフェクト 簡易版（对镜效果 简易版）

把两面镜子斜向配置，做出类似万花筒效果的效果。

## 使用方法

1. 把 ikWWController.pmx 与 ikWorkingWalls.x 放进 MMD。

2. 把 ikWWController 的中心位置设定为作为镜子起点的地板处。

3. 用 ikWWController 的表情变形设定镜子的张开角度与颜色。

镜子（或者说玻璃？）大多会呈现绿色，
所以设为 H = 0.5 左右、S = 0.2 左右，看起来可能比较像？

4. 用 ikWorkingWalls.x 的 Si 可以改变大小。

## 多边形缺失时的对策

在背景模型等多边形较大的模型中，
有时会在与镜子的边界附近发生多边形缺失。

WorkingWallRT 会被分配 WW_Object.fx。
给发生多边形缺失的模型分配 WW_Object_noCheck.fx，
即可抑制该症状。

反过来，分配 WW_Object_noCheck.fx 后，从背面看镜子时，
有时会渲染出本来不应显示的那一侧的模型。

## 设定文件

WW_Settings.fxsub 中有设定项目。

- 可以指定贴在镜面上的贴图。
- 可以指定镜子的初始尺寸。
- 可以设定镜子的张开角度。
    通常请用控制器的表情变形来调整角度。
- 可以指定镜面内的边缘描画。（默认为关）
