# 合わせ鏡エフェクト ポストエフェクト版（对镜效果 后处理版）

将两面镜子斜向放置、做成类似万花筒的效果。
支持 AutoLuminous 与 ikBokeh。

## 使用方法

1. 将 ikWWController.pmx、ikWorkingWalls.x、WW_Posteffect.x 三者一起载入 MMD。
   ※ 除简易版的 2 个文件之外，还需要 WW_Posteffect.x。

2. 将 ikWWController 的センター（中心）位置设定为作为镜子起点的地面。

3. 用 ikWWController 的表情变形（表情モーフ）设定镜子的张开角度与颜色。

   镜子（或者说玻璃？）多半会偏绿色，
   H = 0.5 附近、S = 0.2 附近的话看起来可能比较像。

4. 调整显示顺序。
   - ikWWController.pmx：顺序放在哪里都可以。
   - ikWorkingWalls.x：最好放在要显示的模型、附件（アクセサリ）的最后。
   - WW_Posteffect.x：尽可能放在最后。

5. 可以用 ikWorkingWalls.x 的 Si（尺寸）改变大小。

## AutoLuminous 与 ikBokeh 的效果分配

使用 AutoLuminous 时，请在 MME 的 AL_EmitterRT 标签页中，
对 ikWorkingWalls.x 分配 WW_For_AL.fx。

使用 ikBokeh 时，请在 MME 的 LinearDepthMapRT 标签页中，
对 ikWorkingWalls.x 分配 WW_For_ikBokeh.fx。

## 多边形缺失时的对策

对于背景模型等多边形较大的模型，
在镜子边界附近可能会出现多边形缺失。

WorkingWallRT 会被分配 WW_Object.fx。
对发生多边形缺失的模型分配 WW_Object_noCheck.fx，
可以抑制该症状。

反之，分配 WW_Object_noCheck.fx 后，从背面看镜子时，
有可能会渲染出本不该显示的那一侧的模型。

## 设定文件

WW_Settings.fxsub 中有设定项目。

- 可以指定贴在镜面上的贴图。
- 可以指定镜子的初始尺寸。
- 可以设定镜子的张开角度。
    通常请用控制器的表情变形来调整角度。
- 可以指定镜面内的边缘（エッジ）描画。（默认为关闭）
- 可以开启/关闭面向 AutoLuminous 与 ikBokeh 的输出。
    不使用各自的后处理时，
    关闭它可以提高速度。
