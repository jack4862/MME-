# Breath（吐息）v1.1

让角色「哈——」地呼出白气的效果。

- 这是稍微有点特殊的应用方法，请注意！建议熟读使用方法！-

1. 向 MMD 载入 Breath.x
2. 装在想让其吐息的模型嘴部附近
   （装在头骨骼上，X:0 Y:0.25 Z:-1.0 Rx:-90 左右可能比较推荐）
3. 用记事本等打开 Breath.fx，

```
//ターゲットモデル名（人体モデルを想定）
#define TGT_MODEL "初音ミクVer2.pmd"
```

把写着以上内容的部分中的模型名，改成装有 Breath.x 的模型名。
请注意不是 MMD 上的显示名，而是带 .pmd 或 .pmx 的模型名！！

4. 吐出的息量会随模型的口部表情（口モーフ）强度变化哦！

5. 用 Breath.x 的 Tr 值可以限制吐息的强度。
   只是稍微张嘴就在吐息有点……的时候请用这个。
   顺带一提，为 0 时停止生成。

## --初始状态对应的表情--

- "あ"（a）
- "い"（i）
- "う"（u）
- "え"（e）
- "お"（o）
- "わらい(口)"（笑(口)）
- "おこり(口)"（怒(口)）
- "あーれー"
- "ダミー"（假名占位）×2（适当改名后使用）

## --!!重要!!--

加上「吐息制御」（吐息控制）表情即可控制息量。
想在张口的同时表现「哈— 哈—」的呼吸时，请用 Tr 值操作，或者追加吐息控制表情。
