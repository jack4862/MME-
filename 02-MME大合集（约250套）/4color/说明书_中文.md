ScreenTex.fx ver0.0.4
ScreenTexPmd.fx ver0.0.4
Post_ScreenTex.fx ver0.0.4

把纹理缩放到画面尺寸后贴上。适合绘制画框、
以及把物体的纹理前面与后面分开。
纹理显示静态图像、动画纹理、Screen.bmp 中的任意一个。
可以进行颜色键（color key）透明设定。ScreenTexPmd.fx 是 ScreenTex.fx 的 PMD 版。
Post_ScreenTex.fx 是 ScreenTex.fx 的后处理效果版。
是改写舞力介入P 氏的 laughing_man.fx 制作而成的。

・ScreenTex.fx 使用方法
(1) 把 ScreenTex.x 加载到 MMD。在 MMM 中直接加载 ScreenTex.fx。
(2) 在 ScreenTex.fx 的开头参数中指定要贴的纹理文件名。
(3) 在 MMD 的饰品参数中进行以下变更并登录关键帧。
　　 X,Y,Z：用于颜色键透明的 RGB 色(0～1)。
　　 Rx：颜色键的阈值（为 0 则无颜色键透明）。
　　 Tr：纹理的透明设定
　　 在 MMM 中可以从添加到效果属性的 UI 控件进行颜色键设定。

・ScreenTexPmd.fx 的使用方法
(1) 把 ScreenTexPmd.pmd 加载到 MMD。
(2) 在 ScreenTexPmd.fx 的开头参数中指定要贴的纹理文件名。（不能选择 Screen.bmp）
(3) 在 ScreenTexPmd.pmd 的表情滑块中进行以下变更并登录关键帧。
　　　 目　：key赤,key緑,key青 → 用于颜色键透明的 RGB 色
　　　 ﾘｯﾌﾟ（唇）：key閾値 → 颜色键的阈值（为 0 则无颜色键透明）。
　　　 その他（其他）：透過度 → 纹理的透明设定
(4) 通过绘制顺序，可以在 PMD 内把纹理的前面与后面分开。
　　不过按 MMD 的规格，只有 PMD 的边缘会保持显示。要避免这一点，
　　需要边缘的独自绘制。（请使用 EdgeControl.fx 等。）

・Post_ScreenTex.fx 使用方法
请把 Post_ScreenTex.x 加载到 MMD。使用方法与 ScreenTex.fx 相同。
这个是作为后处理效果运行的。可以在不受 DOF 等其他后处理效果影响的情况下
绘制（不过能贴的只有前面）。
绘制顺序请务必放在其他后处理效果之后。

本 fx 文件如果不是 MME ver0.24 以后则无法正确运行。
