# 视点移动特效 ver0.2（FreeMove 0.20）

- 名称：视点移动特效 ver0.2
- 对应：MikuMikuEffect ver0.2x 用
- 作者：kion
- 更新日：2011.01.02

这是可在 MikuMikuEffect ver0.2x 中使用的特效文件（*.fx）。
已在 MMD ver7.25 + MME ver0.23 下确认可运行。

这是移动视点的特效。
带平滑化功能。

## 关于 MikuMikuEffect

这是由舞力介入P制作的、让 MikuMikuDance 可以使用特效文件的工具。
详见 → http://www.nicovideo.jp/watch/sm12149815

## 文件说明

- Readme.txt ／ 本文件
- CameraFull.x ／ 用于读入 CameraFull.fx 的附件
- CameraFull.fx ／ 特效文件本体
- CameraSmooth.x ／ 用于读入 CameraSmooth.fx 的附件
- CameraSmooth.fx ／ 计算视点的矩阵，以及进行平滑化
- CameraMove.x ／ 用于读入 CameraMove.fx 的附件
- CameraMove.fx ／ 计算移动用坐标与姿态
- Camera1.fx ／ 变更视点后绘制物体
- Cam1Pos.x ／ 设定相机位置的附件
- CenterControl.x ／ 前进后退控制
- LeftControl.x ／ 左旋回与上升下降
- RightControl.x ／ 右旋回与上升下降
- non.fx ／ 用于降低 GPU 负载的参照用文件

由 CameraMove.fx 进行判定与移动。
由 Camera1.fx 变更到另一个视点来绘制物体。
如果将 Cam1Pos.x 改名，CameraSmooth.fx 与 Camera1.fx 就会取不到信息，所以请不要改名。

## 原理

把控制用附件挂在骨骼上，用该附件的位置进行判定。
由 CameraMove.fx 取得附件位置、进行判定，更新位置与姿态，并写入贴图。
再由 CameraSmooth.fx 计算视图矩阵，做平滑化处理后写出到贴图。
在 Camera1.fx 内读取上面的贴图，变更视点后进行绘制。
CameraFull.fx 则使用 Camera1.fx，把绘制到离屏缓冲的内容输出。
平滑化采用的是取平均值的方法，所以会有少许延迟。

## 使用方法

读入以下文件：

- CameraFull.x
- CameraMove.x
- CameraSmooth.x
- Cam1Pos.x

Cam1Pos.x 即相机位置，蓝色面所朝的方向即相机的视线方向。
在 Cam1Pos.x 的尺寸（Si）中以度数指定视角。初始状态为 1，请酌情改为 45 或 60 等值。

判定是以镜音レン.pmd 进行调整的。
例：用镜音レン.pmd 做 FPS 视点

- Cam1Pos.x 设置在头部骨骼
- (x,y,z)=(0,2,-2) (Rx,Ry,Rz)=(0,180,0) Si=90

读入并设置操作用附件
（附件 ／ 骨骼名）

- CenterControl.x ／ 上半身
- LeftControl.x ／ 左中指3
- RightControl.x ／ 右中指3

在 CameraMove.x 的 Si 中设定 0.1。

※为了初始化视点数据与移动数据，请务必按下［播放按钮］至少 1 次。

### 操作方法

- 向前进则前进
- 右手向右移动则右旋回
- 左手向左移动则左旋回

※需要配合模型尺寸进行判定。默认为镜音レン.pmd。请参照参数一节。

（MMD ver7.24 的情况）

（MMD ver7.25 以后）
取消勾选菜单的「ﾓｰｼｮﾝｷｬﾌﾟﾁｬ」→「左右反転」。

### Kinect 捕捉的方法

因为捕捉开始与播放不同步，所以需要如下方法。
可以用 CameraMove.x 的 Si 值（尺寸）设定移动处理开始时间［秒］。
捕捉时，把 Si 设为 10 秒，按下播放按钮后立刻开始捕捉。
按下播放按钮后的 10 秒内不要动，过了 10 秒之后再动。
输出视频时把 Si 设为 0 秒后输出。

## 参数

※判定的调整
请打开 CameraMove.fx。
默认值是按镜音レン调整的。
判定呈壁状，以前进判定为例，向前走靠近墙壁时就会前进。
另外，越靠近墙壁速度越快。

```
// 距離(位置、範囲)
float2 ForwardDistance	= {-6.0, 4.0};	// Z
float2 BackDistance	= {6.0, 4.0};	// Z
float2 LeftDistance	= {9.0, 5.0};	// X
float2 RightDistance	= {-9.0, 5.0};	// X
float2 DownDistance	= {3.0, 3.0};	// Y
float2 UpDistance	= {20.0, 3.0};	// Y
```

各行 {} 内，第一个数字是判定墙壁的位置。下一个数字是判定的范围。
以 Kinect 捕捉的中心 (0,0,0) 为原点。
前后用的 ForwardDistance、BackDistance 是垂直于 Z 轴的墙壁判定。
左、右旋回用的 LeftDistance、RightDistance 是垂直于 X 轴的墙壁判定。
上升、下降用的 DownDistance、UpDistance 是垂直于 Y 值的墙壁判定。

```
float Size = 1.0;
```

用 Size 可以变更判定的大小。
对于体格相同但大小不同的模型很方便。

### 移动最大速度

```
float3 Velocity = float3( 60, 60, 60 );
```

用 Velocity 设定速度。左右（X 轴）、上下（Y 轴）、前后（Z 轴）的移动量。

```
float3 RotateYPR = float3( radians(120.0), radians(120.0), radians(120.0) );
```

用 RotateYPR 设定旋回速度（度）。按 Yaw（Y 轴）、Pitch（X 轴）、Roll（Z 轴）的顺序设定。

### 平滑化

可以用 CameraSmooth.fx 的以下参数设定平滑化。

```
// 閾値
float LimitPos = 0.01;
float LimitQuat = 0.02;
```

只要不超过 LimitPos、LimitQuat 指定的值就不会动作。
LimitPos 是位置的调整值，LimitQuat 是倾斜的调整值。
主要用于抑制细小振动。调大可以抑制振动。
但另一方面，调大也会让动作变得一顿一顿的，所以应尽量取小值。

```
// 平滑化量(1<)
#define POS_SMOOTH	6
#define QUAT_SMOOTH	6
```

保存包含当前帧在内的过去帧的视点信息，计算平均值进行平滑化。
值越大越平滑，但会被过去的信息拖拽，因此延迟会变大。

```
// 平滑化開始時間
#define WAIT_TIME	0.1
```

从按下播放按钮起进行初始化的时间（秒）。
基本上不需要变更。FPS 极小时（1 以下）或许调大一点比较好。

### 使平滑化无效的情况

按以下方式变更数值

```
// 閾値
float LimitPos = 0.0;
float LimitQuat = 0.0;
// 平滑化量(1<)
#define POS_SMOOTH	1
#define QUAT_SMOOTH	1
```

即使设为无效，平滑化的多余处理仍然存在，所以使用 FreeCamera0.1x 更好。

## 注意点・问题点

因为没有进行边缘固定处理，所以与 MMD 原本的相机位置差别很大时，
边缘会变得过粗或过细。
请把相机放在相近的位置，或者关闭边缘。
不支持自阴影。

## 限制

由于使用 Camera1.fx 来绘制模型，原理上无法使用其他特效文件。
Clone.fx、Glass.fx、敏感卡通（センシティブトゥーン）等无法使用。
只能改造 Camera1.fx。

## GPU 负载降低

启用 CameraFull.x 时，向 MainRenderTarget 的绘制结果不会被使用。
对 MainRenderTarget 使用 non.fx 可以省去绘制。使用 non.fx 会稍微变轻。
请从 MME 菜单「特效分配」给各绘制模型应用 non.fx。

改造、再配布自由。
