# 花火（烟花）特效

fx 制作：ロベリア（ビームマンP）

## 用法
自动版为自动播放，可通过 Tr 值错开播放时机。

手动版可通过 Tr 从 1～0 指定播放位置。

另外，自动版可在 fx 内

```
//スクロール速度
float2 UVScroll = {0,0.035};
```

↑改写这里即可设定动画速度
