# nbRGB

　这是一个调整 RGB 的后处理效果。
　效果的适用区域可以从[效果分配]的标签中指定。

## ■使用方法

(1) 把 `nbRGB.x` 加载到 MMD 中。

　　　<补充>
　　　　　使用标签进行部分应用时，基本上要放在模糊类效果的前面。
　　　　　→ 效果 ON/OFF 的边界判定不考虑模糊，所以放在模糊类效果后面的话边界会变得不正常。

(2) 用 `Controller_nbRGB.pmd` 的变形（Morph）操作色调。（变化方式在介绍图片中有说明）

　　　<补充>
　　　　　从 `nbRGB.x` 的操作面板也可以进行部分操作。
　　　　　- X：红(R)　 基本输入范围 -1.0～1.0
　　　　　- Y：绿(G)　 基本输入范围 -1.0～1.0
　　　　　- Z：蓝(B)　 基本输入范围 -1.0～1.0
　　　　　- Rx：红差　 基本输入范围 -1.0～1.0
　　　　　- Ry：绿差　 基本输入范围 -1.0～1.0
　　　　　- Rz：蓝差　 基本输入范围 -1.0～1.0
　　　　　- Si：（未分配）
　　　　　- Tr：R 基准・G 基准・B 基准　 基本输入范围 1.0～0.0（数值的变动方式与变形不同。）（面板操作中无法分别操作 R～B 的基准。）

(3) 想要指定效果的适用区域时，从[效果分配]的[RGB]标签中指定。
　　应用 `rgb_OFF.fx` 后不受效果影响。

(4) 进行部分应用时，根据需要可用[境界_OFF強]变形调整效果 ON/OFF 边界部效果的作用程度。

　　　→ 根据 ON 与 OFF 的差异程度，边界处有时会出现线条，请调整到不明显。
　　　→ 基本上只操作[境界_OFF強]感觉就可以了。
　　　→ 带 Alpha 输出时或对透明材质使用[境界_OFF強]、[境界_ON強]变形，有时外观会变差，请注意。

　　　<补充>
　　　　　在边界的灰区中，初始设定下会以相同程度的强度（与灰区的灰度程度相匹配、未加偏置的比例）进行混合。
　　　　　把[境界_OFF強]变形设为 1.0 时，会较强地混合效果 OFF 的状态。
　　　　　[境界_ON強]变形为 1.0 时，会 100% 采用效果 ON 的状态。

## ■内容物说明

- `nbRGB.x`：用于把 nbRGB 加载到 MMD 的文件。
- `nbRGB.fx`：主文件。
- `Controller_nbRGB.pmd`：效果控制器。可以用变形修改参数。

### ＜[效果分配]的[RGB 标签]用文件＞

- `rgb_ON.fx`：应用于想要加上效果的东西。（初始设定下所有材质都会应用这个。）
- `rgb_ON_for_skydome_noalpha.fx`：用于天空球等设置在最里面、本应是非透明的物体。
  　　　　　　　　　　　　　　　　　　　　　 如果存在意图之外的透明判定区域，效果的作用程度会发生变化，所以把适用区域全部强制当作非透明处理。
  　　　　　　　　　　　　　　　　　　　　　 （例）天空球出现虚线时，应用这个就会改善。
- `rgb_OFF.fx`：应用于不想加上效果的东西。
