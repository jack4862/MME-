# WorkingRay.fx ver0.0.1

这是「做出工作的光」、用来遮住不该让人看到的部位的公告板（Billboard）遮罩效果。

骨骼跟随带有弹性，因此不会跟随细碎的抖动。

准备了两种：从远处射入的 Line[WorkingRay.fx].x，以及用于精准遮罩的 Point[WorkingRay.fx].x。

## WorkingRay.fx 使用方法

1. 将 Line[WorkingRay.fx].x、Point[WorkingRay.fx].x 载入 MMD。
2. 绘制顺序请放在目标模型之后。
3. 在目标 PMD 模型中，把 Line[WorkingRay.fx].x、Point[WorkingRay.fx].x 挂到要遮罩部位的骨骼上。
4. 根据需要修改 fx 文件开头的参数。特别是骨骼跟随不如预期时必须修改。
5. 使用 MMD 的附件参数可以进行以下调整。
   - XYZ：光线位置补正
   - Rz：光线射入的方向
   - Si：光线的尺寸
   - Tr：光线的透明度

基本上以加算合成 ON 来显示效果更好。

## 注意点

因修改参数而更新 FX 文件时，会施加急剧的加速度，有时会无法正常显示。
这种情况下，播放第 0 帧数据就会被初始化，从而重新显示。

※ 这个 FX 文件必须在 MMEver0.24 及以后版本才能正确运行。
