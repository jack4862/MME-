MangaSweat.fx ver0.0.1

モデルに漫画風の全身タラタラな汗をかかせます．
汗テクスチャはスクリーン上に貼られますが,モデルの法線情報を使って歪ませることで
擬似的に3Dっぽく見せることが出来ます．ただしカメラをぐりぐり動かすような使い方には向いていません．
舞力介入P氏のfull.fxを改変して作成しました．


・使用方法
(1)PMD,またはアクセサリにMangaSweat.fxを適用してください．
    GUIの場合｢MMEffect｣→｢エフェクト割当｣のメインタブより適用したいオブジェクトにMangaSweat.fxを割り当てる.
    ファイル名設定の場合：XXXXX.pmd から XXXXX[MangaSweat.fx].pmd に変更，または MangaSweat.fx を XXXXX.fx に変更してロード．
(2)MangaSweatControl.pmdをMMDにロードします．
(3)モデル描画順序で適用したオブジェクトの直前にMangaSweatControl.pmdを置く．
(4)MangaSweatControl.pmdの表情スライダの項目でそれぞれ以下の制御が可能です．
    目  ：ｽｸﾛｰﾙ → 汗テクスチャをスクリーン下方にスクロールします．
    ﾘｯﾌﾟ：透過度 → 汗テクスチャを透明にします．
    まゆ：拡大,縮小 → 汗テクスチャの拡大･縮小を行います．
    その他：X歪み小,X歪み大,Y歪み小,Y歪み大 → モデルの法線情報による汗テクスチャの歪み度を変更します．
