# MangaSweat.fx ver0.0.1

让模型像漫画那样全身汗如雨下。

汗的贴图是贴在屏幕上的，但通过使用模型的法线信息使其扭曲，
就能显得有类似 3D 的效果。不过不适合把镜头转来转去的那种用法。

本效果是改编 舞力介入P 氏的 full.fx 制作而成。

## 使用方法

1. 对 PMD 或附件套用 MangaSweat.fx。
   - 使用 GUI 时：从「MMEffect」→「エフェクト割当（效果分配）」的主选项卡中，给想套用的对象分配 MangaSweat.fx。
   - 使用文件名设置时：把 XXXXX.pmd 改为 XXXXX[MangaSweat.fx].pmd，或者把 MangaSweat.fx 改名为 XXXXX.fx 后载入。
2. 将 MangaSweatControl.pmd 载入 MMD。
3. 在模型绘制顺序中，把 MangaSweatControl.pmd 放在所套用对象的前一个位置。
4. 通过 MangaSweatControl.pmd 的表情滑块各项，可以分别进行以下控制。
   - 目（眼）：ｽｸﾛｰﾙ（滚动）→ 让汗的贴图向屏幕下方滚动。
   - ﾘｯﾌﾟ（唇）：透過度（透明度）→ 让汗的贴图变透明。
   - まゆ（眉）：拡大、縮小（放大、缩小）→ 对汗的贴图进行放大、缩小。
   - その他（其他）：X歪み小、X歪み大、Y歪み小、Y歪み大 → 改变基于模型法线信息的汗贴图扭曲程度。
