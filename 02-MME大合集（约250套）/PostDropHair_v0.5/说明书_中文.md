# 后处理刘海阴影　PostDropHair.fx

用后处理效果描画刘海阴影（前髪影）。

## 【使用方法】

１．把 `PostDropHair.x` 加载到 MMD 中。
２．打开 MME，在 `DropHairRT` 标签中对刘海材质应用「髪影.fx」（前髪影.fx）。
３．在 `DropHairMaskRT` 标签中对背景舞台等不想让阴影干涉的模型或材质应用「髪マスク.fx」。
４．在 `PostDropHair.x` 的 Accessory 栏中调整阴影。
        `XYZ`　　…　阴影的位置
　　 `RxRyRz`　…　阴影的颜色（RGB、红绿蓝）

        `Si`　　　…　对阴影位置进行倍率补正
        `Tr`　　　…　阴影颜色的浓度

５．阴影的颜色或初始位置也可以通过用记事本改写 `前髪影.fx` 来变更。
　　如果做好配合模型的设定并另存为别的名字，就可以按模型应用不同的设定。

## 【MMM 的情况】

１．加载 `PostDropHair.fx`
２．打开 MME，在 `DropHairRT` 标签中对刘海材质应用「髪影.fx」（前髪影.fx）。
３．在 `DropHairMaskRT` 标签中对背景舞台等不想让阴影干涉的模型或材质应用「髪マスク.fx」。
４．用 `PostDropHair.fx` 的 `XYZ`、`RxRyRz` 调整阴影。
        `XYZ`　　…　阴影的位置
　　 `RxRyRz`　…　阴影的颜色（RGB、红绿蓝）

        `Si`　　　…　对阴影位置进行倍率补正
        `Tr`　　　…　阴影颜色的浓度

　　或者

　　可以用 `前髪影.fx` 的 UI（用户界面）进行调整。
　　    `Color`　　　…阴影颜色
　　    `PositionXYZ`…阴影的位置

５．阴影的颜色或初始位置也可以通过用记事本改写 `前髪影.fx` 来变更。
　　如果做好配合模型的设定并另存为别的名字，就可以按模型应用不同的设定。

※`前髪影_255.fx` 是为那些想用记事本打开 `.fx` 文件、以 0～255 来写 RGB 色调的人准备的。

## 【注意】

- 刘海必须作为材质被单独分离出来。
- 如果模型的肤色较深，刘海阴影可能不会显示。
  那种情况下请用 Accessory 的 `XYZ` 调整颜色的浓淡，
  或者打开 `前髪影.fx` 把初始设定的刘海阴影色调浓（示例中有调浓的版本）。
- 也许可以打开 `PostDropHair.fx` 把合成模式改成乘法试试。

- 想要落下刘海阴影的模型有多个时，
  在蒙版 RT 标签中存在极限，有时会出现模型 A 的刘海阴影落到模型 B 身上的情况。
  那种情况下就放弃吧，改加载多个 `PostDropHair.x` 分别设定。
  （在给模型 B 打蒙版的 `PostDropHair.x` 中，不会落下模型 A 的阴影。）

- 这是改変 ミーフォ茜 様 的 M4Layer 与 そぼろ 様 的 EdgeOnly 后使用的。
