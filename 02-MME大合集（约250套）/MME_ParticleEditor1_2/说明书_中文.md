# MME_ParticleEditor

这是用于自定义 http://www.nicovideo.jp/watch/sm12149815
中所介绍的示例效果 FireParticleSystem、FireParticleSystemEx_V20 的工具。
即使看不懂 fx 文件的内容，
也可以只自定义需要的参数。

## 文件构成

MME_SimpleParticleEditor.exe　工具本体
Readme.txt　本文件

## 使用方法

1：请启动 MME_ParticleEditor.exe。
2：把生成的 Particle1.x 载入 MMD。
　　也可以把 GUI 上的文件名拖拽＆拖放进去。
3：适当调整滑块，就会反映到已载入 MMD 的粒子上
4：做出与想象一致的粒子后，
　　请把
　　Particle1.fx
    Particle1.tga
    Particle1.x
　　这 3 个文件复制到合适的文件夹中保存。

## 稍微高级一点的用法

按右上角的 >> 按钮，可以扩展滑块的上限、下限。

## 自 Ver1.1 起的变更

- 把 ParticleSystemEx 更改为对应着色器 2.0 的 ParticleSystemEx_VS20。
  以前只有 Ex 无法运行的人现在也可以使用了。
  另外，由于随之把附件文件（Particle.x）也改成了 ParticleSystemEx_VS20 的东西，
  即使设定与以往相同的参数，有时形状也会不同，敬请谅解。
- 废除覆盖按钮、自动更新复选框
  启动的同时即进入自动更新状态。
  在开始设定之前，或者在设定完成、退出应用程序之前，
  请注意先更改文件名。
- 追加打开文件夹按钮
  调整中的粒子文件会生成在应用程序所在的同一文件夹中。
  如果不小心把应用程序的文件夹关掉了，请按这个按钮。
