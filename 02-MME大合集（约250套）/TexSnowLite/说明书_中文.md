# TexSnowLite Readme

MikuMikuEffect 用 降雪特效

制作：そぼろ

这是让雪降下的特效。

已支持最大粒子数 15000。
由于废除了循环绘制、从一开始就采用包含大量粒子的模型，
尤其是在高性能显卡上的绘制速度得到了飞跃性改善。
作为代价，即使减少粒子数也几乎不会变轻。

通过替换贴图，也可以表现雪以外的效果。
作为示例，也一并附上了星星的贴图。

可通过内部参数更改粒子数、范围、速度、倾斜、
粒子大小、噪声、旋转速度等。

## 通常的使用方法

- 在 MMD 中读取 TexShow.x
- 将绘制顺序设为最后

## 注意事项

- 由于使用了 Alpha 混合，请设置为最后被绘制。
- 需要支持顶点着色器 3.0 及 VTF 的显卡。
