# fxファイルかきかえまくりんぐツール（fx 文件大改写工具）2.0.0

这是 fx 文件参数更改的辅助工具。

自版本 1.0.0 起追加了以下功能：

- 稍微支持了 `#define`
  借此可以（在工具中）进行文件选择。
  与此相关，不再需要加上 `float()` 和 `int()`。

sample.fx 是设置示例。

## 注意

- 在让工具读取 fx 文件之前，请务必先做好备份。虽然工具会附加 .backup 自动备份，但这个自动备份不会覆盖更新。
- 关于细节，请在执行工具后按下帮助按钮，参照帮助内容。
- 另外，需要 .NET Framework 2.0 以上版本。
