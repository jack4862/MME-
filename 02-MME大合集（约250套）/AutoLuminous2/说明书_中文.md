# AutoLuminous Ver.2.0（发光效果 第 3 弹）

## ■ 使用方法

### □ 发光部分的指定

在本效果中，通过改造模型或附件来指定发光部分。

指定方法是：将要发光的材质的镜面反射色（反射色）设为黑色(0,0,0)，
将镜面反射强度（反射强度）设为 100 以上。
由于这种组合通常不会被使用，因此发生非预期发光的可能性很低。

镜面反射强度的标准值为 110。
想先让它发光时请使用这个值。
在此之上或之下增减，发光强度会按镜面反射强度减去 100 后的值成比例地上下变化。

发光颜色由漫反射色和环境色自动决定。

读入按以上方式改造过的模型之后，
读入 AutoLuminous.x 并加载效果，指定部分就会发光。

### □ 参数操作

通过更改 AutoLuminous.x 作为附件的值，可以操作效果的参数。

若在视频中始终使用固定设置，直接输入数值即可；
若要动态变化，推荐安装到假骨骼上。

- **Si：发光强度**

  指定发光部分的光的强度。

- **Tr：模糊强度**

  指定发光部分模糊的强度。
  无法调大。
  这是因为原本的模糊强度已设定得相当大。
  即便如此仍想调大时，需要直接编辑效果。

--------------------------

- **X：光芒方向数**

  指定眩光延伸的方向数量。
  请注意每个方向也会向相反方向延伸光。
  例如指定 3 时会延伸出 6 条光芒。
  适当值为 0～9 左右。
  请注意数量越多负荷越大。
  另外，增加后有时会比预期的更亮。

- **Y：原画面辉度**

  增减原屏幕画面的亮度。
  适当范围约为 -100～100。
  设为 -100 时原屏幕会完全变成纯黑。

- **Z：发光强度**

  只是值的指定方法不同，效果与 Si 相同。
  适当范围约为 -100～500。
  -100 与 Si=0、100 与 Si=2 具有相同的效果。
  设想用于想从假骨骼操作发光强度的情况。

--------------------------

- **Rx：光芒角度**

  将眩光的角度偏移指定的角度。

- **Ry：光芒长度**

  增减眩光的长度。
  适当范围约为 -100～100。
  调得过长会出现条纹。

- **Rz：闪烁周期**

  使发光闪烁。输入的数值直接作为以秒为单位的闪烁周期。
  正数时以正弦波闪烁，负数时以矩形波闪烁。
  设为 0 则停止闪烁。

## ■ 用法的扩展

### □ 与 ObjectLuminous 的兼容性

AutoLuminous 与 ObjectLuminous 一样，
可以应用以下使用方法。

・选择器效果的使用
・对个别材质应用单色效果
・从 MME 标签对材质进行「解除」

各自的详情请参阅 ObjectLuminous 的 Readme 及各种解说。
ObjectLuminous 用的选择器效果可直接使用。

### □ 与 KeyLuminous 的兼容性

与 KeyLuminous 一样，可以指定画面上的键控色（key color）使其发光。
必须编辑效果，详情将在上级篇中解说。

### □ 直接编辑效果

有一部分参数为了更改，需要直接编辑效果。
这需要一定程度的关于效果的知识。

这些参数包括模糊范围、采样数、背景色等。

尤其是采样数，在以全高清级大分辨率输出时，
标准的采样数完全不够、会出现条纹，因此必须调大该值。
不过增加采样数当然会变重。

### □ 通过追加 UV 进行逐顶点发光控制

仅限于 PMX，使用追加 UV 功能，可以更灵活地进行
逐顶点的发光控制。
详情将在上级篇中解说。

# AutoLuminous 高级篇

※本文档中会出现 3DCG 术语、DirectX 术语、MME 术语，恕不另行说明，敬请谅解。

## AutoLuminous 基本结构

AutoLuminous 的实质是 HDR 渲染引擎。
颜色信息全部以浮点数处理，可以处理 0～1 以外的范围的颜色。而超过 1 的颜色会作为高亮度部分接受泛光（bloom）与眩光（glare）处理。

AL_EmitterRT 不过是用于有意附加高亮度部分的前端（front end）。

## 键色发光（キーカラー発光）

与 KeyLuminous 相同，可以指定键色（Key Color）使其以任意颜色发光。
打开效果，编辑以下 3 个参数。

- KeyThreshold
  用于颜色判定的阈值。

- KEYCOLOR_NUM
  键色的数量。
  指定 0 则键色发光无效。

- KeyColors
  键色的数组。
  按注释文的指示，追加键色、核心色、发光色这 3 项。
  必须按 KEYCOLOR_NUM 指定的数量进行设置。
  不过当 KEYCOLOR_NUM 为 0 时参数本身会被忽略，所以怎样都行。

## 通过表情（Morph）进行个别发光控制

如果是 PMD 或 PMX 模型，通过在模型中内置以下名称的假表情（ダミー表情），即可对模型个别控制发光。
也可以只挑选需要的部分。

- LightUp
- LightOff
- LightBlink
- LightBS
- LightUpE (New!)
- LightDuty (New!)
- LightMin (New!)

"LightUp" 及 "LightOff" 可以调整光量。
LightUp 最大可亮到 3 倍。
LightOff 在 MAX 时发光会完全消失。

使用 "LightBlink" 及 "LightBS" 这两个假表情，可以对发光闪烁进行模型个别控制。
"LightBlink" 做正弦波闪烁，LightBS 做矩形波闪烁。
最大间隔为 10 秒。

"LightUpE" 中，亮度会以指数函数方式上升。
最大可上升到 400 倍。
"LightDuty" 可以改变闪烁时开启与关闭的比率。
"LightMin" 可以设置闪烁时的最小亮度。

这些假表情只有在利用镜面反射强度（スペキュラ強度）指定发光时才可使用。

## 顶点发光功能

仅 PMX 可利用追加 UV 进行逐顶点的发光控制。
虽然比材质指定更灵活，但改造与数据管理会变得繁杂。

- 追加UV1
  - X:0.2, Y:0.7
    表示这是 AutoLuminous 用的追加 UV 数据的识别码。
    该值固定。
  - Z:闪烁周期
    以秒为单位指定闪烁周期。
    负值时为矩形波闪烁。
  - W:标志
    指定标志。
    目前指定 1 时，发光将不再乘以贴图。

- 追加UV2
  - X:红, Y:绿, Z:蓝
    指定发光颜色。
  - W:发光强度
    指定发光强度。基准为 1。

　Options 文件夹中随附了用于在 PMDE 中批量更改所选顶点追加 UV 的脚本。
　请从插件 > CSSScript 读入，适当改写数值后执行。

## 用 PMDE 编辑附件

- 启动 PMDE，把想编辑的 X 文件拖放进去。
- 以「新規」「10倍」读入。
- 编辑材质等。
  注意：与在 MMD 中作为附件读入时的显示方式不同。
- 从菜单选择「ファイル」→「エクスポート」，另存为新的名字。
- 尺寸选择「1/10倍」输出。
- 退出 PMDE。会出现未保存的警告，无视即可。

## 遮罩功能

可以设置让特定对象不受发光影响。
首先，打开效果把 MASK_ENABLE 选项设为 1。
于是 MME 的设置标签中会出现 "AL_MaskRT"，选中不想受发光影响的对象并右键，点击「解除」。

对正在发光的对象应用遮罩，就会变成类似背光或光环的表现。

## 残光功能

打开效果，把 AFTERGLOW 设为 0 以上的值即可启用残光功能。
由于是帧混合方式，移动速度太快会出现不连续。请通过提高输出 FPS 等方式应对。

## 贴图的各向异性过滤对应

让应用了复杂贴图的材质发光时，有时会因为贴图缩小的原因而使发光闪烁。
更改 AL_Object.fxsub 的 MIPMAPTEX_SIZE 即可启用各向异性过滤，有可能缓解闪烁。
数值推荐与模型所使用贴图的最大尺寸大致相同，但过大会变重。
另外还有整体变得模糊的副作用。

## 贴图高亮度部分发光

当想让它发光的部分是画在贴图上、无法作为材质分离出来时，从 MME 的 AL_EmitterRT 标签选择目标模型或材质，应用随附的 AL_Texture.fx，即可设为只让贴图上明亮的地方发光。
不过，很多时候需要进行细致的调整。

## 色调曲线更改

读入 ToneCurve.x 后，AutoLuminous 的色调曲线会被更改，变得不易发生白飞（过曝）。
不过这会降低原画面的对比度，因此推荐在画面上存在较多高亮度部分时使用。

反过来，当画面较暗时，低亮度的色调曲线会保持直线，因此可以在不降低对比度的情况下使用。

把 SCREEN_TONECURVE 设为 1 可以强制开启色调曲线。

## 测试模式

读入 AL_Test.x 后 AutoLuminous 会进入测试模式，只显示加入模糊之前的高亮度部分。

## 通过加算合成附加高亮度

通过加算合成设置而颜色超过 1 的附件或模型，通常只会被截断（clamp）为 1，但在 AutoLuminous 中，通过更改渲染目标，即使是 MMD 一侧的绘制也能处理超过 1 的信息，从而被当作高亮度部分处理。

不过，在非加算合成的通常绘制中，由于数值会在着色器内被截断，所以例如即使把照明调得比通常更亮，也不会产生高亮度部分。

把着色器替换为自定义着色器时不在此限。

## 与 SpotLight 并用

MMD 画面上的加算合成型效果，可以使其对应 HDR 处理。
其代表例就是 SpotLight。
通常，SpotLight 照射的地方过亮时该部分只会白飞，但如果让绘制顺序排在 AutoLuminous 之前，并且中间不夹入其他（未对应 HDR 的）后处理效果，就可以作为高亮度部分赋予泛光与眩光效果。

此外也已确认 PostPointLight 等可以同样使用。

## 为了获得高画质

若要追求高画质，建议把采样数增加约一倍，并尽量以较大的尺寸输出后再缩小。

## MikuMikuMoving 对应

AutoLuminous 虽然还是暂定状态，但已对应 MikuMikuMoving。
在 MikuMikuMoving 中，不是读入 AutoLuminous.x，而是读入 AutoLuminous.fx 来使效果生效。

目前仍有一部分功能无法使用，也可能受 MMM 今后更新的影响，敬请谅解。
