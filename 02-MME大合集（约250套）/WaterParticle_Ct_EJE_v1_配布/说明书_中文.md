# ビームマンP 氏的 WaterParticle【控制器对应（色相）】

这是让 ビームマンP 氏 WaterParticle 的色相（红绿蓝）＋α 可以用控制器操作的东西。

## ☆收录内容☆

《WaterParticle霧吹き.x》（喷雾）
《WaterParticle全方位.x》（全方位）
《WaterParticleホース.x》（水管）
　・喷射粒子类型
《WaterParticleA.x》
　・活动粒子（アクティブパーティクル）类型
　・将控制器的 Ａ（调整用）设为 1，WaterParticleA 就会暂时进入常时发現状态
　　调整结束后请改回 0
　・推荐跟随脚尖骨骼等地面附近的骨骼

《WPdf_Ctrl.pmd》※如无需要，不载入也没关系。
　・控制器
　・除上述个别项目之外，还可以进行整体的色相调整

## ☆使用方法☆

1. 载入《WaterParticle霧吹き.x》《WaterParticle全方位.x》《WaterParticleホース.x》《WaterParticleA.x》
   　　中的任意一个。
2. 从附件操作栏（アクセサリ操作枠）中，与想要安装的模型对应的骨骼建立关联。
   　用 X,Y,Z,Rx,Ry,Rz 适当微调。
3. 载入《WPdf_Ctrl.pmd》控制器。
4. 从表情操作栏中，
   　可以调整 赤・青・緑・Ａ（调整用）。

## ☆备忘☆

・在附件栏（アクセサリ枠）中 Si=0 或 Tr=0，或两者都为 0 时消失。

・因为是控制器操作，所以可以登记关键帧，从而能做出颜色变化的动画

・把关键帧复制到其他效果时，使用「粘贴到其他帧（別フレームへペースト）」。
　　复制对应的关键帧
　　选择想粘贴的效果行，用 ctrl+F 粘贴

## ☆注意事项☆

・载入多个文件时，效果之间有时会相互干扰而产生「连凧」（一连串的拉扯伪影）。
　请打开效果分配，在该「DistortionRT」标签页内，
　把《WaterParticle霧吹き.x》《WaterParticle全方位.x》《WaterParticleホース.x》《WaterParticleA.x》
　上述所有项取消勾选。

# WaterParticle 使用方法（水花）

## 概要

类似水花的粒子特效。

## 使用方法

载入 MMD 使用。
参数的操作基本上是通过用记事本等直接编辑 fx 文件来进行。

## 主要的编辑对象参数

```
// 粒子数(0～15000)
#define PARTICLE_COUNT 15000
```
粒子的数量。

```
// 生成限制速度
float CutSpeed = 0;
```
生成的限制速度。为 0 时始终释放。

```
// 重力
float3 Grv = float3(0,-30,0);
```
不考虑模型角度的加速度。
用于重力、风等。

```
// 推进力
float MoveSpd = 0;
```
考虑模型角度的加速度。
朝模型的 Z 方向，以指定的速度喷出粒子。

```
// 衰减力（空气阻力）
float Air = 0.5;
```
推进力（MoveSpd）的衰减力。
