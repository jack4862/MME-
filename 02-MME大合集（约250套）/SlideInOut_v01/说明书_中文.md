# SlideOut.fx / SlideIn.fx 效果集 v0.1【对应着色器2】

## 【约定】
允许使用、再发布、改造、以及改造物的再发布。
不提供任何保证，请自行负责使用。

## 【概要】
这是滑入／滑出（Slide In/Out）的效果集。
做成了 Tr 动画。
SlideOut.fx 会让 Tr=1 时的图像移动着消失。
SlideIn.fx 会让当前影像覆盖到 Tr=1 时的图像上出现。

## 【使用方法】
读取 SlideOut.x 或 SlideIn.x。
绘制顺序最好设定在其他后期效果之后。

在到达场景切换之前，请设为不显示，以免白白耗费 GPU。

在场景切换帧的前一帧，把 SlideOut.x 或 SlideIn.x 设为显示，并令 Tr=1。
然后，用 X、Y、Si 指定「以何种方式消失（以何种方式出现）」。
设定的坐标以画面中心为 X=0, Y=0，上端为 Y=1，下端为 Y=-1，左端为 X=-1，右端为 X=1。
因此，若要向右端消失（从右端出现），则设 X=2。（不是 1）
若要向画面中心缩小消失（从画面中心放大出现），则设 X=0, Y=0, Si=0。

Si 会被插值，但为了配合无法插值的 X 与 Y，已在效果侧进行插值。
因此，MMD 侧不需要进行插值。

在场景切换结束的时间点，设为 Tr=0、不显示。
通过 Tr 的插值来播放动画。
（Tr=0 时若不设为不显示，会白白消耗 GPU 的性能）

为了自然地滑出／滑入，消失（出现）的地方请设为画面外，或者 Si=0。
若以 Si=1 使用，画面外则是 X<=-2、X>=2、Y<=-2、Y>=2 中的任一种。

使用拙作 Exclude.fx，也可以只让背景进行场景切换。
