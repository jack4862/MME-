# o_Tonemap v0.7（简易色调补正滤镜）

配布者：おたもん（user/5145841）　mail:o_tamon@okoneya.mail-box.ne.jp

## 前言

本滤镜只需指定预设即可进行色调补正，是为了在不使用 AviUtl 等软件的情况下，仅靠 MMD＋MME 就能轻松制作影像而做到这一点的。

## 关于透明度支持

本效果基本上是以使用舞台或天空穹顶的非透明视频为对象设想的，但将 fx 文件开头的「#define NON_TRANSPARENT」后面的数字从 1 改为 0，即可在保持透明度的状态下输出。

＊　注意　＊

- 由于规格原因，在透明度有效的状态下背景会变为灰色。
- 不清楚是否 MMD 的规格，以透明度有效状态输出时，半透明部分无法以正确的颜色显示。
- 以 AVI 输出时，请使用 Ut Video Codec RGBA(ULRA) 等支持透明度的编解码器。
- 仅在以 PNG 保存图像、或以 RGBA 系编解码器输出 AVI 时才请设为有效。

## 使用方法

请向可使用 MikuMikuEffect 的 MikuMikuDance 添加附件 o_Tonemap.x。
如果只是单纯进行黑白化或棕褐色化，请添加附件 o_Monochrome/o_Sepia.x。

**Tr**：可以调整效果的强度。
　　使用「Default」预设时，推荐在 0.5～0.75 左右。

**X, Y, Z**：指定最终阶段进行的各色独立式简易明度补正中，X：红色、Y：绿色、Z：蓝色要改变多少亮度。
　　0 为无变化。推荐值范围：-1.0 ～ +1.0。
　　负值越大越暗，正值越大越亮。

＊ Tips ＊

- 各色指定相同的值即可简单地变暗、变亮。
- 将红色(X)提亮 0.1 左右（≒将绿色(Y)、蓝色(Z)压暗）造成偏红，可以增加温暖感。
　在黑白化状态下进行，可以表现暖色系灰调。
- 将蓝色(Z)提亮 0.1 左右（≒将红色(X)、绿色(Y)压暗）造成偏蓝，可以增加清洁感。
　在黑白化状态下进行，可以表现寒色系灰调。

## 可在效果文件开头设置的内容

用文本编辑器等编辑 o_Tonemap.fx 的开头部分即可更改效果。

- **NON_TRANSPARENT**：设为 0 时背景进行透明处理（初始值），设为 1 时背景为纯白不透明。
- **Preset "预设位图的文件名"**
　　初始设置为 "Default"
　　将 "" 中的内容改写为 "Negative-film" 或 "Contrast_Strong" 等 bitmap 文件夹中的预设位图文件名即可切换效果。
　　同捆预设的效果详情见后述。
- **Monochrome　0 或 1**
　　设置是否进行黑白化。初始设置为 0（不黑白化）。
　　设为 1 时，在应用预设前舍弃彩色信息，转换为仅含亮度的黑白。

　　进行黑白化时请设为 Preset "Plain"、Monochrome 1；
　　进行棕褐色化时请设为 Preset "Sepia" 或 "psSepia"、Monochrome 1。
　　　保持彩色应用 "Sepia"，或以黑白应用 "Negative-film" 等也是一种做法。

- **MONO_ALGO　0 或 1 或 2 或 3**
　　指定进行黑白化时使用的计算公式。初始值为 3（基于 BT.709）。
　　　0：不进行黑白化 …… 与 Monochrome 0 等效。

　　　1：平均计算法
　　　　……　单纯将红、绿、蓝各色相加后除以 3 的高速算法。
　　　　　　　接近被称为明度而非亮度的概念，会忽略颜色外观上的明亮程度。

　　　2：基于 BT.601 的亮度计算法 ※与 v0.3 以前的黑白化相同
　　　　……　对各色施加考虑视觉心理的加权后再相加的均衡算法。
　　　　　　　是通常被称为亮度的概念之一。相当于模拟电视的亮度成分＝黑白电视。

　　　3：基于 BT.709 的亮度计算法（带伽马补正）
　　　　……　对各色施加考虑显示设备伽马曲线的、基于视觉心理的加权后相加。
　　　　　　　也用于数字电视，是与 Photoshop 等中的黑白化同等的较重算法。

- **GAMMA 单精度浮点数（推荐值范围：1.0～5.0）**
　　指定 MONO_ALGO 3 时使用的伽马值。初始值为 2.2（相当于 sRGB）。
　　1.0 时无效果。值越大，中间调会被伽马补正得越亮。
　　Windows 及 Mac OS X v10.6 以后、AdobeRGB 使用 2.2，Mac OS X v10.5 以前使用 1.8。

## 同捆预设的效果详情

- **Default**
　――　按制作者的喜好将暗部压得相当低，形成对比度较高的影像。
- **Plain**
　――　如名称所示没有效果。进行黑白化时，在不需要色调补正的情况下请指定此项。
- **Bright**
　――　使画面变亮。由于抬升中间调，不易发生黑位浮起或白位溢出。
- **Dark**
　――　使画面变暗。由于压低中间调，不易发生黑位压死或白色浑浊。
- **Contrast**
　――　压低暗部，不太补正亮部。适合阴影较弱的 MMD。
- **Contrast_Strong**
　――　暗部更暗、亮部更亮，均匀地提升对比度。
- **Sepia**
　――　与黑白化并用，可加工成带有年代感的单色系。
- **Inversion**
　――　将 RGB 各要素的阶调正反颠倒。一般所说的负片正片反转效果属于此类。
- **Negative-film**
　――　像模拟相机的负片一样反转阶调。肌肤等明亮部分很容易黑位压死。
- **Cross-process**
　――　营造出胶片与显影的正负片颠倒般的风味画面。适合风景影像。

## 预设的制作方法

所谓预设的文件是横向 256 像素×纵向 1 像素的全彩位图。
应用规则是：当原色的红色为 n 时，用像素坐标 x=n, y=0 处的红色值替换原色的红色。
同样，绿色、蓝色也分别用原色颜色坐标处像素的颜色替换。

制作最简单的色调曲线补正预设的方法，是用 Photoshop 或 Gimp 等图像编辑软件对 "bitmap\Plain.bmp" 实际进行色调曲线补正。

将结果以别的名称保存并在效果中指定，同样的补正就会在 MMD 上生效。
由于是全彩 BMP，即使对 RGB 分别应用色调曲线，也能同样在 MMD 中再现。
