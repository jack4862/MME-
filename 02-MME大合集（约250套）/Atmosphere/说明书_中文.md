# 【お手軽にトーン補正フィルタ v0.7】（轻松色调补正滤镜 v0.7）

配布者：おたもん（user/5145841）　mail:o_tamon@okoneya.mail-box.ne.jp

## 前言

本滤镜只需指定预设（Preset）即可进行色调补正，即使不使用 AviUtl 等软件，仅靠 MMD＋MME 也能完成简单的影像制作。

## 关于透明度支持

本效果基本上是以使用舞台或天空穹顶（Sky Dome）的**非透过**视频为对象设计的，但只要把 fx 文件开头的「#define NON_TRANSPARENT」后面的数字从 1 改为 0，就可以在保持透明度的状态下输出。

＊　请注意　＊

- 按规格，在透明度有效的状态下背景会变成灰色。
- 不知是否 MMD 的规格所致，以透明度有效状态输出时，半透明部分无法以正确的颜色显示。
- 用 AVI 输出时，请使用 Ut Video Codec RGBA(ULRA) 等支持透明度的编解码器。
- 只在以 PNG 保存图像、或以 RGBA 系编解码器输出 AVI 时才启用。

## 使用方法

在可以使用 MikuMikuEffect 的 MikuMikuDance 中，追加 Accessory「o_Tonemap.x」。

如果只是想单纯进行黑白化或棕褐色化，请追加 Accessory「o_Monochrome.x」／「o_Sepia.x」。

- **Tr**：可以调整效果的生效程度。
  使用「Default」预设时，推荐 0.5～0.75 左右。

- **X, Y, Z**：指定在最后阶段进行的各色独立式简易明度补正——X：红色、Y：绿色、Z：蓝色各自要改变多少亮度。
  0 表示无变化。推荐值范围：-1.0 ～ +1.0。
  负值越大越暗，正值越大越亮。

＊ Tips ＊

- 各色指定相同的值，即可简单地变暗／变亮。
- 把红色（X）提亮约 0.1（≒把绿色（Y）、蓝色（Z）压暗）造成红色偏移，可以增添温暖感。
  在黑白化状态下这样做，可以表现出暖色系灰调。
- 把蓝色（Z）提亮约 0.1（≒把红色（X）、绿色（Y）压暗）造成蓝色偏移，可以增添清洁感。
  在黑白化状态下这样做，可以表现出寒色系灰调。

## 可以在效果文件开头设置的项目

用文本编辑器等编辑 o_Tonemap.fx 的开头部分即可变更效果。

- **NON_TRANSPARENT**：设为 0 时对背景进行透过处理（初始值）；设为 1 时把背景铺成纯白、不透过。

- **Preset "预设位图的文件名"**
  初始设定为 "Default"。
  把 "" 中的内容改写为 "Negative-film"、"Contrast_Strong" 等 bitmap 文件夹中预设位图的文件名，即可切换效果。
  同梱预设的效果详情见后述。

- **Monochrome**　0 或 1
  设定是否进行黑白化。初始设定为 0（不黑白化）。
  设为 1 时，会在应用预设之前丢弃色彩信息，转换为仅含亮度的黑白。

  进行黑白化时，请设为 Preset "Plain"、Monochrome 1；
  进行棕褐色化时，请设为 Preset "Sepia" 或 "psSepia"、Monochrome 1。
  保持彩色状态套用 "Sepia"，或黑白状态下套用 "Negative-film" 等，也是一种玩法。

- **MONO_ALGO**　0 或 1 或 2 或 3
  指定进行黑白化时使用的计算公式。初始值为 3（基于 BT.709）。
  - 0：不进行黑白化 …… 与 Monochrome 0 同等。

  - 1：平均计算法
    …… 只是把红・绿・蓝各色单纯相加再除以 3 的高速算法。
    与其说是亮度（辉度），更接近所谓的明度，会无视颜色的外观亮度。

  - 2：基于 BT.601 的亮度计算法 ※与 v0.3 以前的黑白化相同
    …… 对各色施加考虑了视觉心理的加权后再相加的均衡算法。
    是通常被称为亮度（辉度）的其中一种。与模拟电视的亮度成分＝黑白电视相同。

  - 3：基于 BT.709 的亮度计算法（带伽马补正）
    …… 对各色施加考虑显示设备伽马曲线的、基于视觉心理的加权后相加。
    也被用于数字电视，是与 Photoshop 等软件中黑白化同等的较重算法。

- **GAMMA**　单精度浮点数（推荐值范围：1.0～5.0）
  指定 MONO_ALGO 3 时使用的伽马值。初始值为 2.2（相当于 sRGB）。
  1.0 表示无效果。值越大，中间调会被伽马补正得越亮。
  Windows 及 Mac OS X v10.6 以后、AdobeRGB 使用 2.2，Mac OS X v10.5 以前使用 1.8。

## 同梱预设的效果详情

- **Default**
  —— 按制作者的喜好把暗部压得相当沉，形成对比度较高的影像。
- **Plain**
  —— 顾名思义没有效果。进行黑白化、不需要色调补正时请指定它。
- **Bright**
  —— 使画面变亮。因为是抬升中间调，不易出现黑位浮起或白位压死。
- **Dark**
  —— 使画面变暗。因为是压低中间调，不易出现黑位压死或白色浑浊。
- **Contrast**
  —— 压暗暗部，明亮部分不太补正。适合暗部（Shadow）较弱的 MMD。
- **Contrast_Strong**
  —— 暗部更暗、亮部更亮，均等地提高对比度。

- **Sepia**
  —— 与黑白化并用，可加工成带有年代感的单色系。
- **Inversion**
  —— 把 RGB 各要素的阶调完全反转。一般的负片正片反转（Nega-Posi）效果属于此类。
- **Negative-film**
  —— 变成类似模拟相机负片那样的阶调反转。肌肤等明亮部分很容易出现黑位压死。
- **Cross-process**
  —— 制作出如同胶片与显影的负正关系错位一般的别有风味的画面。适合风景影像。

## 预设的制作方法

被称为预设的文件，是横向 256 像素×纵向 1 像素的全彩位图。
适用规则是：当原色的红为 n 时，用像素坐标 x=n, y=0 处的红的数值来替换原色的红。
同样地，绿和蓝也各自用原色数值所在坐标处像素的颜色来替换。

制作最简单的色调曲线（Tone Curve）补正预设的方法，是把 "bitmap\Plain.bmp" 用 Photoshop 或 Gimp 等图像编辑软件实际进行色调曲线补正。

把结果另存为别的名字并在效果中指定，同样的补正就会在 MMD 上生效。
由于是全彩 BMP，即使对 RGB 分别套用色调曲线，也能在 MMD 中同样再现。
