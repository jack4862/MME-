# MikuMikuEffect 用键控发光滤镜 Ver.2.2

制作：そぼろ

这是对特定颜色的部分进行键控（keying）后，让该部分看起来在发光的效果滤镜。
请注意它并非作为光源起作用。

它不是作用于个别物体，而是由「画面上的颜色」决定一切。
如果键控色也被用在其他模型上，多余的地方也会发光。

本效果以舞力介入P 的 `Gaussian.fx` 为基础。
调整用参数已集中在开头，请酌情修改。

## ● 参数

・**UseKeyX**

选择是否使用第 X 个键控色。
true 为使用，false 为不使用。

・**Key_ColorX**

指定键控色。

・**Extent_S**
・**Extent_G**

放射部分由 2 种模糊组合而成，
分别指定各自的模糊范围。
加大 `Extent_S` 会增大光的范围，
加大 `Extent_G` 会使光变淡地扩散。

・**Core_ColorX**
・**Emittion_ColorX**

`Core_Color` 是核心色，会与键控色置换。
用 `Emittion_Color` 指定放射光的颜色。

・**Strength_A**
・**Strength_B**

是指定效果强度的参数。
很难说明，请实际试一试。
1～2 左右比较合适。

・**Interval**

设定闪烁周期。
单位是帧。
设为 0 则不闪烁。

## ● 示例的试法

・读取 `KeyLuminous.x`
・读取 `sample.x`
`sample.x` 原本是紫色的箱子，效果有效时会发橙色光。

操作 Si、Tr 的值，效果的作用方式会变化。

## ● 材质的诀窍

为了进行键控，要让配件或模型的材质不受光源影响而保持一定颜色，可以：
・键控色选择原色
・Diffuse、Specular、Ambient 全部设为相同
・Toon 纹理选择 `Toon10.bmp` 等不带阴影的
等等。

另外，重要的是键控色尽量不要与画面内其他模型使用的颜色相似。

## ● 通常的使用方法

・在 MMD 中读取 `KeyLuminous2.x`，并将绘制顺序设定在最前面。

## ● 注意事项

・因为是后期效果，请务必将绘制顺序设定在普通物体之前。
