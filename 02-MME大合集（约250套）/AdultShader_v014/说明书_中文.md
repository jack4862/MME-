# AdultShader

- AdultShader_v013.fx【着色器 2 对应】v0.13
- AdultShader.fx【着色器 3 以后】v0.14

## 【约定】

允许使用・再分发・改造・改造物的再分发。
一概无法作出任何保证，请自行负责使用。

基本上使用的是 full.fx(舞力介入P) 的代码，软阴影部分使用了 SpotLight2(そぼろ氏) 的代码。

## 【概要】

这是改变模型氛围的着色器。
以适合夜晚的、妖异的感觉为目标，觉得如何呢。
背景偏黑的话感觉会比较相配。
不太受光源影响，以相机方向的影响为中心赋予立体感。
颜色浓厚、稍显阴暗的影像。
在影中或逆光时效果显著。

AdultShader_v013.fx 相当于 v0.13，且没有软阴影。
AdultShader.fx 是最强烈的设定，油光发亮、边缘融入黑色背景的参数。
AdultShaderS.fx 稍微柔和一点。虽然油光发亮，但边缘在黑色背景上会稍微浮现的参数。头发等会浮现条纹图案。
AdultShaderS2.fx 设定得比较柔和，以便也能较普遍地使用。
虽然没有太多油光感，取而代之立体感也多少变淡。

从 v0.14 起，搭载了 9 点采样 VSM 方式的软阴影。

## 【使用方法】

请把 AdultShader.fx（或 AdultShaderS.fx、AdultShaderS2.fx，以下相同）分配给模型。
从 [MMEffect] 菜单选择 [效果分配]，在对话框上选择模型，分配效果文件。

## 【效果的自定义】

改写 AdultShader.fx 的开头附近即可调整参数。

```
#define ShadowDarkness 1		// 自阴影的最大暗度
```
自阴影的浓度。
把这个数值变小，自阴影会变淡。请用于脸部阴影等的调整。

```
#define EyeLightPower	2		// 视线方向上的色调变化
```
来自视线方向的色调变化。
变大的话马上就会变浓。

```
#define ToonPower	1			// 影的暗度
```
自阴影以及背面的影的浓度。
变大的话会变暗。

```
#define OverBright	1.2			// 做好白飞（过曝）觉悟的亮度补正
```
变暗的要素有很多，所以让它变亮。
弄得太大就会白飞。

＜以下仅限 AdultShaderS.fx, AdultShaderS2.fx＞
```
#define FresnelCoef 0.08			// 菲涅尔项的系数
```
把侧向的面弄得有多亮。
（由于该项，头发等会出现条纹图案）

```
#define FresnelFact	5			// 菲涅尔项
```
要弄亮的面范围。变大的话会变窄。

＜以下共通＞
```
// 软阴影 补正系数
#define SOFTSHADOW_DISTANCE 0.1	// 切断软阴影的距离（越小则越远）
```
把远处大物体的影做成软阴影时，有时会变成奇怪的影。
为此，在远处会切断软阴影。
把这个数值变小，即使在远处也会软阴影化。

```
#define SOFTSHADOW_THRESHOLD 0.0005 // 软阴影补正值 越大影越淡
```
设为过小的值时，本来应该没有阴影的地方有时也会出现影。
反之过大的话，影有时会不再出现。

```
// 阴影贴图尺寸
#define SHADOWMAP_WIDTH 2048
#define SHADOWMAP_HEIGHT 2048
```
在 MMD 中通常阴影贴图尺寸是 2048x2048，但按 Control-G 会变成高精细影模式，阴影贴图尺寸变为 4096x4096。
此时请把 SHADOWMAP_WIDTH、SHADOWMAP_HEIGHT 都设定为 4096。
