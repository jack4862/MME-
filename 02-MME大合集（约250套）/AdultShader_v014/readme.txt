【お約束】
使用・再配布・改造・改造物の再配布を許可します。
一切の保証は致しかねますので、ご自身の責任においてお使いください。

基本はfull.fx(舞力介入P)のコード、ソフトシャドウ部にはSpotLight2(そぼろ氏)のコードを使用しました。

【概要】
モデルの雰囲気を変えるシェーダです。
夜が似合う妖しい感じを目指しましたが、どうでしょうか。
背景が黒っぽいほうが似合う感じかと。
光源の影響をあまり受けず、カメラ方向の影響を中心に立体感を付けます。
色が濃く、やや暗い感じの映像になります。
影の中や、逆光で顕著に効果を発揮します。

AdultShader_v013.fxは、v0.13相当でソフトシャドウ無しです。
AdultShader.fxは、一番きつ目の設定で、テカテカで背景黒に縁が溶け込む感じのパラメータ。
AdultShaderS.fxは、ほんの少し柔らかめ。テカテカですが背景黒に、ほんの少し縁が浮かぶ感じのパラメータです。髪の毛などに縞模様が浮かびます。
AdultShaderS2.fxは、割と一般的にも使えるように設定を柔らかめにしています。
テカテカ感が余り無い代わりに、立体感も多少薄れます。

v0.14から、9点サンプリングVSM方式のソフトシャドウを搭載しました。

【使い方】
モデルにAdultShader.fx(またはAdultShaderS.fx AdultShaderS2.fx以降同じ)を割り当ててください。
[MMEffect]メニューから、[エフェクト割当]を選び、ダイアログ上でモデルを選択して、エフェクトファイルを割り当てます。

【エフェクトのカスタマイズ】
AdultShader.fxの先頭付近を書き換えることで、パラメータの調整ができます。

#define ShadowDarkness 1		// セルフシャドウの最大暗さ
セルフシャドウの濃さです。
この数値を小さくすると、セルフシャドウが薄れます。顔の影などの調整に使ってください。

#define EyeLightPower	2		// 視線方向での色合いの変化
視線方向からの色合いの変化です。
大きくすると、すぐに濃くなります。

#define ToonPower	1			// 影の暗さ
セルフシャドウや、背面の影の濃さです。
大きくすると、暗くなります。

#define OverBright	1.2			// 白飛び覚悟の明るさ補正
暗くなる要素がたくさんあるので、明るくします。
大きくし過ぎると、白飛びします。

<以下は、AdultShaderS.fx, AdultShaderS2.fxのみ>
#define FresnelCoef 0.08			// フレネル項の係数
横向きの面をどのくらい明るくするか。
(この項で、髪の毛などに縞々模様が出ます)

#define FresnelFact	5			// フレネル項
明るくする面の範囲です。大きくすると、狭くなります。

<以下は、共通>
// ソフトシャドウ 補正係数
#define SOFTSHADOW_DISTANCE 0.1	// ソフトシャドウを打ち切る距離(小さいほど遠い)
遠く大きなものの影はソフトシャドウにするとおかしな影になることがあります。
この為、遠いところではソフトシャドウを打ち切るようにしています。
この数値を小さくすると遠いところでもソフトシャドウ化するようになります。

#define SOFTSHADOW_THRESHOLD 0.0005 // ソフトシャドウ補正値 大きいほど影が薄い
あまり小さな値にすると、陰がないはずのところでも影が出てしまうことがあります。
逆に大きすぎると影が出なくなったりします。

// シャドウマップサイズ
#define SHADOWMAP_WIDTH 2048
#define SHADOWMAP_HEIGHT 2048
MMDでは通常シャドウマップサイズは2048x2048ですが、Control-Gを押すと高精細影モードになりシャドウマップサイズが4096x4096になります。
この時はSHADOWMAP_WIDTH、SHADOWMAP_HEIGHTとも4096に設定してください。
