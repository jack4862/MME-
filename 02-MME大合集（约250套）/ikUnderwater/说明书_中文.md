# ikUnderwater

不知不觉做出水中感觉的效果

## ■ 概要

在地面显示焦散（Caustics）的效果。
焦散是指光通过杯中的水或透镜聚集起来的现象。
由于水面起伏波动，映在水底的焦散会摇摇晃晃地晃动。

顺带也会显示神光（God Ray）和水面之类的东西。
水面只有附赠级别的质量。

## ■ 使用方法

1. 把 ikUWController.pmx 和 ikUnderwater.x 放进 MMD。
   ※ 读取 ikUnderwater.x 会花费非常多的时间。

2. 把 ikUWController.pmx 抬高到适当的高度。
   这将成为水面的高度。

3. 从表情变形（Morph）左上角的（眼睛）处，给 ライトR,G,B（Light R,G,B，光 R,G,B）设置适当的值。
   例如 RGB 分别设为 0.1, 0.4, 1.0。
   这将成为神光与焦散的颜色。

4. 试着改变 ikUWController.pmx 的位置与朝向。
   以 ikUWController.pmx 为起点，光会从 Y 轴方向照射下来。

5. 与第 3 步相同，给 フォグ明度（Fog 明度，雾的明度）、フォグR,G,B（Fog R,G,B，雾 R,G,B）设置适当的值。
   例如 フォグ明度 设为 1.0，フォグR,G,B 设为 0.0, 0.2, 1.0。
   这将成为水中整体的颜色。
   也可以使用其他的雾效果。

6. 根据需要把 MMD 的灯光颜色也调成偏蓝色。
   灯光的方向既可以与 ikUWController.pmx 一致，也可以不一致。

7. 描画顺序的设定。基本上按 粒子类 > ikUnderwater > 色调补正类 的顺序输出为好。
   与进行某种描画的效果相性很差。

8. 在 MME 标签中去除多余的项目。
   从 LightSpaceDepth、
   CameraSpaceDepth、
   ReflectionMap、
   RefractionMap 中排除半透明的物体、其他效果等。
   ※ 如果没有出现神秘的方形物体、或者效果部分不生效的症状，就什么都不用做。

9. 适当摆弄表情变形（Morph）的其他项目。

10. 根据需要摆弄 settings.fxsub 的内容。

## ■ 表情变形（Morph）的设置项目

多数表情变形在 0 时会应用默认值。
因此有些项目在 0.000 与 0.001 之间设置会发生很大变化。

- ライト距離、角度（Light 距离、角度）
  - 指定神光与焦散的范围。
- ライトR,G,B（Light R,G,B）
  - 指定神光与焦散的颜色。
- フォグR,G,B、フォグ明度（Fog R,G,B、Fog 明度）
  - 指定水中雾的颜色。
  - 降低明度后，远处会变暗。

- ゴッドレイ強度、コースティクス強度（God Ray 强度、Caustics 强度）
  - 分别指定各自的亮度。
- スペキュラ強度（Specular 强度）
  - 指定水面高光的强度。
- フォグ強度（Fog 强度）
  - 指定水中雾的强度。越大则越靠近相机也会受到雾的影响。
- 深度フォグ強度（深度 Fog 强度）
  - 指定水深越深越暗的雾的强度。

- 波の密度（波の密度，波纹密度）
  - 指定波纹扩散的程度。
- 波の速度（波の速度，波的速度）
  - 指定每帧的变化量。
- 波高（波高，波的高度）
  - 指定波的高度。
  - 只影响水面的外观，不影响焦散与神光。

- エフェクト強度（Effect 强度）
  - 指定效果整体的强度。

## ■ settings.fxsub 的设置项目

在 MMD 运行中改写 settings.fxsub 不会自动应用。
请从 MMEffect 中选择「全て更新」（全部更新）。

各项内容也请参考 settings.fxsub 内的注释。

### □ 与神光有关的项目

RayMarchCount
  每个像素的探索次数。增加后神光会更准确，但运行时的负载与读取时的负载都会增加。设到 64 以上也不会有更好的效果。

FOG_BUFFER_SCALE
  用于神光计算的工作区尺寸。值越大，神光越模糊。越小越清晰，但会变重。

### □ 与水面有关的项目

ENABLE_WATERPLANE
  将其设为 0 后完全不处理水面。
  在深海等不需要水面的场合设为 0。

ENABLE_REFRACTION_MAP
  将其设为 0 后，利用通常的画面进行由水面产生的折射。
  设为 1 时另行创建专用画面。

  设为 0 时，从水中仰望水面之上的情况下，本来是应该看到水面之上的物体的状况，有时却会映出水中之物。浪高的时候等不太会在意。

ENABLE_REFRACTION_EFFECT
  为 0 时，在合成水面图像之后统一施加效果。
  为 1 时，在折射用的工作画面上独立应用水中效果之后再合成。

  为 0 时，从水面之上看水中时，神光与焦散不受波的影响。
  不从水面之上看水面的场合设为 0 即可。

DISTORTION_BUFFER_SCALE
  存放合成水面后所得描画结果的尺寸。越大越轻，但水面会变模糊。

REFLECTION_BUFFER_SCALE
  描绘反射与折射之物的尺寸。越大越轻。

## ■ 已知问题

- 无法正确处理半透明材质。
  当半透明材质被无视水中雾时，试着把 LinearDepth.fx 内的
  ShadowAlphaThreshold 的值调小。
  想要单独调整时，复制 LinearDepth.fx 并修改 ShadowAlphaThreshold。
  把新建的 LinearDepth.fx 分配给想要调整的材质。

  如果因为半透明物体，导致其后方物体的雾变得不自然，
  请从 LightSpaceDepth、CameraSpaceDepth 等中排除半透明物体。

- 从水面之上观看时，与水面的交界很脏。

- 与其他描画类效果相性很差。

- 相机从水面之上移动到水中、以及相反移动时（有时）会看到奇怪的东西。
  相机与水面平行时水面容易出现缺陷。
  快速移动相机。用气泡之类的糊弄过去。

- 雾的颜色设置很麻烦
  需要用 フォグR,G,B、明度、フォグ強度、MMD 的灯光颜色来设置。
  使用色调补正类的效果，或者在视频剪辑时进行色调补正也许更简单。

- 其他整体上，设置都很麻烦。
