# SelfThunder 用法

1. 读取 SelfThunder.x
2. 特效分配 → 在 VertexPosRT 中，对想要噼里啪啦放电的模型应用 SavePos.fxsub
   （其他模型请设为非表示）
3. 在 VertexPos_MaskRT 中，对想要放电的材质应用 SavePos.fxsub（其他全部非表示）
4. 噼里啪啦～

注：顶点数较多的模型看起来大概不太理想
另外，人型模型顶点集中的脸部部分也可能不太理想
