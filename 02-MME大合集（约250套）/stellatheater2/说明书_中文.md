# StellaTheater version 2.0

## 【关于效果】

这是基于实际星表显示真实星空的的效果。
原始数据参照了周年视差观测卫星依巴谷（Hipparcos）的星表（1997）。

## 【使用方法】

请加载以下任意一个文件。

- `hip5000.x`：5,000 颗星版本（到 5.99 等星）
- `hip118217.x`：118,217 颗星版本（到 14.08 等星）
- `hip5000ez.x`：5,000 颗星简易版本（到 5.99 等星）
- `hip118217ez.x`：118,217 颗星简易版本（到 14.08 等星）

刚加载后的状态是正上方为天北极（北极星所在附近）。
向北侧倾斜 25～50 度左右就会接近日本的星空。
装到 dummy 骨骼上操作会比较好。

为了表现地平线的亮度，同捆了已应用夜晚贴图的 `skydome.x`。
按天空球→星空的顺序加载效果会不错。

简易版本虽然在旧的显卡（Shader 2.0）上也能运行，但功能受限。
它无法处理恒星的色彩信息，也很难强调亮星的放大显示。
因为实现方式相当不同，所以在细节处行为也有差异。

## 【再稍微细一点的话题】

因为是星空，所以即使平移摄像机也会显示同一片星空。
因此，Accessory 的 X、Y、Z 参数不起作用。
取而代之的是，在 XYZ 轴上内置了控制功能。

- X 轴：星的大小
  - 值 = -1.0 ～ ∞
  - 大小 = 1.0 + X 轴 * 0.1 + 1（像素）
  - 也就是说，X=10 时为 2 像素，X=90 时为 10 像素

- Y 轴：放大星星的亮度阈值
  - 值 = -4.5 ～ 11.0
  - 阈值 = Y 轴 + 3（等星）
  - 也就是说，Y=0 时为 3 等星，Y=-3.0 时为 0 等星，Y=3.0 时为 6 等星

- Z 轴：给星星带上青色
  - 值 = 0.0 ～ 10.0
  - 红绿的减色 = Z 轴 * 0.1
  - 也就是说，Z=-1 时不减色，Z=10 时变成纯蓝

星星会通过 AutoLuminous 发光。
在 AutoLuminous 原样状态下会看到 Accessory 的 dummy 多边形，因此请对 `AL_EmitterRT` 的 `hip****.x` 应用与 Main 相同的 `.fx` 文件。
想要让它发光更强时，把星星显示得稍大一些会比较好。

另外，因为全规格是 47 万顶点的巨大 Accessory，为了加快读取速度，x 文件已二进制化。
它不像普通 Accessory 那样可以用文本编辑器打开，所以想编辑这里的人请转换成文本格式的 x 文件后使用。
