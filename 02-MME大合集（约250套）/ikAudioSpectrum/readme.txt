■ 使用方法

1. AudioSpectrumLineか AudioSpectrumRing を MMDにいれる。
2. 表情モーフを適当にいじる。

※ 添付のデータは Galaxias! から作成したデータになっています。


■ 好きな音楽のデータを作成する

音声ファイルから、ikAudioSpectrum用のテクスチャファイルに変換する必要があります。

1. Wav2Png/Convert.bat に 適当な .wavファイルをドラッグアンドドロップする。
(音声の長さにもよりますがしばらく時間が掛かります。)

2. できあがった wave.png を ikAudioSpectrum に上書きコピーする。


■ 設定

□ 表情モーフ

開始ノート: 音階のどこから開始するか。0:低い、1:高い
終了ノート: 音階のどこを終点にするか。0:高い、1:低い
　※ 開始ノートと終了ノートの値が近いほど範囲は狭まります。

左右対称: 0.5以上の場合、開始ノート → 終了ノート → 開始ノートとなるようにする。
ノート補間: 0.5未満の場合、ノート間の補間を行う。

移動ノート: ここで指定したノートの音圧に合わせて、アクセサリを前後に動かす。
移動量: 移動量。デフォルトでは移動しない。

回転+: 開始位置を時間でズラす。時計回り、右→左。
回転-: 回転+の逆。

色: 色相を変える。0:赤、0.3:緑、0.6:青
白: 彩度を変える。0:白い、1:原色。
透過: 透明度を指定
明るさ: 明るさ

向き: どちらに波形を表示するか。両方、上(外側)、下(内側)。
スタイル: 表示する形式。
サイズ: 表示サイズ
高さ: 表示サイズ
太さ: 線の太さ
間隔: 線の間隔。スタイルによっては効果がない。

減衰速度: 音圧の下がる速度。
ディレイ: チェックするフレームの遅れ。最大で1秒の遅く反応する。
やわらかさ: 波形を滑らかにする
チャンネル: 左右どちらのチャンネルの音をチェックするか。L+R/L/R


□ エフェクトファイル内

IKAS_OUTPUT_TEX_WIDTH、IKAS_OUTPUT_TEX_HEIGHT
　: 出力用のテクスチャサイズ。大きいほど詳細になりますがメモリを圧迫します。
　小さくしか使わない場合は、小さいテクスチャサイズで十分です。

IKAS_ENABLE_MIPMAP: ミップマップを使用するか。
　ミップマップを使用すると、スペクトルがボケて見えることがあります。
　ミップマップを使わないと、小さくしたときにドットが欠けることがあります。


□ モデル、他

tex/grad.png を書き換えるか、.pmxが参照しているテクスチャを書き換えることで、
全体に色をつけることが可能です。

コンバータの出力した、wave.pngをgimpなどで調整することができます。
Rチャンネルが左、Gチャンネルが右の音になっています。
