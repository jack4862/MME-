# NeonPost（希望能变成霓虹风格的某种东西的特效）

ビームマンP

## 使用方法

扔进 MMD。

修改 fx 内这几行附近：

```
float3 ToonCol = float3(1,0.25,0.25);
float Threshold = 5.0;
float LineSize = 0.50;
```

在 MMEffect 标签的「效果分配」、Main 标签中把模型设为非显示。
进行背景黑化（推荐）。


在读取多个 NeonPost 的基础上，
通过切换 NeonPost_DepthRT 的显示／非显示，
也许可以分别应用、合成、玩出各种花样，也许不行。
