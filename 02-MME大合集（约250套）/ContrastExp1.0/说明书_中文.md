# 对比度调整 ver1.0

- 名称：对比度调整 ver1.0
- 种类：后处理效果
- 支持：MikuMikuEffect ver0.2x 用
- 作者：kion
- 更新日：2011.3.3

## ● 说明

调整对比度的效果。
用指数函数来提高对比度。

## ● 用法

读取 ContrastExp.x。
把 Si 调大，对比度就会变大。
用 X、Y 设置曲线。
用 (Rx,Ry) 设置要调整的颜色范围。以 0～255 指定。
基本上就是改 Si。
把 Y 调大，亮色的变化会变得平缓。
把 X 调大，暗色的变化会变得平缓。
