# FixedCamera.fx ver0.0.3

把运镜固定为正面视角。无论 MMD 的摄像机如何操作，都始终是正面视角。
视角（视野角）也固定为 45ﾟ。
本效果是改造 舞力介入P 氏的 full.fx 制作而成的。

## 使用方法

(1) 把 PMD 名从 XXXXX.pmd 改为 XXXXX[FixedCamera.fx].pmd，或者把 FixedCamera.fx 改为 XXXXX.fx。
(2) 把更改后的 PMD 载入 MMD。
(3) 对位请先将 MMD 的摄像机置于启动时的正面视角之后再进行。
    如果只靠骨骼移动无法完全对上，请适当更改 FX 内的开头参数。
(4) 骨骼操作因为视角不会旋转而比较难做。建议在效果 OFF 的状态下进行动作制作。
(5) 显示虽然固定为正面，但实体（骨骼・刚体）仍在原来的坐标上，所以同一坐标上若有其他模型会发生物理干涉。

## 问题点

坐标原点离屏幕越远，边缘会越粗（边缘描画为 MMD 标准的情况）。
坐标原点来到屏幕前方时，会不再产生自阴影。
操作摄像机会使自阴影出现闪烁。

## 注意点

边缘描画为独自规格的情况下，默认会对所有顶点进行边缘描画。
连 PMD 材质中设定为边缘 off 的地方也会描画边缘，所以根据模型不同，
尤其是表情等的氛围可能会发生变化。因此需要按模型指定边缘材质。

请先用 PMDEditor 确认正在描画边缘的材质，然后在 FixedCamera.fx 的开头参数中指定要描画的材质。
材质指定方法如下记所述。〈摘自 MMEffect 的 REFERENCE.txt〉
　　"0,3,5" 这样用逗号分隔列举编号，即可指定多个编号。
　　另外，"6-10" 这样用连字符连接编号，即可指定范围。
　　"12-" 这样只指定范围的起始编号时，其后的所有编号都会成为对象。

例　あにまさ式 標準ミクv1.3
#define EDGE_ON   "0-4"   // 描画边缘的材质编号

例　Lat式ミクVer2.3_Normal.pmd
#define EDGE_ON   "1,3-5,7-11,13,24,27"   // 描画边缘的材质编号
