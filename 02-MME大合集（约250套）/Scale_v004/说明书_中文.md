# Scale.fx ver0.0.4

只是单纯改变模型的缩放（Scale）。
通过控制模型的骨骼操作与表情设定，可以变更全部参数。
本效果是改造舞力介入P 氏的 full.fx 制作而成。

## 使用方法
1. 给 PMD 或者附件套用 Scale.fx。
   - 使用 GUI 时：从「MMEffect」→「效果分配」的主标签页中，给想套用的对象分配 Scale.fx。
   - 使用文件名设定的情况：把 XXXXX.pmd 改名为 XXXXX[Scale.fx].pmd，或者把 Scale.fx 改名为 XXXXX.fx 后载入。
2. 把 ScaleControl.pmd 载入 MMD。
3. 模型绘制顺序中，把 ScaleControl.pmd 放在所套用对象的紧前面。
4. 用 ScaleControl.pmd 的骨骼与表情滑块可进行以下控制。
   - 骨骼
     - `ｽｹｰﾙ原点`（缩放原点）：以该坐标为中心进行缩放变更。
     - `ｽｹｰﾙ変更`（缩放变更）：坐标位置在 XYZ 各自 -20～+20 时，以指数函数方式缩放到 0.01～100 倍。
   - 表情滑块
     - 拡大（放大）：XYZ 等倍地缩放到 1～10 倍
     - 縮小（缩小）：XYZ 等倍地缩放到 1～0.1 倍
