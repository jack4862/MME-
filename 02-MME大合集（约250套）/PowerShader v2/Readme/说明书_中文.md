# 发光效果 AutoLuminous Ver.4.2

制作：そぼろ

这是继 KeyLuminous、ObjectLuminous 之后的第 3 弹发光效果。
可以让指定的部位看起来在发光。

## ■ 运行环境

- 支持着色器模型 3.0 以及浮点纹理 Mipmap 的显卡（推荐 DX10 世代以后）
- MikuMikuEffect 0.27 及可运行它的 MikuMikuDance
- MikuMikuEffect x64 0.32 及 MikuMikuDance x64
- MikuMikuMoving 1.1.8.1 以后

测试环境：
　Win7 x64 + Phenom II X6 + GTS450
　Win7 x64 + Core i7 2677M + Intel HD Garphic

## ■ 使用方法

### □ 指定发光部分

本效果通过改造模型或 Accessory 来指定发光部分。

指定方法是：把想发光的材质的镜面反射色（Specular 色／反射色）设为黑色 (0,0,0)，把镜面反射强度（Specular 强度／反射强度）设为 100 以上。
这种组合通常不会被使用，因此发生非预期发光的可能性很低。

镜面反射强度的标准值为 110。
总之想让它发光时请使用此值。
在此之上或之下增减时，发光强度会与「镜面反射强度减去 100 后的值」成比例地上下变化。

发光颜色由漫反射色（Diffuse 色）与环境色（Ambient 色）自动决定。

### □ 读入 MMD

读入如上改造后的模型后，读入 AutoLuminous.x 加载效果，指定部分就会发光。

如果是 MMM，读入的是 AutoLuminous.fx。

### □ 参数操作

通过更改 AutoLuminous.x 作为 Accessory 的值，可以操作效果的参数。

若在视频内始终使用固定设定，直接输入数值即可；若要动态变化，推荐安装到假人骨骼上。

- **Si：发光强度**
  指定发光部分光的强度。

- **Tr：模糊强度**
  指定发光部分模糊的强度。
  无法调大。
  这是因为原本的模糊强度已经被设定得相当大。
  即便如此仍想调大的话，需要直接编辑效果。

---

- **X：光芒方向数**
  指定光斑（Glare）伸展的方向数量。
  请注意 1 个方向会向相反方向也伸出光。
  例如指定 3 就会伸出 6 条光芒。
  适当值约为 0～9。
  请注意数量越多负荷越大。
  另外，增加后有时会比预想的更亮。

- **Y：原画面亮度**
  增减原屏幕画面的亮度。
  适当范围约为 -100～100。
  设为 -100 时原屏幕会完全变黑。

- **Z：发光强度**
  只是数值的指定方法不同，效果与 Si 相同。
  适当范围约为 -100～500。
  -100 与 Si=0、100 与 Si=2 有相同的效果。
  这是设想从假人骨骼操作发光强度的情况。

---

- **Rx：光芒角度**
  按指定的角度偏移光斑的角度。

- **Ry：光芒长度**
  增减光斑的长度。
  适当范围约为 -100～100。
  拉得太长会出现条纹。

- **Rz：闪烁周期**
  让发光闪烁。输入的数值直接就是以秒为单位的闪烁周期。
  正数用正弦波闪烁，负数用矩形波闪烁。
  设为 0 则停止闪烁。

## ■ 用法的扩展

### □ ObjectLuminous 兼容功能

AutoLuminous 与 ObjectLuminous 同样，可以适用以下使用方法：

- 使用选择器效果（Selector Effect）
- 对个别材质套用单色效果
- 从 MME 标签页「解除」材质

各项详情请参阅 ObjectLuminous 的 Readme 及各种解说。
ObjectLuminous 用的选择器效果可以直接使用。

### □ 与 KeyLuminous 的兼容功能

与 KeyLuminous 一样，可以指定画面上的关键色（Key Color）使其发光。
因为必须编辑效果，详情在上級編中解说。

### □ 直接编辑效果

有一些参数为了变更必须直接编辑效果。
这需要一定程度的效果知识。

这些参数包括：模糊范围、采样数、背景色等。
各项目的说明记载在效果文件中。

尤其是采样数，在以全高清级大分辨率输出时，标准的采样数完全不够、会出现条纹，因此必须把值调大。
不过采样数增加当然会变重。

### □ 通过追加 UV 进行逐顶点发光控制

仅限 PMX，使用追加 UV 功能可以更灵活地进行逐顶点的发光控制。
详情在上級編中解说。

## ■ 轻量效果「AutoLuminousBasic」

AutoLuminousBasic 是在 AutoLuminous 过重、无法运行时，只使用最小限度功能的轻量版效果。
虽然大幅变轻，但功能与描画品质都受限，也无法与其他效果联动。
品质大致相当于 ObjectLuminous。

请认为它能做的只是让 AL 对应模型简单地发光。

## ■ 对应模型的配布

把镜面反射改为特殊规格以对应 AutoLuminous 的模型，若能在 Readme 等中写上「AutoLuminous 対応」（支持 AutoLuminous），我想会提升易用性。

另外此时，推荐设定为在读取未改造的 AutoLuminous 的默认状态下、发光强度也不会产生违和感。

另外，若使用了 2.0、3.0 以后的新功能，推荐追加促使用户升级 AutoLuminous 版本的文字。

不过，这些完全不具有强制性。

## ■ 疑难解答（Troubleshooting）

请从上往下依次尝试。

- **报错无法运行**
  →请确认 MME 为 Ver.0.27 以上
  →请试着重新下载
  　→很遗憾，很有可能是显卡不支持

- **不报错但无法正常运行**
  →请确认在只有示例与 AutoLuminous 的状态下是否能正常运行
  →请确认 AutoLuminous.x 的位置或尺寸等是否变成异常值
  →请试着重新下载
  　→很遗憾，很有可能是显卡不支持
  　→若怀疑是 bug，请在 Twitter 等上报告

- **材质形态键没有反映**
  →因为按 MME 的规格无法正常取得形态键之后的颜色。
  　从 Ver.3.5 起镜面反射强度与 Alpha 会得到反映。
  　在 MMM 中可以使用材质形态键。

- **太重无法正常作业**
  →请编辑效果，把 HALF_DRAW 设为 1。
  　画质会下降但会变轻。
  →请编辑效果，把 HDR_RENDER 设为 0。
  　功能会受限但会变轻。
  →请试着减少采样数。
  →请试着使用 AutoLuminousBasic。
  →请研究用 ObjectLuminous 或 KeyLuminous 代替
  　→换掉 PC 或显卡

- **不想发光的部分擅自发光**
  →如果是加算球面（加算スフィア）发光，请对该模型套用 Options 文件夹的 full_saturate.fx
  →在 MME 的分配标签页中选择 AL_EmitterRT，
  　对不想发光的模型分配 "AL_BlackMask.fx"。
  →请编辑效果，把 HDR_RENDER 设为 0。
  →把 KEYCOLOR_NUM 设为 0，试着关闭关键色发光功能。

- **Accessory 该怎么编辑**
  →X 文件可以用记事本打开直接改数值
  →……因为这样实在不太好，所以在 Readme 上級編中
  　追加了关于用 PMDE 编辑 Accessory 的说明。

# MikuMikuEffect 用扩散滤镜（Diffusion）

製作：そぼろ

通过操作 Tr（透明度）可以控制特效的强度，通过 Si（尺寸）可以控制模糊范围。

默认设置有点偏强，请酌情调整。

通过移动附件的位置可以进行简易色调补正。
X、Y、Z 分别对应 R、G、B，在 -1.0～1.0 的范围内变化颜色的强弱。

其他用于调整的参数都集中在特效文件的开头，请酌情修改。
从 Ver.7 起，可以更详细地设定合成方式。
