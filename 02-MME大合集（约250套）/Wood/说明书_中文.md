# Wood README

这是从 AMD RenderMonky 1.82 的示例 "Wood" 中的 "Wood0" 转换而来的东西。
是木纹着色器。

## 关于示例 PMM 文件

在 MMD 中读取之前，需要做以下准备。

(1) 请将 "Wood.fx" 和 "NoiseVolume.dds" 复制到 UserFile\Model\ 中。
(2) 请以 "初音ミクVer2[Wood.fx].pmd" 这一名称，创建 "初音ミクVer2.pmd" 的副本。

## 通常的使用方法

- 如上述示例那样，在设定为使用 "Wood.fx" 来绘制要应用特效的物体之后，
  再在 MMD 中读取。

## 注意事项

- 不支持自阴影（SelfShadow），请将其设为 OFF。
