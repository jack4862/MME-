# FireParticleSystemGrv

这是对 FireParticle.fx 的改造。

## 追加的参数说明

```
//重力の向き（重力方向）
float3 particleGravityVec
```
表示重力的方向。初始值为向下。

```
//重力の強さ（重力强度）
float particleGravity
```
表示重力的强度。设得越强，受到重力的影响就越大。

```
//重力曲線の係数（重力曲线系数）
int particleGravityPow
```
这是控制受到重力时所循曲线的系数。
具体来说，
- 1：一次函数，直线
- 2：二次函数，抛物线
- 以下依次为三次、四次……
