# ScreenTex.fx ver0.0.4
# ScreenTexPmd.fx ver0.0.4
# Post_ScreenTex.fx ver0.0.4

把贴图缩放为画面尺寸后贴上去。适合用于画框的描画，
以及把物体用贴图的正面与背面来分开。
贴图会显示静态图片、动画贴图、`Screen.bmp` 中的任意一种。
可以进行色彩键（Color Key）透过设定。`ScreenTexPmd.fx` 是 `ScreenTex.fx` 的 PMD 版。
`Post_ScreenTex.fx` 是 `ScreenTex.fx` 的后处理效果版。
这是改変舞力介入P 氏的 `laughing_man.fx` 后制作的。

## ・ScreenTex.fx 使用方法

(1) 把 `ScreenTex.x` 加载到 MMD 中。在 MMM 中直接加载 `ScreenTex.fx`。

(2) 用 `ScreenTex.fx` 开头的参数指定要贴上去的贴图文件名。

(3) 用 MMD 的 Accessory 参数进行以下变更并登录关键帧。
    `X,Y,Z`：色彩键透过所用的 RGB 色（0～1）。
    `Rx`：色彩键的阈值（为 0 时不进行色彩键透过）。
    `Tr`：贴图的透过设定
    在 MMM 中可以从追加到效果属性的 UI 控件进行色彩键设定。

## ・ScreenTexPmd.fx 的使用方法

(1) 把 `ScreenTexPmd.pmd` 加载到 MMD 中。

(2) 用 `ScreenTexPmd.fx` 开头的参数指定要贴上去的贴图文件名。（无法选择 `Screen.bmp`）

(3) 用 `ScreenTexPmd.pmd` 的表情滑块进行以下变更并登录关键帧。
    　目：key红, key绿, key蓝 → 色彩键透过所用的 RGB 色
    　ﾘｯﾌﾟ（唇）：key阈值 → 色彩键的阈值（为 0 时不进行色彩键透过）。
    　その他（其他）：透明度 → 贴图的透过设定

(4) 通过描画顺序，可以在 PMD 内把贴图的正面与背面分开。
    不过由于 MMD 的规格，只有 PMD 的边缘会保持显示状态。要避免这一点
    需要独自描画边缘。（请使用 `EdgeControl.fx` 等。）

## ・Post_ScreenTex.fx 使用方法

请把 `Post_ScreenTex.x` 加载到 MMD 中。用法与 `ScreenTex.fx` 相同。
这个是作为后处理效果运行的。它可以在不受 DOF 等其他后处理效果
影响的情况下描画（不过只能贴在正面）。
描画顺序请务必放在其他后处理效果之后。

这个 fx 文件只有 MME ver0.24 以后才能正确运行。
