# 天堂滤镜（ヘブンフィルター） ver0.0.1

这是用来做类似「天堂状态」演出的效果。姑且算是面向剧情片制作的。
可能不太适合把镜头转来转去的那种用法。

准备了两种：一种是施加在特定物体周围的（Heaven_Back.fx、Heaven_Flont.fx），
另一种是全屏的（Screen_Heaven_Back.fx、Screen_Heaven_Flont.fx：镜头固定）。

本效果是改 dancer 舞力介入P 氏的 laughing_man.fx、FireParticleSystem.fx 制作而成。

## Heaven_Back.fx、Heaven_Flont.fx 使用方法

1. 将 Heaven_Back.x、Heaven_Flont.x 载入 MMD。
2. 绘制顺序请设为 Heaven_Back.x → 目标模型 → Heaven_Flont.x。
3. 根据需要修改 fx 文件开头的参数。
4. 用 MMD 通常的附件参数来设置位置、大小、透明度。

## Screen_Heaven_Back.fx、Screen_Heaven_Flont.fx 使用方法

1. 将 Screen_Heaven_Back.x、Screen_Heaven_Flont.x 载入 MMD。
2. 绘制顺序请设为 Screen_Heaven_Back.x → 目标模型 → Screen_Heaven_Flont.x。
3. 根据需要修改 fx 文件开头的参数。
4. MMD 的附件参数只能使用 Tr（透明度）。
