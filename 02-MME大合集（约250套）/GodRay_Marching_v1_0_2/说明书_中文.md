# ゴッドレイマーチング（God Ray Marching）使用方法

制作者：ビームマンP
基础及代码参考：AutoReflection（柄杓 氏）

## 使用方法

1. 将 GodRay_Marching.pmx 载入 MMD。
2. 载入天空穹顶式的模型，或者随附的 黒背景.x、白背景.x。
3. ぺかぁ（亮起来吧）
5. 想让神光光线穿透的模型，请从特效分配的「EnvMap」「PosMap」中设为不显示。粒子之类的也先去掉吧。

## Morph 说明

基本如其名。

## 进阶用法

用记事本等打开 GodRay_Marching.fx，

```
//ループ数（精度。スペックの許す限り上げるといいとおもう）
//美しさを求めるなら512とか？ＰＣ爆発するかもだけど。
int LoopMax = 256/LOCAL_LOOP;
```

改写这里的数字即可提升精度、变得更漂亮。
不过会越来越重。加油吧。
