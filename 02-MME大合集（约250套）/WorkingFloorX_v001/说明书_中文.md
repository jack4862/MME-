# WorkingFloorX.fx ver0.0.1

进行地板镜面描画＋X 阴影描画。
这是在以前制作的 WorkingFloor2.fx 上追加 X 阴影的版本。
X 阴影参考了 mqdl 氏的 xshadow.fx。

只需读取一个效果模型，就能给所有人型模型追加 X 阴影。
X 阴影的尺寸由模型的大小、浓度由光的强度自动调整。

## 使用方法
1. 请把 MMD 的地面阴影设为不显示。
2. 把 WorkingFloorX.x 载入 MMD。
3. 在 WorkingFloorX.fx 开头部分离屏渲染（Offscreen Render）定义的指定位置，追加要适用的模型。
   默认情况下所有的 PMD、PMX 都已适用。

   例）适用 初音ミク.pmd、鏡音リン.pmd、negi.x 时的记述方法

   ```
   "初音ミク.pmd = WF_Object.fx;"
   "鏡音リン.pmd = WF_Object.fx;"
   "negi.x = WF_Object.fx;"
   ```

4. 用 MMD 的附件参数进行以下变更并登录关键帧。
   - Tr：地板镜面的透过度
   - 用其他参数设定地板的描画范围。
     关闭效果时 WorkingFloorX.x 的白色板面之内即为描画范围。
5. 关于 X 阴影，请根据需要修改 WF_XShadow.fx 开头的参数。
6. 绘制顺序请设定为：背景舞台 → WorkingFloorX.x → 其他物体。

把 Tr 设为 0 也可以只显示 X 阴影，但内部仍然进行镜面描画，会造成处理上的浪费。
若想完全去掉镜面描画处理，建议改写 WorkingFloorX.fx 开头的参数。

## 应用
把 WorkingFloorX.x 替换为其他形状的模型，即可配合舞台的形状来限制镜面描画的范围。
