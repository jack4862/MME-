# NewBomb（爆炸效果）

ビームマンP（BeammanP）

## ---使用方法---

### ・pmx 版

载入 NewBomb.pmx
用表情（モーフ）设置参数

### ・配件版

载入 NewBomb_AC.x 与 NewBombController_0.pmx
坐标等通过把 NewBomb_AC.x 挂在假骨骼（ダミーボーン）等上来操作
参数用 NewBombController_0.pmx 来操作

即使载入多个 NewBomb_AC_0.x，也能用一个 NewBombController_0.pmx 操作全部。

另外，若想让它们各自做不同的动作，请复制 NewBomb_AC_*.x、NewBomb_AC_*.fx、NewBombController_*.pmx 并修改数字后，
用记事本等打开 NewBomb_AC_*.fx，把写着

```
//コントローラ名
#define CONTROLLER "NewBombController_0.pmx"
```

的部分中的数字改成刚才的数字。

例：
NewBomb_AC_1.x、NewBomb_AC_1.fx、NewBombController_1.pmx
