# ActiveParticle.fx ver0.0.1 / ActiveParticleR.fx ver0.0.1

只在物体正在移动时放出贴图粒子。
由于放出的粒子数量与放出位置会根据物体的移动量进行调整，因此无论怎样移动物体，
粒子都会均匀地扩散开来。
替换贴图还能实现各种粒子表现。
准备了通常版（ActiveParticle.fx：粒子始终朝向正面的公告板）与 3D 旋转版
（ActiveParticleR.fx）两种。

## ActiveParticle.fx、ActiveParticleR.fx 使用方法
1. 请把 ActiveParticle.x、ActiveParticleR.x 载入 MMD。
2. 绘制顺序请尽量设定在后面。
3. 把 ActiveParticle.x、ActiveParticleR.x 挂到适当的骨骼上并移动，粒子就会配合动作被描画出来。
4. 请根据需要修改 fx 文件开头的参数。
   默认使用同梱的 sample.png（心形）作为样例贴图，
   但替换贴图文件后也能实现其他的粒子表现。
   要处理多种贴图时，需要把同尺寸的贴图横向排成一列做成一张图像文件。
5. 用 MMD 的附件参数可以进行以下变更。
   - Si：粒子的放出量
   - Tr：粒子的透过度

## 注意点
一次描画的粒子数量最多为 4096。若出现要产生更多粒子的状况，
则在正在发生的粒子消失之前，不会再放出新的粒子。

※ 要在 MME 中使用本 FX 文件，必须使用支持 VTF（Vertex Texture Fetch）的 SM3.0 显卡。
