# 简易抠像效果 v0.5（お手軽キーイングエフェクト / o_postKeying）

## 前言

本效果使用离屏渲染目标（offscreen render target），通过指定「要保留的对象」和「要消除的对象」，以仿佛用抠像（keying）抠出来一样的状态进行输出。

由于是在进行通常的渲染之后再做抠取作业，所以即使使用了不支持透明化的效果，也可以只输出模型。

＊　注意　＊
基本上是以对由不透明对象构成的项目进行分割输出为前提。

虽然已尽量做到在抠出半透明材质、以及用半透明材质进行抠取时也能大致运作，但由于 MMD 的规格或本人能力不足，很多时候可能无法输出正确的颜色。请当作「总比抠不出来好」，并多方尝试 noDRAW 与背景有无等各种组合。

## 关于透明度对应

由于本效果是以 α 输出为前提的，因此并未设想做成不透明的情况。
输出时请务必使用支持透明度的编解码器。

想使用白色背景或黑色背景时，只要把该颜色的位图图像读入作为背景图像即可解决。

＊　注意　＊
- 由于规格上的原因，在透明度有效、而 MMD 的预览等会忽略透明度的场合，与透明部分的交界处看起来会很脏。
- 由于 MMD 的规格，在透明度有效状态下输出时，若未读入不透明背景，就无法显示正确的颜色。
- 进行 AVI 输出时，请使用 Ut Video Codec RGBA(ULRA) 等支持透明度的编解码器。
- 模型半透明部分较多时，并用 o_disAlphaBlend 有可能抠得更漂亮。

## 内含文件

- o_postKeying.fx
  用于在 MMD 上简便地输出经过抠像处理后影像的效果。

- o_postKeying.x
  用于在 MMD 中使用上述滤镜的附件文件。

- Black.fx
  在离屏目标中使用的专用着色效果。
  被指定了本效果的对象会以透明状态输出。
  ※初始设置下所有附件都会变透明，因此手持附件等请指定 White.fx。

- White.fx
  在离屏目标中使用的专用着色效果。
  被指定了本效果的对象在抠取之后，会照原样输出。
  ※初始设置下所有模型（.pmd、.pmx）都会变成不透明，因此舞台等请指定 Black.fx。

  地面阴影会显示出来，如果素材不需要，请在 MMD 一侧把地面阴影设为非显示。

- noDraw.fx
  在以背景素材形式输出视频时，若只想对用于抠像叠加的角色做非显示，
  请在 MME 的「Main」标签中指定给想要叠加的对象。

  使用这些文件，可以做到只让一部分模型保持非显示、而仍然绘制到阴影或 Working Floor2 上等。

- 説明書.txt
  本文件。请先阅读。

## 使用方法

在可以使用 MikuMikuEffect 的 MikuMikuDance 中添加附件 o_postKeying.x。
它会被附件的绘制顺序影响，因此请设定为「必定在最后绘制」。

- 在 MME 的效果分配的「KeyingMapRT」标签中，对想保留的对象指定「White.fx」，
  对想消除的对象指定「Black.fx」，然后进行 RGBA 输出，即可输出经过抠像处理的视频、静态图像。

- 在输出用于叠加上述已抠像视频的背景视频时，对指定了 White.fx 的模型在
  「Main」标签中指定「noDraw.fx」即可让模型非显示，而阴影与工作地板等仍可保持显示。
  SSAO 等也会被处理，因此请务必在该效果的 RT 标签中把相应模型设为非显示。

- 可通过附件操作设置的内容

  Tr：指定切取部分的透明度。虽然想着「有总比没有好」而实现了它，但基本上请以 1.0 使用。

  Si：补正切取部分的透明度。1.0 为无补正。
  　　当背景位于不透明部分的范围内时，模型的半透明部分越大越偏向透明，越小越偏向不透明。

- 可通过改写效果文件设置的内容

  SHOW_KEYING_MAP：设为 0 时正常应用效果（初始值），设为 1 时显示用于抠取的地图。
  　　　　　　　　 虽然是为测试而实现的，但基本上请保持初始值 0 使用。

  TRANSPARENT_MODE：设为 0 时对背景做透过处理（初始值），设为 1 时半透明部分会变为不透明，
  　　　　　　　　　只存在透明或不透明两种。
  　　　　　　　　　虽然是为测试而实现的，但基本上请保持初始值 0 使用。
