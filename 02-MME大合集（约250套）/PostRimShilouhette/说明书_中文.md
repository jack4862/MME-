# PostRimShilouhette

利用模型轮廓的伪边缘光（拟似リムライト）效果。
通过法线进行缩小或偏移，让用轮廓做出的边缘光发光。
也支持 MMM。

## 使用方法

- 将 PostRimShilouhette.x 载入 MMD。（MMM 的情况下载入 PostRimShilouhette.fx）
- 载入 RimShilouhetteCTR.pmx 并通过控制器操作。
  单独用 x 文件也可以操作，但发光功能的调整需要 pmx 控制器。
- 想进一步调整时，请修改 PostRimShilouhette.fx 或 RimMask.fx。
  不需要发光功能时，修改 fx 文件将其关闭会更轻量。

## 设定参数

- PostRimShilouhette.x（MMM 时为 PostRimShilouhette.fx）
  XYZ　边缘光的方向
  Rxyz 边缘光的颜色
  Si　边缘光的宽度
  Tr　整体强度（边缘光与发光功能两者）
  ※发光功能的调整只能用 pmx 控制器进行。

- RimShilouhetteCTR.pmx
  骨骼
  ﾘﾑﾗｲﾄ XYZ（边缘光 XYZ）　边缘光的方向。（旋转无效。与 ～.x 的 XYZ 相同）
  RGB XYZ　边缘光的颜色。（XYZ 对应 RGB。与 ～.x 的 Rxyz 相同）

  变形（モーフ）
  幅太く・細く（加宽・变细）　边缘光宽度的调整
  ﾘﾑﾗｲﾄ弱・強（边缘光弱・强）　边缘光单独的强度。即使关闭，发光功能仍会保留。
  発光強く・弱く（发光强・弱）　发光功能单独的强度。即使关闭，边缘光本身仍会保留。
  ぼかし広く・狭く（模糊宽・窄）　发光宽度的调整
  Red・Green・Blue　色调（与 ～.x 及骨骼的 RGB 相同）

## 使用上的注意

- 有天空穹顶（スカイドーム）或全面背景时，必须在 RT 标签页中取消勾选。
- 不需要发光功能时，请在 PostRimShilouhette.fx 内的模糊标志前加上「//」将其关闭。
- 通过 fx 文件的设定可以改为屏幕合成。好不好用我不太清楚。
- 通过 fx 文件的设定，可以让边缘光的颜色使用模型的颜色。
- 将背景设为透明进行 alpha 抠图时，也许把 fx 文件开头的背景色设为 {1, 1, 1, 0} 比较好。
- 存在半透明材质时，半透明部分会发光。要防止发光，请在 RimShilouhette 标签页中应用 BlackMask.fx。
