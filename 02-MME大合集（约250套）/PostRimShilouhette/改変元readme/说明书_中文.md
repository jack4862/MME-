# EdgeControl.fx ver0.0.5 / EdgeControl_MMM.fxm ver0.0.5

不使用 MMD 标准的边缘描画，而是用着色器进行独自的边缘描画。
由于边缘的粗细是根据顶点与摄像机位置的距离决定的，因此可以避免在摆放位置、摄像机角度以及巨大模型上边缘变得过粗的弊害。
另外，也可以给 Accessory（附件）加上边缘。

## 使用方法

### MMD・MME 版的情况

1. 对 PMD、PMX 或 Accessory 应用 `EdgeControl.fx`。
   使用 GUI 时：从「MMEffect」→「效果分配」的 Main 标签中，对想要应用的对象分配 `EdgeControl.fx`。
   使用文件名设定的情况：把 `XXXXX.pmd` 改名为 `XXXXX[EdgeControl.fx].pmd`，或者把 `EdgeControl.fx` 改名为 `XXXXX.fx` 后加载。
2. 适当修改 `EdgeControl.fx` 开头的参数。
3. 把 `EdgeController.pmd` 加载到 MMD 中。
4. 在模型描画顺序中，把 `EdgeController.pmd` 放在所应用对象的紧前面。
5. 用 `EdgeController.pmd` 的表情滑块各项可以进行如下控制。
   - 目：颜色控制 ON → 滑块左侧为 OFF，变成 MMD 标准的边缘色；右侧为控制器指定的颜色。
   - ﾘｯﾌﾟ（唇）：边缘红、边缘绿、边缘蓝 → 以 RGB 指定边缘色。
   - まゆ（眉）：边缘细 → 让边缘变细。
   - その他（其他）：边缘粗 → 让边缘变粗。

（注：原文第 (5) 条写作「ColorControl.pmd」，与第 (3)(4) 条的 EdgeController.pmd 不一致，此处照原文保留。）

### MikuMikuMoving 版的情况

1. 把 `EdgeControl_MMM.fxm` 加载到 MMM 中。
2. 从 MMM 菜单的「文件」→「效果分配」中选择想要应用的模型，分配 `EdgeControl_MMM`。
3. 根据需要适当修改 `EdgeControl_MMM.fxm` 开头的参数。
4. 可以从 MMM 的效果属性中追加的 UI 控件修改参数。

## 注意点

若要以 MMD 标准的边缘色进行描画，必须先让画面处于已经描画了边缘的状态（有 PMD・PMX 模型且未处于骨骼选择状态），否则无法正常显示。另外，能给 Accessory 加上边缘的只有在颜色控制 ON 的时候。

默认设定下会对所有顶点进行边缘描画。
由于连 PMD 材质中设定为边缘 off 的地方也会描画边缘，因此根据模型不同，尤其是表情等处的氛围可能会发生变化。因此需要针对每个模型指定要描画边缘的材质。

请先用 PMDEditor 确认正在描画边缘的材质，然后在 `EdgeControl.fx` 开头的参数中指定要描画的材质。
材质指定方法如下记述。＜摘自 MMEffect 的 REFERENCE.txt＞

> 像 `"0,3,5"` 这样，用逗号分隔列举编号，即可指定多个编号。
> 另外，像 `"6-10"` 这样用连字符连接编号，即可进行范围指定。
> 像 `"12-"` 这样只指定范围的起始编号时，该编号之后的所有编号都成为对象。

例　あにまさ式 標準ミクv1.3

```
#define EDGE_ON   "0-4"   // エッジを描画する材質番号
```

例　Lat式ミクVer2.3_Normal.pmd

```
#define EDGE_ON   "1,3-5,7-11,13,24,27"   // エッジを描画する材質番号
```

# M4Layer

离屏渲染（Offscreen Rendering）图层。

## 概要

这是一个用于对后处理效果（Post Effect）执行类似图像编辑软件中图层混合模式那种合成的后处理效果。
另外，还可以通过蒙版（Mask）只对特定部分应用。
默认状态下它什么都不做，请编辑参数后使用。

## 可用的合成方法

通过编辑 `M4Layer.fx` 的 `LAYER_MODE` 即可选择合成方法。
各合成模式的含义大体上与市面上常见的图像编辑软件相同，
用名称去搜索应该就能明白。此外，Photoshop 或 Fireworks 的帮助文档里也有说明。
http://help.adobe.com/ja_JP/fireworks/cs/using/WS4c25cfbb1410b0021e63e3d1152b00d169-7fd8.html#WS4c25cfbb1410b0021e63e3d1152b00d169-7fd5

- 0: 正常
- 1: 加法
- 2: 减法
- 3: 乘法
- 4: 滤色（Screen）
- 5: 叠加（Overlay）
- 6: 强光（Hard Light）
- 7: 柔光（Soft Light）
- 8: 亮光（Vivid Light）
- 9: 线性光（Linear Light）
- 10: 点光（Pin Light）
- 11: 颜色减淡（Color Dodge）
- 12: 颜色加深（Color Burn）
- 13: 变暗
- 14: 变亮
- 15: 差值（差的绝对值）
- 16: 排除

- 17: 色相：将前景的色相合成到背景的饱和度与亮度上。
- 18: 饱和度：将前景的饱和度合成到背景的色相与亮度上。
- 19: 颜色（色相与饱和度）：将前景的色相与饱和度合成到背景的亮度上。
- 20: 亮度：将前景的亮度合成到背景的色相与饱和度上。

## 使用方法

先加载其他的后处理效果，然后在效果分配中通过 `LayerRT` 对该后处理效果打勾启用，
再试着改变 `LAYER_MODE`。
例如：加载一个会把画面变成灰度的效果，再加载本效果，然后把 `LAYER_MODE` 设为叠加（Overlay）。

另外，在 `LayerRT` 上分配任意的着色器类效果，即可选择着色器类效果的合成方法。
其他还可以试着调整描画顺序和效果分配，会很有趣。
比如把粒子类效果的 `.fx` 分配到粒子 `.x` 上，或者对复合后处理效果随意分配本体以外的 `.fx` 之类。

通过 `Tr` 与 `Si` 值可以调整图层与原图像的合成率。
`Si * Tr` 为 1 时完全合成，为 0 时保持原图像不变。
`Si` 也可以取大于 1 的值或负值。

### 蒙版的使用方法

在 `LayerMaskRT` 中分配了 `InvisibleMask.fx` 的部分不会受到图层合成的影响。

## 其他

- 也可以用来在应用后处理效果的同时只让一部分以通常方式描画，
  但若为此用途，数据P 的 `Exclude` 应该是最强的，所以用那个比较好。
- 或许把它当作效果制作者/改编者复制粘贴合成方法公式的源码来用，才是它最正确的用法。
  它原本是为了把 PostRimLighting 的加法合成部分通用化而制作的，所以整个挪用也没问题。
