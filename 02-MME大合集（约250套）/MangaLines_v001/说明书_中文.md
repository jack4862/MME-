# MangaLines ver0.0.1

这是漫画、动画的效果线（速度线）效果。
准备了集中线（MangaLines_Center.fx）与平行线（MangaLines_Parallel.fx）两种。
也可以通过贴图动画（Texture Animation）让效果线动起来。

## ・MangaLines_Center.fx 使用方法
1. 请把 MangaLines_Center.x 载入 MMD。
2. 绘制顺序请尽量设定在后面。
3. 请根据需要修改 fx 文件开头的参数。
4. 用 MMD 的附件参数可以进行以下变更。
   - XY：线的中心位置补正（画面中心为 0，画面端为 -1、+1）
   - Z ：0 则无动画，Z>0 则为有动画的线长
   - Ry：线的粗细调整
   - Rz：集中线中心空白的大小
   - Si：动画时线的速度
   - Tr：线的透过度（淡入淡出进度）

## ・MangaLines_Parallel.fx 使用方法
1. 请把 MangaLines_Parallel.x 载入 MMD。
2. 绘制顺序请尽量设定在后面。
3. 请根据需要修改 fx 文件开头的参数。
4. 用 MMD 的附件参数可以进行以下变更。
   - XY：线的位置补正（画面中心为 0，画面端为 -1、+1）
   - Z ：0 则无动画，Z>0 则为有动画的线长
   - Ry：线的粗细调整
   - Rz：线的旋转角
   - Si：动画时线的速度
   - Tr：线的透过度（淡入淡出进度）
