# Line 特效 v4 使用方法

制作者：ビームマンP

这是绘制轨迹的特效。
连接到 dummy 骨骼或模型上并使其移动，就会显示轨迹。
将 Tr 值设为 0.1～1.0 可调节透明度，将 Tr 值设为 0 则重置轨迹信息。

通过修改特效文件内的记述，可以实现各种表现。

作为示例，准备了以下几种：

- 100simple：长度 100，简单轨迹
- 10000simple：长度 10000，简单轨迹
- 1000shot：长度 1000，被射出的轨迹
- 1000grv：长度 1000，受重力影响的轨迹
- 1000shot_grv：长度 1000，射出＋重力轨迹

另外，也准备了几种贴图文件。
请将 テクスチャ色々 文件夹内的图片重命名为 Line.png 后使用。
