# Silhouette2.fx ver0.0.2

使用贴图图像对模型进行轮廓（剪影）描画。
我把以前做的 Silhouette.fx 重新审视，重构为不使用离屏渲染（オフスクリーンレンダ）也能使用。
其结果是大幅减轻了描画负担，并且可以轻松地对每个模型单独应用。
轮廓影像可以使用单色、贴图、动画 GIF・APNG 动画（Screen.bmp 动画
已不能使用）。也可以使用遮罩图像进行淡入・淡出。
本效果是改造 舞力介入P 氏的 full.fx 制作而成的。

## 使用方法

(1) 对 PMD 或附件应用 Silhouette2.fx。
    使用 GUI 时：从「MMEffect」→「效果分配」的 main 标签页，对想应用的对象分配 Silhouette2.fx。
    使用文件名设定的情况：把 XXXXX.pmd 改为 XXXXX[Silhouette2.fx].pmd，或者把 Silhouette2.fx 改为 XXXXX.fx 后载入。
(2) 请适当更改 Silhouette2.fx 的开头参数。
(3) 把 SilhouetteControl.pmd 载入 MMD。
(4) 在模型描画顺序中，把 SilhouetteControl.pmd 放在所应用对象的前一个。
(5) 用 SilhouetteControl.pmd 的骨骼与表情滑块各自的项，可以进行以下控制。
    骨骼：ｽｸﾛｰﾙ（滚动） → 用 XY 移动进行贴图的滚动显示。
    目（眼睛）：単色赤,単色緑,単色青 → 指定单色时的 RGB 颜色。显示贴图时不需要
    ﾘｯﾌﾟ（嘴唇）：拡大,縮小 → 进行贴图的放大・缩小。单色时不需要
    まゆ（眉毛）：加算合成 → 以加算合成描画作为轮廓的颜色。
          エッジも（边缘也） → 把边缘也作为轮廓描画的对象。
          地面影も（地面影也） → 把地面影也作为轮廓描画的对象。
    その他（其他）：透過度 → 把轮廓颜色与模型颜色做线性合成。
            フェード → 淡入淡出的进行度，0 为完全透明，1 为完全遮罩，因此淡入为 1→0，淡出为 0→1
            閾値 → 值越小则淡入淡出的变化越锐利，越大则越平缓。
