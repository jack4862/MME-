MMD_CameraMirror

カメラのモーションを上下反転させるツールです
床面反射を比較的簡単に実現できます

■使い方

MMD_CameraMirror.exeに反転させたいカメラモーションの
VMDファイルをドラッグ＆ドロップしてください
末尾に"_M"の付加された反転したVMDファイルが生成されます

いかなる使用も自由ですが自己責任でお願いします

■必要なもの

.NET Framework 2.0

■床面反射の作り方

・モデルのモーションとカメラワークを決定します
・カメラのモーションをVMDファイルに書き出します
・カメラのモーションをこのツールで反転させます
・反転したVMDファイルを読み込みます
・影や床を消してAVIに録画します
・AviUtl等でAVIを上下反転します
・MMDで元のPPMを開き直し、背景AVIとして作成したAVIを読み込み、床を半透明にします
・床面反射の出来上がり
