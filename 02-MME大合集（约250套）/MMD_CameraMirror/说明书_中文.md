# MMD_CameraMirror

将相机动作上下翻转的工具。
可以比较简单地实现地面反射。

## 使用方法

把想要翻转的相机动作的 VMD 文件
拖放到 MMD_CameraMirror.exe 上。

会生成一个在文件名末尾加上 "_M" 的、已翻转的 VMD 文件。

任何使用方式都自由，但请自行承担风险。

## 必要环境

.NET Framework 2.0

## 地面反射的做法

- 确定模型的动画与运镜。
- 将相机的动作导出为 VMD 文件。
- 用本工具将相机的动作翻转。
- 读取翻转后的 VMD 文件。
- 隐藏阴影和地面，录制为 AVI。
- 用 AviUtl 等将 AVI 上下翻转。
- 在 MMD 中重新打开原本的 PPM，作为背景 AVI 读取制作好的 AVI，并把地面设为半透明。
- 地面反射即告完成。
