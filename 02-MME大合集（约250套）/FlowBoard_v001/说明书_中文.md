# FlowBoard ver0.0.1

在 B 样条曲线上排列一组 Billboard（广告牌）并使其平滑流动。
我想也可以用于文字字幕（テロップ）等。

## FlowBoard.fx 使用方法

1. 请准备用于板阵列的图像文件。
   要处理多种纹理时，需要把同尺寸的纹理横向排成一列，做成一张图像文件。
2. 在 FlowBoard.fx 开头适当指定图像文件名及其他各种参数。
3. 将 FlowBoard.pmd 载入 MMD。
4. 改变骨骼「基準点1～基準点6」（基准点1～6）的位置，板阵列就会以 B 样条曲线插值后排列。
5. 板尺寸根据骨骼「サイズ1～サイズ6」（尺寸1～6）与对应基准点1～基准点6 之间的距离，以 B 样条插值。
6. 用 FlowBoard.pmd 的表情滑块进行各种参数设置。打开「進行ON」（前进 ON）即让板阵列流动。
7. 将「進行ON」置为 OFF（左侧），或播放 0 帧，经过时间会被重置。
