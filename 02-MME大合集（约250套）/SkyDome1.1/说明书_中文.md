# 天空 ver1.1

//　种类　　后期效果

## ● 说明

实时计算天空。终究只是伪似的。
雾与天空的颜色会根据太阳和月亮的位置而变化。

## ● 使用方法

根据需要读取以下文件。
・`SkyDome.x`　天空的颜色。
・`Sun.x`　太阳。设定例（Z=10000）
・`Moon.x`　月亮。　稍大一些，设定例（Z=-10000, Si=0.5）
・`CloudDome.x`　远处可见的云。
・`Cloud1.x`　在上方流动的云。设定例（Y=1000, Si=10）

・`GodRay.x`　树叶间漏下的阳光
用 Si 设定光束长度，用 Tr 设定强度。
设定例（Si=8, Tr=0.5）

・`Fog.x`　雾
在 X～Z 的范围内起雾。比 Z 更远的地方会被雾遮住看不见。
在 0～Y 的高度起雾。低于 0 看不见（下限）。（下限的值可在 `Fog.fx` 内更改）
雾的颜色 RGB=(Rx,Ry,Rz) 各色在 0～255 的范围内指定。
设定例 (X,Y,Z)=(0,1000,5000), (Rx,Ry,Rz)=(255,255,255)

※ 注意绘制顺序
请按以下顺序绘制：
`SkyDome.x`
`Sun.x`
`Moon.fx`
`CloudDome.x`
`Cloud1.x`
`上述以外的模型`

`GodRay.x`、`Fog.x` 是后期效果，所以顺序不太相关。

## ○ 关于联动

太阳的位置默认与光源方向联动。
打开 `GodRay_config.h`，将
`#define SYNCLIGHT`
这一行改为
`//#define SYNCLIGHT`
就可以自由移动太阳和月亮的位置。

## ○ 其他设定

可通过以下文件进行详细设定。

云的量与云的浓度可在以下文件中设定。
`CloudDome_config.h`
`Cloud1_config.h`

太阳和月亮的颜色设定在以下文件中进行。
`Sun_config.h`
`Moon_config.h`　可设定月相。
