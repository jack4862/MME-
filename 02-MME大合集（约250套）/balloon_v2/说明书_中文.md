# balloon_v2

——气球特效——
作者：ビームマンP（ロベリア）

## 重要事项

这是超级重的特效。
特别是使用 model_baloon 时请格外注意。
最坏的情况会连 OS 一起崩掉！

## 基本用法

1. 读取 baloon.x。
2. 读取 BaloonController.pmd。
3. 用控制器的 X,Z 坐标控制风向，通过表情 morph（表情变形）进行各种设置。
4. 开启 baloon.x 的阴影即可显示阴影。

## 备注

更改「速度」morph 时整体会闪烁，这是计算上的规格。
请在场转换等时候好好掩饰过去。

## 文件说明

- model_baloon.fx：.pmd 用
