# ikPaperForAL

对 AL_EmmiterRT 标签中要面板化（パネル化）的模型，分配 ikPaper_モデル01AL.fx。

如果面板化的是 ikPaper_モデル01 以外的模型，请复制原来的 ikPaper_xxx.fx，
并把最后的

```
#include "ikPaper.fxsub"
```

替换为

```
#include "ikPaperAL.fxsub"
```
