# z_LeafLight

这是为了简单地投下树荫般的光而制作的效果。
文件夹内放有视频版与静止画版两种。
视频版并非持续播放，而是在按下播放按钮时才会播放视频。

这是对舞力介入P 公开的投影仪（Projector）效果的改造。
（其原始数据是そぼろ 氏的聚光灯效果 Ver.2.0）
舞力介入P 与そぼろ 氏的详细解说所载的 readme，已存放在改造来源 readme 文件夹中。

## 使用方法

1. 在读取了某个舞台的状态下，把 LeafLight.x 拖入 MMD。
2. 把 MMD 的灯光调暗。
3. 把附件的参数 Rx30 设定为 Y30 左右。
4. 完成！

用 Si 可改变灯光的大小，用 Tr 可改变灯光的亮度。

## 备注
- 灯光的颜色可通过 LeafLightXXX_Object.fx 内 LightColor 的值来改变。
- 同样，改变 LightPower1 的值即可改变光量。
- 若阴影的表现有问题，请调节 ShadowColor1、ShadowColor2。

## 注意点
- 读取多个同名效果时，最后读取的那个灯光所映出的阴影会反映到所有灯光上。
  这种情况下，请把改成别的名字的效果（要读取多个 LeafLight1.x 时则用 LeafLight2.x）放在最后读取，并调整自阴影。

- 请勿就效果相关的技术性问题或咨询进行询问。
