# ikOverray

## ■ 概要

本文档说明 MikuMikuEffect 用效果「ikOverray」的使用方法。
ikOverray 是基于光源与景深、追加仿佛光从画面外射入一般的渐变的效果。

虽然名叫 Overray，但与 Photoshop 的叠加（Overlay）不同，暗的部分不会变得更暗。
※ Ver0.02 起也支持叠加显示。

## ■ 使用方法

1. 在 MMD 的饰品中添加 "ikOverray.x"。
2. 设定各种参数。设定例见后文。
3. 一部分参数需要直接编辑 .fx 文件。

## ■ 饰品参数设定例

- 标准的设定：
  - X: 0　　// 不补正渐变长度
  - Y: 1　　// 景深有效
  - Si: 1　// 强度为标准
  - Ry: 0　// 光源方向有效
- 强调的设定：
  - X: 0.3　// 渐变稍短。
  - Y: 0.5　// 稍微无视景深。
  - Si: 5.0　// 提高光照的强度
- 强调的设定 2：
  - X: 0.2　// 渐变稍短。
  - Y: 0.1　// 几乎无视景深。
  - Si: 3.0　// 提高光照的强度
- 空气远近风：
  - X: 0
  - Y: 1
  - Si: 1
  - Ry: 1　// 完全无视光源方向

## ■ 参数的详细说明

### □ 可在饰品上设定的参数

- **Si**：光照的强度
  - 0: 效果关闭
  - 1: 标准强度
- **Tr**：效果的最终作用程度
  - 0: 效果关闭
  - 1: 效果开启
  - Si = 2, Tr = 0.5 与 Si = 1, Tr = 1 强度同为 1，但结果有差异。
  - ※ Ver 0.02 中光源方向的影响度从 Tr 变更为 Ry。
- **X**：光照的衰减率
  - 调整渐变的长度。
  - 0: 渐变变长
  - 1: 渐变变短
- **Y**：景深的影响度
  - 0: 不受影响（无视景深，全部受光照影响）
  - 1: 受影响（越靠后的物体越受光照影响）
- **Z**：测试模式
  - 0: 关闭
  - 1: 开启
    - 显示效果作用程度的模式。
    - 红与绿（以及黄）表示效果的强度。
    - 蓝表示原图像的灰阶值。
- **Ry**：光源方向的影响度
  - 1: 不受影响（与光源相反的方向也会变亮）
  - 0: 受影响（光源的反方向保持暗）
  - ※ Ver 0.02 中从 Tr 变更为 Ry。值的含义也变更了。
- **Rx**：伪光源的方向。
  - 仅当 USE_RX_AS_DIRECTION 为 1 时有效。
  - 0: 12 点方向（从上）
  - 90: 3 点方向（右）
  - 180: 6 点方向（下）
  - 270: 9 点方向（左）

### □ 在效果文件上直接操作的参数

- **USE_LIGHT_COLOR**
  - 是否使用光照的颜色。
  - 0: 不使用。（使用 .fx 文件中指定的颜色。）
  - 1: 使用光照的颜色。
- **LIGHT__COLOR** / **LIGHT_FALLOFF_COLOR**
  - 光照的颜色。
  - 当 USE_LIGHT_COLOR 为 0 时，将此值用作光照的渐变颜色。
  - 以 0.0～1.0 的小数指定，但习惯 Photoshop 等 0～255 范围的人，也可以指定为 128.0/255.0。此时请在分子或分母上加上 ".0"。
  - 也可以指定负值。
- **LIGHT_TYPE**
  - 渐变的类型。
  - 0: 直线状的渐变
  - 1: 基于距光源距离的圆形渐变
  - 2: 基于视线角度差的球状渐变
- **COLOR_MODE**
  - 合成光的方式
  - 0: 加算。把光加上去
  - 1: 乘算。变暗
  - 2: 叠加（Overlay）。亮时加算，暗时乘算
  - 3: 填充。用于雾等。
- **USE_RX_AS_DIRECTION**
  - 0: 以光源位置为基准显示渐变
  - 1: 与光源位置无关，按饰品 Rx 指定的角度绘制渐变
- **BlurSize**
  - 模糊景深数据的尺寸。
  - 通过模糊景深，赋予光绕射一般的效果。
- **ENABLE_GAMMA_CORRECT**
  - 在线性空间进行颜色计算。
  - 与无效时相比，明亮部分的效果减少，暗部分的效果上升。
    - 通常的色彩空间是配合人眼特性，按明亮部分分配大、暗部分分配小的方式来分配的。
    - 因此，即使单纯把颜色减半或加倍，亮度也不会变成一半或一倍。
    - 想知道详情的人请搜索「伽马校正（gamma 校正）」。
