
ikOverray


■ 概要

	このドキュメントは、MikuMikuEffect用エフェクト「ikOverray」の使い方を説明するものです。
	ikOverrayは、光源と奥行きを元に、画面外から光が差すようなグラデを追加するエフェクトです。

	Overrayといいながら、Photoshopのオーバーレイと異なり、暗い部分がより暗くなることはありません。
	※ Ver0.02でオーバーレイ表示にも対応しました。


■ 使用方法

1. MMDのアクセサリに、"ikOverray.x"を追加してください。

2. 各種パラメータを設定します。設定例は後述します。

3. 一部のパラメータは、.fxファイルを直接編集する必要があります。


■ アクセサリのパラメータ設定例

	オーソドックスな設定：
		X: 0		// グラデ長の補正なし
		Y: 1		// 奥行き有効
		Si: 1		// 強度は標準
		Ry: 0		// 光源方向有効

	強調した設定：
		X: 0.3		// グラデを短め。
		Y: 0.5		// 奥行きやや無視。
		Si: 5.0		// ライトの強度を上げる

	強調した設定2：
		X: 0.2		// グラデを短め。
		Y: 0.1		// 奥行きほぼ無視。
		Si: 3.0		// ライトの強度を上げる

	空気遠近風：
		X: 0
		Y: 1
		Si: 1
		Ry: 1		// 光源方向完全無視


■ パラメータの詳細

□ アクセサリ上から設定できるパラメータ

	Si：ライトの強度
		0: 効果オフ
		1: 標準的な強度

	Tr: エフェクトの最終的な掛かり具合
		0: 効果オフ
		1: 効果オン
			Si = 2, Tr = 0.5 と、Si = 1, Tr = 1はともに強度1ですが、
			結果に違いがあります。
		※ Ver 0.02で ライト方向の影響度はTrからRyに変更。

	X: ライトの減衰率
		グラデの長さを調整する。
		0: グラデが長くなる、
		1: グラデが短くなる

	Y: 奥行きの影響度
		0: 受けない(奥行きを無視してすべてがライトの影響を受ける)、
		1: 受ける(奥にあるものほどライトの影響を受ける)

	Z: テストモード
		0: オフ
		1: オン
			エフェクトの掛かり具合を表示するモード。
			赤と緑(と黄色)がエフェクトの強度をあらわします。
			青は元画像のグレースケール値を表します。

	Ry: ライト方向の影響度
		1: 受けない(光源と反対方向も明るくなる)、
		0: 受ける(光源の反対は暗いまま)
		※ Ver 0.02で TrからRyに変更。値の意味も変更しました。

	Rx: 偽光源の方向。
		USE_RX_AS_DIRECTIONが1のときのみ有効。
		0: 12時方向(上から)、
		90: 3時方向(右)、
		180: 6時方向(下)、
		270: 9時方向(左)となる。



□ エフェクトファイル上で直接操作するパラメータ

	USE_LIGHT_COLOR
		ライトの色を使うかどうか。
		0: 使わない。(.fxファイルで指定した色を使う。)
		1: ライトの色を使う。

	LIGHT__COLOR
	LIGHT_FALLOFF_COLOR
		ライトの色。
		USE_LIGHT_COLOR が 0 の場合、ライトのグラデ色としてこの値を使用する。

		0.0～1.0の少数で指定しますが、PhotoShopなどの0～255の範囲に慣れている方は、
		128.0/255.0と指定することも可能です。その場合、分子か分母に".0"をつけてください。

		負の値を指定することも出来ます。


	LIGHT_TYPE
		グラデのタイプ。
		0: 直線状のグラデ
		1: 光源からの距離による円形のグラデ
		2: 視線の角度差による球状のグラデ

	COLOR_MODE
		光を合成するモード
		0: 加算。光を足しこむ
		1: 乗算。暗くなる
		2: オーバーレイ。明るいときは加算、暗いときは乗算
		3: 塗りつぶし。フォグなどに使う。

	USE_RX_AS_DIRECTION
		0: ライトの位置を基準にグラデを表示
		1: ライト位置とは無関係に、アクセサリのRxで指定した角度でグラデを描画

	BlurSize
		奥行きデータをボカすサイズ。
		奥行きをボカすことで、光が回り込んだような効果を与える。

	ENABLE_GAMMA_CORRECT
		色の計算を線形空間で行う。
		無効時よりも、明るい部分の効果が減少して、暗い部分の効果が上昇する。

			通常の色空間は人間の目の特性に合わせて、明るい部分が大きく、
			暗い部分が少なくなるように配分されています。
			このため、単純に色を半分にしたり、倍にしたりしても、
			明るさが半分になったり、倍になったりしません。
			詳細が知りたい方は、ガンマ補正で検索してください。
