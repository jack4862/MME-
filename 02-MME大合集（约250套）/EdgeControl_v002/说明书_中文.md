# EdgeControl.fx ver0.0.2

不使用 MMD 标准的边缘描画，而是以着色器（Shader）的独自规格来描画边缘。
由于边缘的粗细是由顶点与摄像机位置的距离决定的，因此无论摆放、摄像机角度还是巨大模型，
边缘都不会变得过粗。
此外，也可以给附件加上边缘。
本效果是改造舞力介入P 氏的 full.fx 制作而成。

## 使用方法
1. 把 PMD 名从 XXXXX.pmd 改为 XXXXX[EdgeControl.fx].pmd，或者把 EdgeControl.fx 改名为 XXXXX.fx。
2. 把改名后的 PMD 载入 MMD。
3. 酌情修改 EdgeControl.fx 开头的参数。

## 注意点
默认设定下会对所有顶点描画边缘。
即使是 PMD 材质中设为边缘 off 的地方也会被描画边缘，因此视模型不同，
尤其是表情等的氛围可能会发生变化。因此需要按模型分别指定要描画边缘的材质。

请先用 PMDEditor 确认哪些材质在描画边缘，然后在 EdgeControl.fx 开头的参数中指定要描画的材质。
材质指定方法按如下方式记述。＜摘自 MMEffect 的 REFERENCE.txt＞

> 像 "0,3,5" 这样用逗号分隔列举编号，即可指定多个编号。
> 另外，像 "6-10" 这样用连字符连接编号，即可进行范围指定。
> 像 "12-" 这样只指定范围的起始编号时，则其后所有编号都成为对象。

例　あにまさ式 标准初音未来 v1.3
```
#define EDGE_ON   "0-4"   // 描画边缘的材质编号
```

例　Lat式ミクVer2.3_Normal.pmd
```
#define EDGE_ON   "1,3-5,7-11,13,24,27"   // 描画边缘的材质编号
```
