# 【水玉（圆点）投影阴影效果 v0.2】

发布者：おたもん（user/5145841）　mail:o_tamon@okoneya.mail-box.ne.jp

## ■ 前言

本效果是以ビームマンP 的投影阴影（Drop Shadow）效果为基础，
想着「如果用于时尚演出的话，水玉网点风也是必要的吧」，于是灵机一动做出来的东西。

## ■ 概要

在 MMD 模型的后方显示一种水玉（圆点）朝外侧逐渐变小消失的投影阴影。
可以通过配件操作或 Dummy Bone（空骨骼）来做动画等，请用作一个点缀。

## ■ 关于透明度支持

由于不是后处理效果（Post Effect），所以仅在透明度有效的状态下可用。

已知问题：在背景透明的状态下应用 o_SelfOverlay 等会出问题。
请读取白色图像等作为背景，或者如果是本人的效果，请把透明度设为无效后再使用。

＊　注意　＊
- 不知是否 MMD 的规格所致，在透明度有效的情况下输出时，半透明部分无法以正确的颜色显示。
- AVI 输出时，请使用 Ut Video Codec RGBA(ULRA) 等支持透明度的编解码器。

## ■ 用法

请在可使用 MikuMikuEffect 的 MikuMikuDance 中添加配件 o_DotsDropShdw.x。
它会受到配件描画顺序的影响，请设定为比模型更早描画。

由于 MMD 的规格，无法把配件 o_DropShadow.x 的描画插入模型之间。
因此在模型形式的舞台等之上进行描画时，请并用データP 的 Exclude.fx。

- 可通过配件操作设置的项目
  - X：指定把投影阴影在横向（正数为向右）偏移多少。设得太大时会出问题。
  - Y：指定把投影阴影在纵向（正数为向上）偏移多少。设得太大时会出问题。

  - Z：初始设定下调整「水玉的大小」。（推荐值范围：-0.5 < Z < 1.0）
    通过改写 fx，可以切换为调整「网格的大小（水玉的密度）」。

  - Si：指定水玉的淡出宽度。（推荐值范围：0.8 < Si < 2.0）

  - Tr：指定投影阴影的不透明度。通过改写 fx 可以切换两种模式。

  ＊ 仅在 MikuMikuEffect 中有效的操作
    Rx、Ry、Rz：指定投影阴影的颜色（依次为红・绿・蓝）。全为 0 是黑，为 1 是白。

- 可在参数控制栏中设置的项目（MikuMikuMoving）
  - 密度：调整水玉之间的间隔。

  - ●大小：更改水玉的大小。数字越小，水玉尺寸越大。

  - 水玉の色（水玉的颜色）：可以指定水玉的颜色。MikuMikuMoving 专用参数。

- 可通过改写效果文件设置的项目

  （o_DropShadow.fx）
  - BLUR_MODE：为 0 时水玉会出现锯齿但运行高速，为 1 时处理较重但能漂亮地描画水玉（初始值）。
  - ALPHA_MODE：为 0 时按每个水玉进行半透明处理，为 1 时按投影阴影整体进行半透明处理（初始值）。
    好用的是 1，但水玉重叠的部分会变浓的 0 也许能做出某些表现。
  - ZPOS_MODE：切换可由配件操作的「Z」调整的要素。初始值 1 指定水玉的大小。
    0 指定水玉的密度。大小以及水玉的中心位置也会切换，因此不太好用，
    但在场景切换的时机想要变更等情况下可以切换使用。

  （drawDShdw.fx）
  - ThicknessRate：与配件操作另行地指定作为基准的描边宽度。

  ＊　知道了有好处的小技巧　＊
  在 MMD 中，基于规格，只有配件操作的大小 (Si) 与不透明度 (Tr) 会在关键帧之间平滑变化。

  想要让位置 (X,Y) 或水玉的大小 (Z) 平滑变化时，请把它与 Dummy Bone（空骨骼）绑定，
  并对空骨骼一侧的位置或旋转设置关键帧，这样就可以带插值曲线地平滑变化。
