# 放射模糊（RadialBlur）ver1.0

- 名称：放射模糊（原文写作「放射部ラー」，疑为「放射ブラー」之误）ver1.0
- 种类：后期效果（ポストエフェクト / Post Effect）
- 对应：MikuMikuEffect ver0.2x 用
- 作者：kion
- 更新日：2011.4.12

## ●说明

简易放射模糊。

## ●使用方法

载入「RadialBlur.x」。
「RadialBlur.x」的位置会成为模糊的中心。
用 Si 指定模糊的强度。设置示例（Si=5）。
