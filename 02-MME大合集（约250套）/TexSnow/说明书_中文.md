# TexSnow Readme

MikuMikuEffect 用 降雪特效

制作：そぼろ

这是让雪降下的特效。
虽然已经有基于 FireParticleSystem 的同类特效，
但本特效采用完全不同的方式，是更专注于雪的表现的特效。

其机制是将 1 张广告牌反复绘制多次，
属于无视速度、重视扩展性的设计，因此相当重。

通过替换贴图，也可以表现雪以外的效果。
作为示例，也一并附上了星星的贴图。

可通过内部参数更改粒子数、范围、速度、倾斜、
粒子大小、噪声、旋转速度等。

## 通常的使用方法

- 在 MMD 中读取 TexShow.x
- 将绘制顺序设为最后

## 注意事项

- 由于使用了 Alpha 混合，请设置为最后被绘制。
- 需要支持顶点着色器 3.0 的显卡。
