
AMD RenderMonky 1.82 の、サンプル "Disco Lighting"よりコンバートしたものものです。


●サンプルのPMMファイルについて、
MMDで読む前に、以下の準備が必要です。
(1) "DiscoObject.fx" と "LightCube.dds" を UserFile\Accessory\ と UserFile\Model\ にコピーしてください。
(2) "初音ミクVer2[DiscoObject.fx].pmd" という名前で "初音ミクVer2.pmd" のコピーを作成してください。
(3) "stage01[DiscoObject.fx].x" という名前で "stage01.x" のコピーを作成してください。

●通常の使用方法
・DiscoLight.xをMMDで読み込み、描画順序の先頭に設定してください。
・それ以外の全てのオブジェクトについて、上記のサンプルのように、"DiscoObject.fx"を使って描画するように設定してください。

●注意事項
・セルフシャドウには対応していないので、OFFにしてください。
