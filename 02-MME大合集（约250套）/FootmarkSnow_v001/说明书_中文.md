# FootmarkSnow.fx ver0.0.1

这是 Footmark 的积雪版本。

把它挂在左右脚踝骨骼上，就能随着模型的动作，在积雪上踩出陷入雪中的脚印。

## FootmarkSnow.fx 使用方法

1. 将「積雪足跡右[FootmarkSnow.fx].x」（积雪脚印·右）和「積雪足跡左[FootmarkSnow.fx].x」（积雪脚印·左）载入 MMD。
2. 把绘制顺序设为排在地面附件之前。
3. 把「積雪足跡右[FootmarkSnow.fx].x」挂到目标 PMD 模型的右脚踝骨骼上，把「積雪足跡左[FootmarkSnow.fx].x」挂到左脚踝骨骼上。
4. 配合模型调整脚印的位置和大小。默认值是按标准初音未来 v1.3 调整的。
   比起用 MMD 的附件参数调整，直接改 fx 文件开头的参数可能更好调。
5. 给地面附件套用降雪效果（SnowCover：そぼろ 氏作），并用 MMD 的附件参数把地面高度设为 Y=0.5～0.6 左右。
6. 播放第 0 帧即可重置（从播放模式切到编辑模式时同样如此）。

## 注意点

如果不配合模型和动作，把 fx 文件开头的脚印检测相关参数调整得当，就会出现脚印不显示、重复显示等各种问题。
把脚边放大来看会有各种瑕疵，不过嘛，这就是它的规格……

※ 要在 MME 中使用这个 FX 文件，必须有一块支持 VTF（Vertex Texture Fetch）的 SM3.0 显卡。
