# ikPostFog

朝任意方向施加雾（Fog）的后处理效果

## ■ 用法

	(0. 读取适当的舞台数据。)
		※ 如果没有背景、天空穹顶、模型，效果不会显现。

	1. 把 ikPostFog.pmx 放进 MMD。
	2. 从表情变形（Morph）中，把 加算（加法）的 R,G,B 中任意一个设得大于 0，给雾上色。
		如果相机位于原点附近、且没有被舞台等遮挡，就会显示从下到上的渐变。

	3. 试着调整变形的「深さ+」（深度+）或「厚さ+」（厚度+）等。
	4. 试着改变 ikPostFog.pmx 的角度或位置。

	(5. 从 MME 的 PostFogNormalMapRT 标签中，取消勾选多余的东西。）

	在不旋转的状态下，以「すべての親」（所有父级）为中心，雾的浓度朝上 (+Y) 方向变淡，
	朝下 (-Y) 方向变浓。
	上下方向的宽度可以通过「深さ+」「深さ-」（深度+、深度-）控制。

	深度 (Z) 方向的雾的厚度可以通过「厚さ+」「厚さ-」（厚度+、厚度-）控制。
	左右 (X) 方向的雾的厚度可以通过「幅+」「幅-」（宽度+、宽度-）控制。

	通过旋转 pmx，可以更改雾的方向。

## ■ 设置项目

用变形（Morph）设置的项目

	全体拡大（整体放大）
		把雾的尺寸整体调大。

	深さ+、深さ-（深度+、深度-）
		控制雾的高度。越深，雾的渐变越长。
		沿着局部空间中的 Y 轴（＝在 MMD 画面右下显示着 LOCAL 的状态下、模型上显示的绿色轴），雾的浓度变淡。

		深度也会影响雾整体的浓度。拉得越长，雾整体越淡。
		为了在内容不变的情况下拉伸，整体会变淡。

	幅+、幅-（宽度+、宽度-）
		控制 X 轴方向的雾的厚度。

	厚さ+、厚さ-（厚度+、厚度-）
		控制 Z 轴方向的雾的厚度。

		宽度与厚度不影响雾的整体浓度，但视线穿过雾内的距离变长时，相应雾会变浓。

	濃度+、濃度-（浓度+、浓度-）
		控制雾的浓度

	エリア限定（区域限定）
		是否对雾范围的后方也施加雾的影响。

		在 视线→雾→雾区域外
			这样的情况下，エリア限定=0 时，雾区域外也会受到雾的影响。
			想减弱对雾区域外的影响时，把这个值调大。

	加算R,G,B（加法 R,G,B）
		雾越浓，就越加上在此指定的颜色。

	減衰R,G,B（衰减 R,G,B）
		雾越浓，就越从原图像中减去在此指定的颜色。
		更准确地说，是 原图像的颜色 * (1 - 衰减色)。

	ライトR,G,B（灯光 R,G,B）
		指定灯光方向的雾的颜色。
		根据灯光与相机的角度，加算 R,G,B 的颜色会变化为在此指定的颜色。

	ライト強度（灯光强度）
		该值越大，越容易受灯光颜色的影响。为 0 时无效。

	ライト範囲（灯光范围）
		该值越大，灯光颜色的范围越大。
		不过，即使调到最大，如果朝向灯光的反方向也不会受到灯光的影响。

	フェード（淡出）
		降低效果整体的作用。

	テストモード（测试模式）
		与设置的颜色无关地显示雾施加的程度。
		把有雾的部分显示为白色，受灯光颜色影响的部分显示为黄色。

		在测试模式下显示在画面上部的颜色，
		从上到下依次表示 加法色、(1 - 衰减色)、灯光色。
		从左往右则成为雾浓度较高状态下的颜色。
		灯光色会依照灯光强度与加法色合成。
			灯光强度为 0 时，灯光色与加法色相等。

		使用多个雾效果时、使用其他后处理效果时，
		可能会受它们影响而颜色发生变化。

## ■ 文件的内容

	ikPostFog.pmx
		效果本体。

		ikPostFog.fx
			用于 ikPostFog.pmx 的效果文件。有几个次要的设置项目。
		ikPostFog.fxsub
			效果文件的共通部分。
			除想直接摆弄 HLSL 的人以外，推荐放着不管。

		ikNormalMap.fx
			调查画面景深的效果。基本上无需触碰。
		ikNormalMapMask.fx
			对不想受雾影响的模型・材质，用它代替 ikNormalMap.fx 使用。
			设置到 MME 的 PostFogNormalMapRT 标签中。

	ikPostFogSub.pmx
		使用多个时的子效果

		通过借用 ikPostFog.pmx 的计算结果，实现省内存・高速化。
		因此，必须与 ikPostFog.pmx 同时使用。

		ikPostFogSub.fx
			用于 ikPostFogSub.pmx 的设置文件

	ikPostFogAcs.x
		配件版的効果
		用于描画顺序有问题、或想指定父级来移动等不想使用 pmx 的场合。

		ikPostFogAcs.fx
			用于 ikPostFogAcs.x 的设置文件

	ikPostFogController.pmx
		ikPostFogAcs.x 用的控制器

## ■ 注意点

	由于是以距离为基准计算雾，远距离下雾会扭曲。

	在模型编辑模式与相机编辑模式（制作视频时）下，灯光色的观感有时会不同。
	这是因为在 MMD 的模型编辑模式中移动变形时，如果不在菜单中启用相机・照明追従（相机・照明跟随），
	灯光的方向会被重置到默认位置。
