# Wind（风）

--使用方法--
把 Wind.x 载入 MMD 即会显示。
角度与大小指定等，可以与普通附件同样地进行。

在部分显卡上无法使用，但这是必需的，
很抱歉目前无法对应……

--参数说明--（数值为默认值）

//复制条数
int CloneNum = 64;
设定在 60F 内生成的风的条数。

//贴图名
texture Aura_Tex1
<
   string ResourceName = "Wind_Tex.png";
>;
设定风用的贴图。
请试着准备新的贴图，或修改附带的东西来确认效果。

//整体播放速度
float AnmSpd = 1;
设定动画整体的进行速度。

//整体高度
float Height = 1;
设定风的伸长？

//配置时偏离中心的随机宽度
float SetPosRand = 0.1;
设定 XZ 坐标上（MMD 中施加旋转或放大之前的）的偏移。

//每一缕风的高度最大值
float LocalHeight = 0.5;
设定风效果每一个的高度最大值。
调小可以变成细密的效果。

//风的扩散强度
float WindSizeSpd = 1;
设定风扩散的强度。

//扩散的随机宽度
float WindSizeRnd = 1;
会按此处指定的量，给每一缕风赋予扩散速度的偏差。

//贴图重复次数
float ScrollNum = 1;
设定风效果 U 值的重复次数。
默认贴图推荐设为 1。

//颜色设定
float3 Color = float3( 0, 0, 0 );
用 R,G,B 设定给风着色的颜色。

//亮度
float Brightness = 10;
设定颜色的强度。

//扭曲力度
float DifPow = 1.0;
设定扭曲效果时拉扯背景的距离。
调得太大反而会让效果变得不易看清。

//整体旋转速度
float RotateSpd = 0.5;
设定效果整体绕 Y 轴旋转的速度。
（为了减轻图案感）

//个别旋转系数（倾斜的离散度）
float RotateRatio = 0.05;
设定每一缕风 XZ 轴旋转的离散程度。
设为 0 时在 XZ 平面上，设为 1 时会朝着全周方向生成。

//最小半径
float MinSize = 1;
设定生成时的最小半径。

//发射时间偏移（随机值）
float ShotRandOffset = 0;
设定生成速度的偏差。
