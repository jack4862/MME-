# EasyBillboard.fx ver0.0.1

让用绘图工具制作的立牌配件（書き割りアクセ）进行 Billboard（广告牌，始终朝向正面）处理。
由舞力介入P氏的 laughing_man.fx 修改制作而成。

## 使用方法

1. 准备图像文件，用绘图工具制作立牌配件。
2. 把配件名从 XXXXX.x 改为 XXXXX[EasyBillboard.fx].x，或者把 EasyBillboard.fx 改名为 XXXXX.fx。
3. 将改名后的配件载入 MMD。
4. 在 MMD 中可以做通常的配件参数修改。无需改动 fx 内部。
5. 即使粘在 PMD 的骨骼上运动，配件的朝向也不会改变。
6. 绘制顺序需要设置为在其他物体之后绘制。

## 应用

把 x 文件中记述的图像文件名改为 screen.bmp，就可以用背景 AVI 让它动起来。

## 注意点

基本上是一张画那样的立牌配件专用。用在 3D 模型上基本无法正常绘制。
