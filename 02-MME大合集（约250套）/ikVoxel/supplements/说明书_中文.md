# ikVoxel / supplements 说明

- **vox_AL_Object.fxsub**
  使用 そぼろ 氏的 AutoLuminous4 时的文件。
  用它来代替 AL_Object.fxsub 进行设置。

- **vox_HgSSAO_Depth.fxsub**
  **vox_HgSSAO_Normal.fxsub**
  使用 針金 氏的 HgSSAO 时的文件。也可用于 HgSAO。

- **vox_WorkingFloor.fxsub**
  用于 針金 氏的 WorkingFloorX。
  用它代替 WF_Object.fxsub 来指定。

- **vox_ikBokeh.fxsub**
  用于拙作 ik 虚化（ikボケ）。

- **ikPolishShader.fxsub**
  **vox_PolishMain.fx**
  **vox_PolishMaterial.fx**
  **vox_PolishShadow.fxsub**
  **vox_PolishMain_common.fxsub**
  **vox_PolishMaterial_common.fxsub**
  用于拙作 ikPolishShader。
  把 vox_PolishMain.fx 设置到 Main 选项卡，把 vox_PolishMaterial.fx 设置到 ColorRT 选项卡。

  vox_PolishShadow.fxsub 请先复制到 ikPolishShader/Shadows 中，
  再设置到 ShadowRT 选项卡。

  如果为了 ikPolishShader 而修改了 ikPolishShader.fxsub 的设置，
  请把修改后的 ikPolishShader.fxsub 覆盖到本文件夹。
