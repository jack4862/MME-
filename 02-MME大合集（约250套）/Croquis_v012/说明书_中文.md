# Croquis.fx v0.12 【着色器 3 以后】

CroquisLite.fx v0.12【支持着色器 2】

## 【约定】

允许使用、再发布、改造、以及改造物的再发布。
不作任何保证，请自行承担责任使用。

## 【概要】

通过轮廓提取，制作线画风影像的后期效果。
由于可以用 Tr 与原图像合成，因此也可以绘制成带淡彩的线画风。

Croquis 是较重的效果。建议仅在最终输出时 ON。
CroquisLite 不进行抗锯齿、画质会下降，但稍微轻一些，且着色器 2 也能运行。

## 【使用方法】

只需读取 `Croquis.x` 或 `CroquisLight.fx`。
进行淡彩时，将 Tr 设为 0.6-0.8 左右比较好。

## 【自定义】

已支持 gisupeke 氏的 MME 编辑工具，以及 sh5 氏的 fx 文件改写工具（fxファイルかきかえまくりんぐツール）。
可以编辑线的颜色、底色。

手动改写时，在 `Croquis.fx` 以及 `CroquisLite.fx` 的第 12 行～第 24 行左右

```
float4 FrontColor <
	string UIName = "線の色";
	string UIWidget = "Color";
	bool UIVisible =  true;
	float3 UIDefault = float4(0, 0, 0, 1);
> = float4( 0 , 0 , 0 , 1 ); ← ここが線の色

float4 BackColor <
	string UIName = "地の色";
	string UIWidget = "Color";
	bool UIVisible =  true;
	float3 UIDefault = float4(1, 1, 1, 1);
> = float4( 1 , 1 , 1 , 1 ); ← ここが地の色
```

分别是前景色（线的颜色）和背景色（底色的颜色）。
默认是白底黑线。
颜色的指定为 float4(R,G,B,A)，A 与配件的 Tr 相同，是不透明度。

例如改写如下，即可成为原图像上加绿线。

```
float4 FrontColor <
	string UIName = "線の色";
	string UIWidget = "Color";
	bool UIVisible =  true;
	float3 UIDefault = float4(0, 0, 0, 1);
> = float4( 0 , 1 , 0 , 1 ); ← 緑の線

float4 BackColor <
	string UIName = "地の色";
	string UIWidget = "Color";
	bool UIVisible =  true;
	float3 UIDefault = float4(1, 1, 1, 1);
> = float4( 0 , 0 , 0 , 0 ); ← 黒の透明
```
