# 歪み軌跡（扭曲轨迹）DistLine 使用方法

会扭曲的轨迹！

参数基本上通过直接编辑 fx 文件来设置。

## 主要参数

```
float4 LineColor = float4(1,0.1,0.1,1);
```
以 RGBA 指定着色的颜色。0,0,0,1 为无着色，1,1,1,1 为白色。

```
float DistPow = 0.25;
```
设置扭曲的强度。为 0 时不扭曲。

```
float CutSpeed = 0;
```
指定生成轨迹的最低速度。
在希望缓慢移动时不产生轨迹等情况使用。
另外，为 0 时始终生成。

```
#define LINE_LENGTH 100
```
轨迹的长度。

```
float lineSize = 0.1;
```
线条的粗细。
也可通过 MMD 上的 Si 值进行操作。

```
float LineSpd = 0.0;
```
射出线条的速度。
射出方向为模型的 Z 方向。
