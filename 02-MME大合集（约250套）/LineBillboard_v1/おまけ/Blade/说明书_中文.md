# LineSystem 剑轨迹用设置文件（Blade）

使用方法：

- 装入 MME
- 让模型持有某种武器（基本上以直刀为前提。镰刀之类的话就……总之加油吧）
- 读取 blade.x
- 将 blade.x 设置到持武器一侧的手腕上
- 在配件操作中，把 Ry 设为 90（角度对齐）
- 挪动 X（前后调整）、Z（高度调整），把 blade.x 的中心对准想要产生剑轨迹的坐标
- 用 Si 调整剑轨迹的大小
- 修改 blade.fx 内的 `#define LINE_LENGTH 15` ← 把这里的数字调大或调小，来调整轨迹的长度
- 贴图方面，请用同名的贴图覆盖，或者修改 blade.fx 的

```
//テクスチャ名
texture Line_Tex
<
   string ResourceName = "blade.png";←在此处更改
>;
```
