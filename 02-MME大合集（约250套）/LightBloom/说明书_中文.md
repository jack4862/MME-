# LightBloom

## 概要
可在 MikuMikuDance 及 MikuMikuEffect 中使用的画面效果。属于后期效果。

## 效果
使画面中明亮的部分更加明亮，并让该光稍微向周围溢出。

## 使用方法（准备）
1. 通过「附件操作」读取同梱的 LightBloom.x。
2. 之后，从菜单的[背景]->[附件编辑]把 LightBloom.x 的绘制顺序设为最上层。
（在这个阶段，画面应该还不会有特别的变化。）

## 使用方法（操作）
可通过附件操作的 X、Y、Z、Si 调节效果。不过坐标（X,Y,Z）的自动插值似乎直接不起作用，
若要让亮度等画面效果动态变化，请从模型操作读取假骨骼（ダミーボーン），再从附件操作
把读取的假骨骼套用到 LightBloom.x 上。然后操作假骨骼的 XYZ 即可。
Si 似乎会被自动插值，因此请从附件操作中操作其数值。

## 使用方法（效果）
- **X**：类似判定为明亮部分的阈值。适当值范围约 0～+20
- **Y**：让整个画面均匀变亮或变暗。（+值为加算，-值为减算）。适当值范围约 -100～+100
- **Z**：让由 X 变亮的部分进一步变亮。（与 X 的结果相乘。取负值则抵消 X 的部分）。适当值范围约 0～+30
- **Si**：光溢出的距离增加。为 0 时几乎不溢出。（负值与正值效果相同）。适当值范围约 0～10

## 计算
由 X 与 Z 算出的亮度，只需少许操作效果就会强烈显现。
Y 对整个画面的亮度变更是最后阶段才套用的。在 X 与 Z 的高亮度处理之后，再对整个画面进行加算减算。
因此，当 X 与 Z 为 0 时，Y 只在 -100～+100 才有意义，但随着 X 或 Z 变大，Y 的幅度也会变宽。
Si 大致是 1 为 1 倍、2 为 2 倍、0 为 0 倍这样的感觉。调得太大就会看到网格状纹路。

## 备注
- 仅用 X 与 Z 来调节亮度。
- 表现从黑暗处走到明亮处时，眼睛适应光的过程。
- 用 Y 调成纯白、纯黑来做画面转换。
- X20、Y-60 左右可营造昏暗的氛围。
