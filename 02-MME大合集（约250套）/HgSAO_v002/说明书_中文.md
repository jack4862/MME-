# HgSAO.fx ver0.0.2

SAO（Scalable Ambient Obscurance，可缩放环境光遮蔽）特效。

SAO 是 SSAO 的发展形态，即使对细小的凹凸也能相对漂亮地叠加 AO。
本特效参考了 mogg 氏的 ScalableAO_MMM 示例以及开发方（NVIDIA）的示例代码，并加以改良，使其在 MMD/MMM 中能够实用。

## 运行环境

必须使用支持 SM3.0 的显卡。
已在 MMEv0.37、MMEv0.37x64、MMMv125a、MMM64v125a 上确认可运行。旧版本可能无法运行。

## 使用方法（MME）

1. 将 HgSAO.x 载入 MMD。
2. 适当修改 HgSAO.fx 开头的参数。
3. 通过 MMD 的附件（アクセサリ）参数可以进行以下修改。

| 参数 | 作用 |
| --- | --- |
| X | AO 处理的 ScreenSpace 缩放比（在 -100～+1000 左右调整） |
| Y | AO 处理的 Disk 半径（在 -3～+10 左右调整） |
| Z | AO 处理的偏移（bias）值（在 -0.1～+0.1 左右调整） |
| Rx | AO 明度（在 -0.5～+2.0 左右调整） |
| Rz | AO 的模糊强度（在 -1～+3 左右调整） |
| Si | 由 AO 产生的阴影浓度调整（在 0～2 左右调整） |
| Tr | 调小时，阴影的合成方式会从 自乘（自己乗算）→ 乘法（乗算） 变化。 |

## 关于 AO 取消（AO キャンセル）

从「MMEffect」→「特效分配（エフェクト割当）」的 HgSAO_DepRT 标签中选择模型并应用 HgSAO_Cancel.fxsub，即可有意地只解除指定模型的 AO。
（使用 Lat 式模型时，请通过该方法解除脸部的 AO。）

## 关于 MikuMikuMoving

本特效也支持 MikuMikuMoving。
请将 HgSAO.fx 直接载入 MikuMikuMoving 使用。
在 MMM 中，可以通过 HgSAO.fx 特效属性里追加的 UI 控件来修改参数。
（特效属性中的「拡大」「アルファ」与 MME 的 Si、Tr 含义相同。）
