# 类半兰伯特（Half-Lambert）照明效果 Ver0.24

作者：納豆カレー（http://www.nicovideo.jp/user/16307485　http://www.youtube.com/user/eo2a2oiYT）

## ◆前言

这是可在 MikuMikuDance 与 MikuMikuEffect 中使用的效果。一如往常，这是外行人照猫画虎做出来的东西，各方面都比较可疑（不可靠）。

- 与「多边形数相对较多／材质数量少、整体紧凑／没有在材质颜色上玩花样」的模型相性较好。
- 光源最多可设置 4 个点光源。要更多时请自行编辑 fx 文件。
- Lite 版使用 MMD 标准光源。MMD 的光源是无衰减的平行光源，因此质感与点光源版并不完全相同。
- 大致分为 Blinn-Phong 与 Cook-Torrance 两种。区别在于镜面反射光的计算方法。
  - Cook-Torrance 是更精密的模型，但相应地负载也更高。另外由于参数不足，材质的 Specular（高光）处理方式比较特殊。
  - MMD 标准所使用的恐怕是 Blinn-Phong，所以嫌改模型麻烦的人请使用 Blinn-Phong 版。
- 与 Diffusion 滤镜并用会得到不错的效果。

## ◆使用方法

- 效果文件的分配：基本上有以下两种方法。
  1. 放在想要使用效果文件的模型所在同一文件夹中，重命名为模型名后读取模型。
  2. 在 MME 的 GUI 上分配效果文件。（推荐）
- 用于 Accessory（配件）时，请勾选「影」（阴影）。
- NormalMap 版请在 MME 的 GUI 上进行子集展开，只分配给想要使用的材质。
  - 也就是说，有几种法线贴图就需要几个效果文件。在效果内部按有无法线贴图来分支处理很麻烦，所以没有那样做。
- 如果不需要根据模型特别修改效果文件，那么在 GUI 上给所有模型分配同一个文件，动作会稍微轻一些。

- 光源设置（Lite 版不需要）：使用 PointLight0～3.x。
  - 与 Dummy Bone（空骨骼）等关联使用的话，位置设置会变得轻松。推荐そぼろ氏的 SpotLight 效果所附带的 SpotLightModel.pmd。
  - Accessory 面板的 Si 是光的强度，Rx、Ry、Rz 分别对应 R（红）、G（绿）、B（蓝）。
    - Si 会被关键帧插值，但 Rxyz 不会被插值，因此难以让颜色连续变化。
    - 另外，配件的球体多边形是用于确认位置的，没有其他意义。它不是光的照射范围。
  - Rx、Ry、Rz 的值是在计算光的衰减之后才反映的，所以填入较大的值有时会导致颜色过曝（色彩溢出）。
    - 建议将 Rxyz 的值控制在 0.0～2.0 左右，亮度用 Si 值来调整。
  - 可以用 MMD 的照明颜色设置环境色（基础颜色）。初始状态的 RGB 各 154 为基准。
    - 将 RGB 全部设为 0 后，光照射不到的部分会变成纯黑。

- 调整模型的材质：调整颜色与高光。基本上使用 PMD 编辑器。
  - 受光部分受材质的 Diffuse 颜色影响，不受光部分受材质的 Ambient 颜色影响。
  - Diffuse 颜色似乎分为 0.8 与 1.0 两大派？视贴图而定，但在同一照明下 1.0 的模型有时会稍微亮一些。
  - 请注意，高光（镜面反射）在 Blinn-Phong 与 Cook-Torrance 中的计算方法完全不同。

    - ◇Blinn-Phong
      - 镜面反射光的颜色为材质的 Supecular（原文如此，即 Specular）与光源颜色相乘的结果。
      - 镜面反射光的强度按材质的 Shininess（光泽度）值取幂。该值越大，反射越尖锐。（取值在 5.0～600.0 左右比较合适？）

    - ◇Cook-Torrance
      - 材质 Specular 的 R 是面的粗糙度参数（Beckmann 分布函数的 m）。该值越小，越有光滑的感觉。
      - 材质 Specular 的 G 是垂直入射时的菲涅尔系数（Schlick 菲涅尔系数近似式的 F0）。该值越小，垂直入射到面的光的反射越弱。
      - 材质 Specular 的 B 是镜面反射的亮度。该值与材质的 Diffuse 相乘所得的值被用作反射光的颜色。
      - 材质 Shininess 的值不使用。

    - 这些值很难靠感觉填写，建议使用 "Cook-Torrance_Specularテスト用.fx" 来调整。
      - 已大致支持 fx 变量编辑工具 fxinput（http://mmd.dip.jp/files/75）。

## ◆注意事项

- 自阴影使用 MMD 标准的阴影。由于锯齿明显，已把颜色调得相当淡。
- 由于无法判定遮挡物，光会穿透墙壁、天花板等照射过来。请注意光源位置，以免产生违和感。
- 已设定为不使用 Sphere Map（球面贴图）与轮廓线。
