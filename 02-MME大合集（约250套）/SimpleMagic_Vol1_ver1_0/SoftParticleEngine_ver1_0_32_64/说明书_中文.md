# ソフトパーティクル（软粒子）的用法

软粒子引擎
作者：ビームマンＰ

软粒子引擎是 MMD 专用的。无法在 MMM 中使用。

1. 另行获取支持软粒子的特效（ビームマン 的作品在发布页面上标注有“SP対応”）
2. 在 MMD 上配置支持软粒子的特效
3. 读取 SoftParticleEngine.x
4. 陷入地面或角色内部的粒子边缘会被模糊掉！
