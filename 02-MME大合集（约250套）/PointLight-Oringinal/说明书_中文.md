# PointLight（点光源）测试用效果（by 極北P）

## ○使用方法

1. 把 "PointLightモデルアクセ(改名配置)用.fx" 改名为目标模型用并配置（所有需要的部分）
2. 添加 PointLight1.x（不要与 .fx 搞错。如果崩溃，请与 3. 的添加顺序对调）
3. 添加 1. 的模型／饰品
4. 通过 MMD 的[背景]-[饰品编辑]把 PointLight1 的绘制顺序改为在模型之前（增加「0番目より～」的编号）
5. 初始状态光量为 0，所以设定颜色
   →把 PointLight1.x 的 Rx,Ry,Rz 看作 RGB 进行颜色设定（例：Rx(R):1,Ry(G):1,Rz(B):1 -> 白(1,1,1)）

※添加时偶尔 MMD 会崩溃（原因不明）。同样，根据环境不同也可能无法使用。

## ○使用方法＋

- 添加虚拟骨骼 → 把虚拟骨骼连接到 PointLight1.x（光源的任意移动）
- 添加 PointLight2.x 及以后（添加后需要变更绘制顺序／颜色设定）

※相同的照明饰品不可追加（MME 的规格）

## ○说明

是简单的点光源（类似物）。只设定颜色和位置也大致能用。

反面，颜色计算公式终究只是单纯的数值加算，所以做得很粗糙（与 Toon 的调整也未设定）

与通常的方向光一样，遮蔽物的另一侧也会成为照明对象，敬请注意。
另外，性质上与自阴影也不兼容。

终究是作为测试用制作的，请把它当作那样的东西使用。

※与景深效果等的共用，请结合 MMD／MME 侧的版本更新状况等加以探讨（把效果内的对象部分移植的话，在现阶段也可以共用）

## ○效果参数解说

### ・饰品

- 表示　　　　　：照明的 ON／OFF
- 位置(X,Y,Z)　 ：照明位置　※移动推荐使用虚拟骨骼
- 旋转(Rx,Ry,Rz)：颜色(RGB)设定（各值 0-1　※范围外也姑且可以输入）
- 尺寸(Si)　　　：照明的强度

※把饰品的「影」设为 ON 时有时会显示不正确的影，所以请保持 OFF（未勾选）
※通过连接的虚拟骨骼的旋转，也姑且可以连续改变颜色（不推荐／在特定角度会得出不正确的计算结果）

### ・模型效果

```
// 个别颜色设定有效 (true:以饰品的旋转值指定颜色／false:固定为白色)
static bool PL_ColorChange = true;
```
→为 false 则强制设定为白色

```
// 衰减系数 = cf.w / ( cf.x + cf.y*d + cf.z*d^2 )
// d:与光源的距离
static float4 PL1_Cf = float4(0,1,0,1);   // x,y,z,w -> cf = 1/d
static float4 PL2_Cf = float4(0,1,0,1);
static float4 PL3_Cf = float4(0,1,0,1);
static float4 PL4_Cf = float4(0,1,0,1);
```
→照明衰减系数的设定

```
// 光源的强度 (设定负数也可以有减色效果)
static float PL1_Power = 1;
static float PL2_Power = 1;
static float PL3_Power = 1;
static float PL4_Power = 1;
```
→照明的强度
设定负数也可以作为减色照明

※负数设定用 (-1,-1,-1) 等旋转值的颜色设定也可以

### ・照明效果

```
// 照明点的显示
static bool Draw = false;
```
→设为 true 则显示照明对象（影像输出时需要非显示化 =false）
