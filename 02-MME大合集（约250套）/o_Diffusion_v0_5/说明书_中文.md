# 改変扩散滤镜 v0.5（o_Diffusion）

- 配布者：おたもん（user/5145841）　mail:o_tamon@okoneya.mail-box.ne.jp

## 前言

本特效是以そぼろ先生制作的扩散滤镜（ディフュージョンフィルタ）为基础，
再现 sayappa 先生的「ディフュージョン：補足」(illust_id=10325142) 的作品。

## 关于对应透明度

本特效基本上是以使用了舞台（stage）或天空穹顶（sky dome）的不透明视频为
使用前提，但只要把 fx 文件开头的「#define NON_TRANSPARENT」后面的数字从
1 改为 0，就可以在保持透明度的状态下输出。

＊　请注意　＊
- 由于规格限制，在透明度有效的状态下背景会变成灰色。
- 不知是不是 MMD 的规格问题，以透明度有效方式输出时，半透明部分不会以正确的颜色显示。
- AVI 输出时请使用 Ut Video Codec RGBA(ULRA) 等支持透明度的编解码器。
- 请仅在以 PNG 保存图像，或以 RGBA 系编解码器输出 AVI 时启用。

## 本特效能做到的事

通过扩散影像中的明亮部分，可以附加室外的空气感，
或让影像整体的质感变得融洽。

与そぼろ先生的扩散滤镜的不同之处在于，通过变更比较（明）的对象，
只扩散明亮的部分，不改变其他部分。

因此虽然失去提升对比度的效果，并且稍微变重了，
但可以把暗部的虚化等变化抑制到最小。

想要提升对比度时，请并用拙作「お手軽トーン補正」等。
在我的环境中，不知为何与お手軽トーン補正并用时处理反而会变轻。

## 使用方法

请在可以使用 MikuMikuEffect 的 MikuMikuDance 中添加附件 o_Diffusion.x。

- Tr：扩散效果的强度。越小特效效果越弱。
　　　根据用途而定，但 0.5～0.75 左右比较好用。配布视频使用的是 Tr=1.0。

- Si：把模糊尺寸变为「所指定的值」倍。（推荐值范围：0～2.0）

- X, Y, Z：指定在最后阶段进行的各色独立式简易明度补正中，X: 红色、Y: 绿、Z: 蓝的亮度要改变多少。
　　　　　　0 为无变化。推荐值范围: -1.0 ～ +1.0。
　　　　　　负值越大越暗，正值越大越亮。

＊ Tips ＊
- 各色指定相同的值，即可变更扩散效果的强弱。
- 把红色(X)提高 0.1 左右（≒把绿(Y)、蓝(Z)调暗），让明亮部分带上红色，可以增添温暖感。
- 把蓝色(Z)提高 0.1 左右（≒把红(X)、绿(Y)调暗），让明亮部分带上蓝色，可以增添清洁感。

## 可以设定的内容

用文本编辑器等编辑 o_Diffusion.fx 的开头部分即可变更效果。

- NON_TRANSPARENT：设为 0 时对背景进行透明处理（初始值），设为 1 时把背景做成白色实底，不透明。

```
float Extent = float( 0.001953125 );
```
　　设定模糊的范围。建议用附件的 Si（尺寸）来调整。

```
float Strength = float( 0.6666667 );
```
　　设定特效的效果强弱。建议用附件的 Tr（不透明度）来调整。

```
float3 ColorFilter = float3( 1.0, 1.0, 1.0 );
```
　　按红、绿、蓝（、α）的顺序设定简易明度补正。建议用附件的 X, Y, Z（位置）来调整。

## 更新履历

v0.5 - 12 / 07 / 07
- 面向 MikuMikuMoving 对参数 UI 部分做了微调。
- 简易色调补正变得连我自己都无法理解的复杂，所以做了简化。

v0.4 - 12 / 01 / 03
- 改为可以从附件操作变更简易明度补正。
　―　只要把 Z 设为 0.1，就能做出有清洁感的白色表现。
- 背景中没有显示模型或附件等时，改为保持透明输出。
　―　按规格透明部分会以灰色显示，但输出的 RGBA 格式视频中会是透明的。

v0.3 - 11 / 08 / 26
- 以そぼろ先生的最新版 Diffusion7 为基础更新了实现部分。
　―　修正了大概是在 v0.1b 时混入的 bug，该 bug 使得明亮效果偏强。

v0.2a - 11 / 06 / 05
- 修正了因拼写错误导致横向模糊未生效的问题。

v0.2 - 11 / 05 / 16
- 更新为对应 MME v0.2 以后的版本
　―　参考了そぼろ先生的最新版 Diffusion6。
　―　与附件的绘制顺序或模型绘制的前后无关，均可使用。

v0.1b - 11 / 03 / 16（未公开）
- 试着整理源代码
　―　改写「模糊」的记述之后，在我的环境中只快了 1fps。
　―　为了易读把「模糊」的记述替换成了循环语句，因此根据环境不同可能变重了。

v0.1a - 11 / 03 / 09
- 移动色调补正的处理位置。
　―　在反复摆弄的过程中它变成了在比较（明）合成之后处理，现改回合成之前。

v0.1 - 11 / 03 / 08（初公开版）
- 变更算法，使其正确处理比较（明）合成。
　―　把原本基于亮度覆盖整个像素的做法，改为对 R,B,G 各元素分别比较、覆盖。
　―　特效作用部分与未作用部分的交界会变得自然，但负载稍重。

v0.02 - 11 / 02 / 19
- 实现上向 sayappa 先生的扩散滤镜算法靠拢。
　―　そぼろ先生版是把已完成屏幕合成的输出与已完成乘算的输出做比较（明）合成，现改为与原始输出进行。
　―　通过这一变更，不再出现比应用前更暗的部分，会像本来的扩散滤镜那样起作用。
　―　因此，改造前的そぼろ先生版那种对比度提升而显得漂亮的效果没有了。

- 试着提高求像素亮度计算式的精度。
　―　把系数的精度从小数点后 2 位提高到小数点后 6 位，感觉亮度精度提升了约 4.8%。
　―　与そぼろ先生版 Ver.4 相比，亮度成分评价的权重稍有不同，所以印象可能会变化。
　　　不过与上面的算法变更相比，还算是停留在误差级别的范围内。

- 大幅减弱默认状态下的特效作用范围与强度。
　―　因为我个人多用默认状态，所以改成直接使用也不会作用过强。

v0.01 - 11 / 01 / 19
- 按そぼろ先生的算法几乎不需要做比较（明）合成，所以删除。
　―　因为已完成乘算的图层与已完成屏幕合成的图层的比较（明）合成结果几乎等同于后者。

- 变更简易色调补正的算法，使补正幅度变化得更平缓。
