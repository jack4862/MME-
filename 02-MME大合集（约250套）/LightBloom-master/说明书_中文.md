# 泛光

###### 　　[English](https://github.com/MikuMikuShaders/LightBloom/blob/master/README.md) &nbsp; [中文文档](https://github.com/MikuMikuShaders/LightBloom/blob/master/README_chs.md)

泛光是一个为了 mikumikudance 编写的图像特效，对过亮的像素执行模糊来添加更多的真实性。

## 蒙板

`蒙板` 用于创建相机残缺来体现镜头的不完美，来给与更多的真实性（`左边`：只有泛光，`右边`：泛光和蒙板的叠加）。更多的了解你可以看 UE 的（[文档](https://docs.unrealengine.com/latest/CHN/Engine/Rendering/PostProcessEffects/Bloom/index.html)）

## 需求

* MikuMikuDance（仅在 926 版 x64 上测试）
* MikuMikuEffect（仅在 037 版 x64 上测试）
* Direct3D 9 With Shader Model 3.0 (ps_3_0)

## 快速开始

* 从 Github 页面中下载并且解压该文件。
* 放置该目录中的 `LightBloom.x` 或者 `LightBloom with DirtMap.x` 到 MMD 的窗口。
* 放置该目录中的 `LightBloomController.pmx` 到 MMD 的窗口。
* 拖拽标签栏中的 `BloomThreshold` 到 0.5

## 影响参数

* `BloomThreshold` - 定义一个阈值用于提取超出一定范围的亮度执行泛光。
* `BloomRadius` - 控制泛光模糊的大小。
* `BloomColorAllHSV` - 修改所有模糊层的亮度和颜色（使用线性的 HSV 的色彩）
* `Bloom1st~5st HSV` - 修改单个模糊层从内到外的亮度和颜色（调节高数值的模糊层，可以使泛光产生的半径更大）
* `DirtColorHSV` - 调教蒙板产生的亮度和颜色

# LightBloom

###### 　　[English](https://github.com/MikuMikuShaders/LightBloom/blob/master/README.md) &nbsp; [中文文档](https://github.com/MikuMikuShaders/LightBloom/blob/master/README_chs.md)

　　Bloom 是用于 MikuMikuDance 的图像效果，它有助于提示物体的相对亮度，或增添美感与氛围感。更多信息可参阅这篇[论文](http://kalogirou.net/2006/05/20/how-to-do-good-bloom-for-hdr-rendering/)。

## Dirt Mask（脏污遮罩）

`Dirt Mask` 是一种用于制造相机瑕疵（左：仅 Bloom，右：Bloom + Dirt Mask）并给出更具冲击力的 HDR 效果的效果。更多信息可参阅 UE4（[文档](https://docs.unrealengine.com/latest/INT/Engine/Rendering/PostProcessEffects/Bloom/index.html)）。

## 需求（Requirements）

* MikuMikuDance（仅在 926 版 x64 上测试过）
* MikuMikuEffect（仅在 037 版 x64 上测试过）
* 支持 Shader Model 3.0（ps_3_0）的 Direct3D 9

## 快速开始（Quickstart）

* 从 github 页面下载 zip 压缩包。
* 解压压缩包。
* 把 `LightBloom.x` 或 `LightBloom with DirtMap.x` 拖放到 MMD 窗口中。
* 把 `LightBloomController.pmx` 拖放到 MMD 窗口中。
* 在表情（morph）面板中把 `BloomThreshold` 拖到 0.5。

## 效果参数（Effect Params）

* `BloomThreshold`（泛光阈值）— 提取亮度高于该水平的像素。
* `BloomRadius`（泛光半径）— 以屏幕宽度百分比控制蒙雾（veiling）效果的尺寸。
* `BloomColorAllHSV`（整体泛光颜色）— 缩放整个泛光效果的亮度和颜色（线性色彩空间，使用 HSV 颜色）
* `Bloom1st~5st HSV`（第 1～5 层泛光颜色）— 修改各层泛光的亮度和颜色；如果需要更大的泛光，请使用更高的层
* `DirtColorHSV`（脏污遮罩颜色）— 缩放整个脏污遮罩的亮度和颜色
