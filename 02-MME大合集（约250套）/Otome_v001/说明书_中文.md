# 乙女滤镜（乙女フィルター）ver0.0.1

水玉（圆点）与闪闪发光——模仿动画演出中常见的那种少女风效果的 Effect。姑且是面向剧情演出的。
可能不适合像大幅甩动相机那样的用法……

准备了两种：针对特定物体周围施加的（Otome.fx），以及针对整个画面的（Screen_Otome.fx：相机固定）。

本效果由舞力介入P氏的 laughing_man.fx、FireParticleSystem.fx 修改制作而成。

## Otome.fx 使用方法

1. 请将 Otome.x 载入 MMD。
2. 绘制顺序请置于目标模型之后。
3. 根据需要修改 fx 文件开头的参数。
4. 用 MMD 通常的配件（アクセサリ）参数设置位置、大小、透明度。

## Screen_Otome.fx 使用方法

1. 请将 Screen_Otome.x 载入 MMD。
2. 绘制顺序请尽量靠后。
3. 根据需要修改 fx 文件开头的参数。
4. MMD 的配件参数只能使用 Tr（透明度）。

随附的 Back.bmp 请用作背景 BMP，或配合 ScreenTex.fx 等使用。
