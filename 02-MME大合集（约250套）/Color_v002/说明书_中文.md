# Color.fx ver0.0.2 / Color_Flat.fx ver0.0.2

对模型进行颜色变更。全部参数都可通过控制模型的表情设定来变更。
Color.fx 可以进行单色填充、灰度、棕褐色（Sepia）、正负片转换。
Color_Flat.fx 是完全平涂，把模型涂成单色。会成为剪影描画。
本效果是改造舞力介入P 氏的 full.fx 制作而成。

## 使用方法
1. 给 PMD 或者附件套用 Color.fx 或 Color_Flat.fx。
   - 使用 GUI 时：从「MMEffect」→「效果分配」的主标签页中，给想套用的对象分配 Color.fx。
   - 使用文件名设定的情况：把 XXXXX.pmd 改名为 XXXXX[Color.fx].pmd，或者把 Color.fx 改名为 XXXXX.fx 后载入。
2. 把 ColorControl.pmd 载入 MMD。
3. 在模型绘制顺序中，把 ColorControl.pmd 放在所套用对象的紧前面。
4. 用 ColorControl.pmd 的表情滑块各项可进行以下控制。
   - 目（眼睛）：赤,緑,青 → 指定填充用的 RGB 颜色。
   - ﾘｯﾌﾟ（嘴唇）：色相,彩度,照度 → 指定填充用的 HSV 颜色。
   - まゆ（眉毛）：ブレンド（混合） → 决定 RGB 色与 HSV 色的影响度，从而决定填充色。
     エッジも（边缘也） → 让边缘也成为颜色变换的对象。
   - その他（其他）：α値 → 把填充色与模型的颜色进行线性合成。
     グレー,セピア,ネガ → 分别进行灰度、棕褐色、正负片转换。（Color_Flat.fx 中无法使用）
