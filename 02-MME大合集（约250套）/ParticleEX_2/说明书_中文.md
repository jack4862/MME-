# ParticleEX_2

- 不知为何会大量喷出的粒子 -

## 概要

是带重力的粒子。

## 使用方法

载入 MMD 后使用。
基本上参数的操作是通过用记事本等直接编辑 fx 文件来进行。

## -主要编辑对象参数-

```
// パーティクル数(0～15000)  ← 粒子数(0～15000)
#define PARTICLE_COUNT 15000
```
这是粒子的数量。

```
//生成制限速度  ← 生成限制速度
float CutSpeed = 0;
```
这是生成（放出）的限制速度。为 0 时始终放出。

```
//重力
float3 Grv = float3(0,-30,0);
```
是不考虑模型角度的加速度。
用于重力、风等。

```
//推進力  ← 推进力
float MoveSpd = 0;
```
是考虑模型角度的加速度。
朝模型的 Z 方向，以指定的速度喷出粒子。

```
//減衰力(空気抵抗）  ← 衰减力(空气阻力)
float Air = 0.5;
```
是推进力（MoveSpd）的衰减力。
