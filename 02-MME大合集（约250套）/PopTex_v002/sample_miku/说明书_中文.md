# PopTex 贴图数据（第6回MMD杯使用）

这是第6回MMD杯中使用过的 PopTex 的映射（マッピング）数据。

请把 PopTex_Hi.fx 开头参数中的以下部分进行修改。

```
#define TexFile     "im896661_miku.bmp"    // 画面に貼り付けるテクスチャファイル名（贴到画面上的纹理文件名）
#define HeightFile  "im896661_mikuH.png"   // 高さマップテクスチャファイル名（高度贴图纹理文件名）
#define ElasticFile "im896661_mikuS.png"   // 軟度マップテクスチャファイル名（软度贴图纹理文件名）
#define MappingType  1  // マッピングに使う値 0:グレースケール割り当て,1:α値を割り当て（映射所用的值 0:分配灰度，1:分配 α 值）
```
