# PopTex.fx ver0.0.2

根据贴图的映射信息把贴图图像隆起，再用着色器内的物理计算让它 Q 弹 Q 弹地动。
本效果是改造舞力介入P 氏的 full.fx 制作而成。

准备了进行物理运算的顶点数不同的两种。
- **PopTex_Lo.fx**：64*64 顶点，形状会变粗但运行轻快
- **PopTex_Hi.fx**：256*256 顶点，能做得很精细但运行沉重

## ・使用方法
1. 在 MMD 中载入 PopTex_Hi.x 或 PopTex_Lo.x。
2. 在 MMD 中载入 PopTexControl.pmd。
3. 酌情修改 PopTex_Hi.fx 或 PopTex_Lo.fx 开头的参数。
4. 把 PopTex_Hi.x、PopTex_Lo.x 挂到适当的骨骼上。
5. 用 PopTexControl.pmd 的表情滑块进行参数调整，再移动挂上的骨骼，就会 Q 弹 Q 弹地动。

## ・注意点
载入模型时或变更 FX 参数时会被施加急剧的加速度，有时会无法正常显示。
这种情况下，播放第 0 帧即可让数据初始化并重新显示。

※ 要在 MME 中使用本 FX 文件，必须使用支持 VTF（Vertex Texture Fetch）的 SM3.0 显卡。
