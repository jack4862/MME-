# Footmark ver0.0.1

把它挂在脚踝骨骼上，就能随着模型的动作留下脚印。

## Footmark.fx 使用方法

1. 将「足跡右[Footmark.fx].x」（脚印·右）和「足跡左[Footmark.fx].x」（脚印·左）载入 MMD。
2. 把绘制顺序设为紧接在地面附件之后。
3. 在目标 PMD 模型中，把「足跡右[Footmark.fx].x」挂到右脚踝骨骼上，把「足跡左[Footmark.fx].x」挂到左脚踝骨骼上。
4. 配合模型调整脚印的位置和大小。默认值是按标准初音未来 v1.3 调整的。
   比起用 MMD 的附件参数调整，直接改 fx 文件开头的参数可能更好调。
   替换贴图文件，还可以表现出其他形状的脚印。
5. 用 MMD 的附件参数 Tr 可以改变脚印的透明度。
6. 播放第 0 帧即可重置（从播放模式切到编辑模式时同样如此）。

## 注意点

如果不配合模型和动作，把 fx 文件开头的脚印检测相关参数调整得当，就会出现脚印不显示、重复显示等各种问题。

※ 要在 MME 中使用这个 FX 文件，必须有一块支持 VTF（Vertex Texture Fetch）的 SM3.0 显卡。
