# RainLite Readme

MikuMikuEffect 用 降雨特效 Ver.1.1

制作：そぼろ

对 TexSnowLite 进行自我改造，做成了让雨降下的特效。
大体上遵循 TexSnow，但省略了若干参数。

把 Tr 值设为 0.3 左右会与背景融合，感觉不错……也许。

参考了 ビームマンP 的 LineBillboard.fx。

## 更新履历

Ver.1.1
- 重新审视了线广告牌的方式，变为从任何角度看都不会消失。

## 通常的使用方法

- 在 MMD 中读取 RainLite.x
- 将绘制顺序设为最后

## 注意事项

- 由于使用了 Alpha 混合，请设置为最后被绘制。
- 需要支持顶点着色器 3.0 及 VTF 的显卡。
