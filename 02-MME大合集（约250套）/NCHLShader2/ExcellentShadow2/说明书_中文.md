# 超高画质自阴影效果 ExcellentShadow Ver.2.4（ExcellentShadow2）

> 本文件是针对 NCHLShader2 做了预效果化（プリエフェクト化）的版本。
> 请注意：对未应用随附着色器的对象不会产生效果。
> 以下为そぼろ（Sovoro）原文照录。

制作：そぼろ（Sovoro）

这是面向「为了获得漂亮的阴影，无论怎么折磨显卡都无所谓」的用户的高画质阴影效果。

它将 MMD 标准的透视阴影贴图、近景用固定阴影贴图、远景用广域固定阴影贴图这三张动态混合，再通过后处理（post 处理）加入模糊，从而实现了前所未有的出色阴影。

## 使用环境

- MikuMikuEffect Ver.0.27 以上
- MikuMikuMoving Ver.1.1.8.2 以上
- 支持 SM3.0 以及浮点纹理 mipmap 的显卡
- 推荐 VRAM：1GB 以上

## 使用方法

1. 读入 ExcellentShadow.x。此时不会发生任何事情。
2. 对所有的模型、附件（アクセサリ）应用 full_ES.fx。
3. 启用模型、附件的自阴影。

ExcellentShadow.x 的位置会成为阴影贴图的中心。
请让 ExcellentShadow.x 配置在想要投影的对象附近。

阴影贴图的大小由 ExcellentShadow.x 的 Si 决定。
把阴影贴图调大，可以让自阴影出现在更广的范围内，但相应地细小的阴影会被压溃，边缘也会变脏。
请在远景、近景之间妥善调整。
即使在默认状态下，也能覆盖ゲキド街（激怒街）的一半左右。

本效果也会利用 MMD 标准的阴影，因此对关闭效果时的阴影也多加留意，能得到更好的结果。
使用 Ctrl+G 扩大阴影缓冲区也有效果。

通过 ExcellentShadow.x 的 Tr 可以调整阴影的浓度。
把 Tr 调小，阴影就会变浓。

本效果在默认状态下对 PMD 模型只会较弱地应用。
（这是为了防止人物模型的阴影变得过浓）
想要也对 PMD 模型应用时，请编辑 full_ES.fx，把 PMD_SHADOWPOWER 的值调大。

通过附件的 X 旋转可以增减阴影的模糊强度。
范围为 -100～100。
骨骼挂载的影响会被忽略。

## 材质 Morph（材質モーフ）对应

在 MMD＋MME 中，对于使用了材质 Morph 的 PMX 模型，请用 full_ES_pmx.fx 代替 full_ES.fx 来应用。

## 轻量化、详细设置

### 画质等级（クオリティレベル）

打开 ExcellentShadowCommonSystem.fx，通过 EXSHADOW_QUALITY 的数值可以设置画质等级。
初始值被设定为中等画质。

如果太重以致无法正常运行时，请试着降低该值。

### MMD 标准阴影的使用／不使用

打开 ExcellentShadowCommonSystem.fx，改变 MMDSHADOW_USING 的值，即可设置是否利用 MMD 标准的阴影。
不使用时，由于 ExcellentShadow 内部的阴影没有做透视化处理，拉近（アップ）时的阴影容易出现锯齿，但阴影的轮廓不会「蠕动（うにうに）」般地抖动。

### 多重采样阴影（マルチサンプリングシャドウ）

打开 ExcellentShadowCommonSystem.fx，改变 MULTISAMPLING 的值即可启用多重采样阴影功能。
内容上大致与ビームマンP（BeamManP）的简易软阴影相同。
再对其进一步模糊，就能得到锯齿更少的阴影。
会略微变重。

### 应用阴影的 Alpha 值阈值

本效果中，低于一定 Alpha 值的对象在阴影处理中会被忽略。
打开 ExcellentShadowCommonSystem.fx，改变 ShadowAlphaThreshold 的值即可更改该阈值。

## MikuMikuMoving 对应

自 Ver.2.3 起，已支持 MikuMikuMoving。
使用方法是：读入 ExcellentShadow.fx，并对模型应用 full_ES_mmm.fxm。
不过，存在以下限制。

- MMDSHADOW_USING 会被强制关闭，只使用 ExcellentShadow 内部的阴影贴图。
- 不支持 MMM 的多重光源。第 2 光源以后不会产生阴影。
  基本上请以单光源使用。
- 在 MMM 中无法对模型逐个设置是否投影。
  所有对象都会被施加自阴影。
  作为例外，Alpha 值 0.98 的材质不投影这一 MMD 规格，已在 ExcellentShadow 内部重现。

## SSAO 联动

读入随附的 ExShadowSSAO 效果后，SSAO 信息会被传递给 full_ES 着色器一侧，从而进行非后处理的 SSAO 绘制。
虽然差别不易分辨，但由于能够考虑材质与阴影的信息，因此感觉上会稍微自然一些。
举例来说，被照明的部分其 SSAO 效果会变弱。

ExShadowSSAO 的内容与 SvSSAO 几乎相同，但会把阴暗度贴图（陰度マップ）传递给 ExcellentShadow，因此无法单独使用。

## 着色器效果的 ExcellentShadow 对应

基于 full.fx 的着色器效果，可以比较简单地使其对应 ExcellentShadow。

如果效果的内容相对 full.fx 有大幅改动，用这种方法可能无法成功。
此外，本方法无法适用于顶点变化系、增殖系的效果。

- 首先，把目标效果另存为别的名字。
  在末尾加上「_ES」之类会更容易辨认。

- 用编辑器打开效果，参考 full_ES.fx，把以下指示的 4 处复制粘贴添加进去。

```
/////////////////////////////////////////////////////////////////////////////////////////
/////////////////////////////////////////////////////////////////////////////////////////
// ■ ExcellentShadowシステム　ここから↓

XXXX

// ■ ExcellentShadowシステム　ここまで↑
/////////////////////////////////////////////////////////////////////////////////////////
/////////////////////////////////////////////////////////////////////////////////////////
```

此外，用这种方法改造过的效果，在未使用 ExcellentShadow 时，可以显示 MMD 通常的阴影。

## 注意事项

- 与 AbsoluteShadow 没有兼容性。
- 由于机制上的原因，半透明对象的阴影会略显奇怪。
