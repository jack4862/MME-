キーフレーム間をスプラインで補間するツール
まろやかMMD　V0.90　2012/5/14

【目的】
このツールは、主に手打ちで作ったMMDモーションの
キーフレーム間を、位置、回転ともにスプラインにて補間するツールです。

【利用するには】
本プログラムはVisual C＃ .NET 2010で作られています。利用のためには予め皆様の
パソコンに,net framework 4.0以降が組み込まれている必要があると思いますが、
詳細は私も良く知りません。動かなかったらごめんなさい。

【利用法】
EXEを立ち上げますと、ウィンドウが表示されます。ここにモーションファイル(.vmd)を
ドラッグ、ドロップしてください。「ファイルを開く」ボタンから
ダイアログで設定することもできます。
その後、実行ボタンを押すと.「出力ファイル名」で指定した場所、ファイル名で
変換後のファイルが出力されます。

【入力ファイルについて】
入力ファイルは、最大200ボーン、10000フレームまでを受け付けますが、
出力ファイルは全点にキーフレームを持ちますので、あんまり巨大なファイルを入れると
読み込み時に死にそうになりますのでやめましょう。
まずは１ボーンだけとか、100フレームだけとかでおためしください。
また、現在あるキーフレームは残しますので、既に全点にキーフレームが
打たれているファイル（kinectとか）には機能しません。
