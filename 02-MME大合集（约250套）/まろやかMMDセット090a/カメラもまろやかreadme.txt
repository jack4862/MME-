キーフレーム間をスプラインで補間するツール　カメラ版
カメラもまろやかMMD　V0.90　2012/5/14

【目的】
このツールは、主に手打ちで作ったMMDカメラモーションの
キーフレーム間を、位置、回転ともにスプラインにて補間するツールです。

【利用するには】
本プログラムはVisual C＃ .NET 2010で作られています。利用のためには予め皆様の
パソコンに,net framework 4.0以降が組み込まれている必要があると思いますが、
詳細は私も良く知りません。動かなかったらごめんなさい。

【簡単な利用法】
EXEを立ち上げますと、ウィンドウが表示されます。ここにカメラモーションファイル(.vmd)を
ドラッグ、ドロップしてください。もしくは「ファイルを開く」ボタンから
ダイアログで選んでもOKです。
その後、実行ボタンを押すと、「出力ファイル名」に示された名前で
変換後のファイルが出力されます。

【入力ファイルについて】
入力ファイルは、10000フレームまでを受け付けます。
現在あるキーフレームは残しますので、既に全点にキーフレームが
打たれているファイルには機能しません。
