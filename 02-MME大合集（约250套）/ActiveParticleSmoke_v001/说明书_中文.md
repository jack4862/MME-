# ActiveParticleSmoke.fx ver0.0.1 / ActiveParticleSmokeHG.fx ver0.0.1

烟会随物体的移动拖出尾巴。可以做出类似纳豆导弹的效果。
由于放出的粒子数量与放出位置会根据物体的移动量进行调整，因此即使快速移动物体，
烟的尾巴也不容易中断。
准备了通常版（ActiveParticleSmoke.fx：粒子数 4096）与高级版
（ActiveParticleSmokeHG.fx：粒子数 16384）两种。这是应用 ActiveParticle.fx 制作的。

## ActiveParticleSmoke.fx、ActiveParticleSmokeHG.fx 使用方法
1. 请把 ActiveParticleSmoke.x 或 ActiveParticleSmokeHG.x 载入 MMD。
2. 绘制顺序请尽量设定在后面。
3. 把 ActiveParticleSmoke.x、ActiveParticleSmokeHG.x 挂到适当的骨骼上并移动，就会在移动过的轨迹上描画出烟的尾巴。
4. 请根据需要修改 fx 文件开头的参数。
5. 用 MMD 的附件参数可以进行以下变更。
   - Si：粒子的放出量
   - Tr：粒子的透过度

## 注意点
一次描画的粒子数最多为 4096（HG 版为 16384）。若出现要产生更多粒子的状况，
则在正在发生的粒子消失之前，不会再放出新的粒子。

※ 要在 MME 中使用本 FX 文件，必须使用支持 VTF（Vertex Texture Fetch）的 SM3.0 显卡。
