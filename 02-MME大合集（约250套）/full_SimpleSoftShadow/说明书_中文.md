# full_SimpleSoftShadow（简易软阴影）

## 使用方法

在「效果分配」中把 full_SimpleSoftShadow.fx 分配给目标模型。

想要更改模糊程度时，请改 fx 内上部的

```
float SoftShadowParam = 0.5;
```

这里。调大则模糊得一片糊涂，调小则变得锐利（为 0 时与 MMD 默认大致相同）。

在 MMD 侧操作中提高了阴影贴图分辨率（CTRL+G）时，
把

```
#define SHADOWMAP_SIZE 1024
```

这里的 1024 改成 4096 就刚好合适，也许。


以上就是全部。简单！
