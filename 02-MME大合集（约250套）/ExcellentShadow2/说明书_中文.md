# 超高品质自阴影效果　Ver.2.0

制作：そぼろ

这是为「只要能获得漂亮的阴影，怎么折磨显卡都无所谓」的人准备的高品质阴影效果。

把 MMD 标准的透视阴影贴图、近景用固定阴影贴图、远景用广域固定阴影贴图这 3 张动态混合，
同时通过后处理进行模糊，实现了前所未有的卓越阴影。

## ■ 使用环境

MME0.27 以后

支持 SM3.0 及浮点纹理 mipmap 的显卡
推荐 VRAM：1GB 以上

## ■ 使用方法

１．读取 ExcellentShadow.x。在这个阶段什么都不会发生。
２．对所有模型・配件应用 full_ES.fx。
３．启用模型・配件的自阴影。

ExcellentShadow.x 的位置会成为阴影贴图的中心。
请让 ExcellentShadow.x 配置在想要拍摄的物体附近。

阴影贴图的大小由 ExcellentShadow.x 的 Si（强度）决定。
把阴影贴图调大可以让更广的范围产生自阴影，但相应地细微的阴影会被压溃，边缘也会变脏。
请在远景、近景中好好调整。
默认状态下也能覆盖ゲキド街（激怒街）的一半左右。

本效果也会利用 MMD 标准的阴影，因此对关掉效果时的阴影也留心的话，可以得到更好的结果。
Ctrl+G 的阴影缓冲扩大也有效果。

可以用 ExcellentShadow.x 的 Tr 调整阴影的浓度。
Tr 调小则阴影变浓。

该效果在默认状态下对 PMD 模型只会较弱地应用。
（这是为了防止人物模型的阴影变得过浓）
想也应用到 PMD 模型时，请编辑 full_ES.fx，把 PMD_SHADOWPOWER 的值调大。

可以通过配件的 X 旋转增减阴影的模糊强度。
范围为 -100～100。
骨骼安装的影响会被忽略。

## ■ 轻量化・详细设置

- 品质等级

打开 ExcellentShadowCommonSystem.fx，
可以通过 EXSHADOW_QUALITY 的数值设置品质等级。
初始值设定为中等品质。

如果太重而无法正常运行时，请试着把值调低。

- MMD 标准阴影的使用／不使用

打开 ExcellentShadowCommonSystem.fx，
通过修改 MMDSHADOW_USING 的值，可以设置是否利用 MMD 标准的阴影。
不使用的情况下，由于 ExcellentShadow 内部的阴影没有被透视化，仰拍时的阴影容易出锯齿，但阴影的轮廓不会再「蠕蠕」地动。

- 多重采样阴影

打开 ExcellentShadowCommonSystem.fx，
通过修改 MULTISAMPLING 的值，启用多重采样阴影功能。
内容上大致与ビームマンP 的简易软阴影相同。
再把它进一步模糊，就能得到锯齿更少的阴影。
会稍微变重。

## ■ SSAO 联动

读取同捆的 ExShadowSSAO 效果后，
SSAO 信息会被传递给 full_ES 着色器一侧，
进行非后处理的 SSAO 描画。
虽然差别难以分辨，但由于能够考虑材质与阴影的信息，
感觉会稍微自然一些。
举例来说，受到照明照射的部分其 SSAO 效果会变弱。

ExShadowSSAO 的内容与 SvSSAO 几乎相同，但已设定为无法单独使用。

## ■ 着色器效果的 ExcellentShadow 对应

基于 full.fx 的着色器效果，
可以比较简单地对应 ExcellentShadow。

如果效果的内容相对 full.fx 有大幅改动，
用这个方法有时会不顺利。
另外，无法适用于顶点变化系、增殖系的效果。

- 首先，把目标效果另存为别的名字。
  在末尾加上 "_ES" 之类会比较容易分辨。

- 用编辑器打开效果，一边参考 full_ES.fx，
  一边按下面指示的 4 处位置复制粘贴并追加。

> /////////////////////////////////////////////////////////////////////////////////////////
> /////////////////////////////////////////////////////////////////////////////////////////
> // ■ ExcellentShadowシステム　ここから↓
>
> XXXX
>
> // ■ ExcellentShadowシステム　ここまで↑
> /////////////////////////////////////////////////////////////////////////////////////////
> /////////////////////////////////////////////////////////////////////////////////////////

（注：上述注释意为「■ ExcellentShadow 系统　从这里开始↓」／「■ ExcellentShadow 系统　到这里为止↑」）

另外，用这种方法改造过的效果，在不使用 ExcellentShadow 时，
可以显示 MMD 通常的阴影。

## ■ 注意事项

- 与 AbsoluteShadow 没有兼容性。
- 在机制上，半透明物体的阴影有些可疑。
- 不支持 MMM。
