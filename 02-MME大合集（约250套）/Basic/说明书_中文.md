# Basic

这是与 MMD 标准着色器几乎相同动作的特效文件。

简易版为 basic.fx，完整版为 full.fx。

basic.fx 不支持球面贴图（スフィアマップ），无法描画。
另外，轮廓、阴影以及自阴影用 Z 值绘制（セルフシャドウ用Z値プロット）会使用 MMD 标准着色器。

## 使用上的注意
- 不支持 MMD ver7.08 中追加的轮廓颜色变更（エッジ色変更）。
