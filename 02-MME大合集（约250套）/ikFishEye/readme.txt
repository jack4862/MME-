魚眼レンズ
ゆがみ強度をコントロールできる魚眼レンズエフェクト。

■ 使用方法 (アクセサリ版)

1. ikFisheye.xを入れる。
2. アクセサリのXでゆがみ率の調整。-10～+40程度。
3. アクセサリのZでスケーリング。

あとは .fxの先頭で設定を変更できます。


■ 使用方法 (モーフ版)

1. ikFisheyeC.x と fisheyeCtrl.pmx を入れる。
2. fisheyeCtrl のモーフで各種制御。
3. fisheyeCtrl の Scaling ボーンで画面のスケーリング。


□ 共通：

デフォルト状態では、カメラの視野角が35度のときゆがみなし。
35度未満のとき糸巻歪曲 (画面中央に寄る)
35度以上のとき樽型歪曲 (画面端に膨らむ)


■ Checker

checker.x はゆがみチェック用にチェック模様を出すだけのエフェクトです。
アクセサリのTrで不透明度を変更できます。
