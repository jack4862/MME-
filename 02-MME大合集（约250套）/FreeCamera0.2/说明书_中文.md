# 视点变更效果 ver0.2

- 对应：MikuMikuEffect ver0.2x 用
- 制作者：kion
- 更新日：2010.12.29

这是在 MikuMikuEffect ver0.2x 中可使用的效果文件（*.fx）。
已在 MMDver7.25 + MMEver0.23 中确认可运行。

这是变更视点的效果。
带平滑化功能。

## ●关于 MikuMikuEffect

这是由 舞力介入P 制作的、让 MikuMikuDance 可以使用效果文件的工具。
详情请看 → http://www.nicovideo.jp/watch/sm12149815

## ●文件内容

- readme.txt　本文件
- CameraFull.x　／用于读取 CameraFull.fx 的配件
- CameraFull.fx　／效果文件本体
- CameraSmooth.x　／用于读取 CameraSmooth.fx 的配件
- CameraSmooth.fx　／计算视点的矩阵，以及平滑化
- Camera1.fx　／变更视点来描画物体
- Cam1Pos.x　／设定相机位置等的配件
- non.fx　　／用于降低 GPU 负载的参照

由 Camera1.fx 把物体变更到别的视点进行描画。
如果更改 Cam1Pos.x 的名字，CameraSmooth.fx 与 Camera1.fx 将无法取得信息，因此请不要更改。

## ●机制

用 CameraSmooth.fx 计算视图矩阵，进行平滑化处理后写入纹理。
在 Camera1.fx 内读取上面的纹理，变更视点进行描画。
CameraFull.fx 使用 Camera1.fx 把描画到离屏缓冲的内容输出。
由于平滑化采用取平均值的方法，所以会稍有延迟。

## ●用法

读取以下文件。
- CameraFull.x
- CameraSmooth.x
- Cam1Pos.x

Cam1Pos.x 即为相机位置，蓝色面所朝的方向即相机的视线方向。
在 Cam1Pos.x 的尺寸 (Si) 中以度数指定视角。初始状态为 1，所以请适当改为 45 或 60 等。

例：用 鏡音レン.pmd（镜音连）做 FPS 视点
- Cam1Pos.x 设置在 頭（头部）骨骼
- (x,y,z)=(0,2,-2)　(Rx,Ry,Rz)=(0,180,0)　Si=90

※ 为了初始化视点数据，请务必按下［播放按钮］至少 1 次。

## ●使用 Kinect 时把视点设为 FPS 视点或角色后方视点时的设置

（MMDver7.24 的情况）
请把 Data/SamplesConfig.xml 的第 26 行改写为 <Mirror on="false" />。
（MMDver7.25 以后）
从菜单的「ﾓｰｼｮﾝｷｬﾌﾟﾁｬ」（Motion Capture）→ 取消勾选「左右反転」（左右翻转）。

## ●参数

用 CameraSmooth.fx 的以下参数可以设置平滑化。

    // 閾値（阈值）
    float LimitPos = 0.01;
    float LimitQuat = 0.02;

只要不超过 LimitPos、LimitQuat 指定的值就不会移动。
LimitPos 是位置的调整值，LimitQuat 是倾斜的调整值。
主要是为了抑制细小振动的设置值。调大可以抑制振动。
另一方面，调大后动作也会变得卡顿，所以应尽量取小值。

    // 平滑化量(1<)
    #define POS_SMOOTH	6
    #define QUAT_SMOOTH	6

保存包括当前帧在内的过去帧的视点信息，计算平均值进行平滑化。
值越大越平滑，但会被过去的信息拖拽，因此延迟会变大。

    // 平滑化開始時間（平滑化开始时间）
    #define WAIT_TIME	0.1

从按下播放按钮起进行初始化的时间（秒）。
基本上不需要更改。FPS 极端小（1 以下）时调大也许比较好。

- 想让平滑化无效时
  如下更改值：

      // 閾値（阈值）
      float LimitPos = 0.0;
      float LimitQuat = 0.0;
      // 平滑化量(1<)
      #define POS_SMOOTH	1
      #define QUAT_SMOOTH	1

  即使设为无效，也存在平滑化的多余处理，因此使用 FreeCamera0.1x 更好。

## ●注意点・问题点

由于没有进行边缘固定处理，与 MMD 原本的相机位置相差很大时，
边缘会变得过粗、或变得过细。
请把相机位置放在相近的位置，或者把边缘设为 OFF。
不支持自阴影。

## ●限制

由于使用 Camera1.fx 来描画模型，在机制上无法使用其他的效果文件。
Clone.fx、Glass.fx、センシティブトゥーン（敏感卡通）等不能使用。
只能改造 Camera1.fx。

## ●降低 GPU 负载

启用 CameraFull.x 时不会使用对 MainRenderTarget 的描画结果。
对 MainRenderTarget 使用 non.fx 即可省去描画。使用 non.fx 会稍微变轻。
请从 MME 菜单「エフェクト割り当て」（效果分配）给各描画模型应用 non.fx。
