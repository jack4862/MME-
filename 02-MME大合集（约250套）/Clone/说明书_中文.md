# MikuMikuEffect 用 オブジェクト複製エフェクト（物体复制效果）Ver.3.1

制作：そぼろ

这是复制物体的效果。

以 full.fx 为基础。
用 count 控制复制数量，用 ClonePos 函数操作配置。

虽然已尽量考虑到方便修改，
但由于需要编辑函数，因此需要一定程度的编程知识。

虽然原则上也可以套用到附件上，但移动量会变成 10 倍，
旋转时的处理也会变得麻烦。
倒不如说，更推荐做成 PMD 后再套用。

## ●异向性过滤功能

从 Ver.3.0 起支持异向性过滤。
默认为无效，但把 MIPMAPTEX_SIZE 设为 512 或 1024 之类的值
即会生效，贴图的缩小会变得漂亮。

## ●通常的使用方法
- MME0.1：
  复制到与想套用的模型相同的文件夹，并把模型的文件名改成
  初音ミクVer2[Clone.fx].pmd　这样。

- MME0.2 以降：
  从 MME 的操作面板中，给对象模型分配 Clone.fx。
