# FXAA

FXAA 是一个用于 MikuMikuDance 的后处理（post-process），它是 GPU 上非常快速的实现，该方法能解决大部分低频抗锯齿（low-freq AA）的成因，但无法完全防止时域锯齿（temporal aliasing）。

## 需求

* MikuMikuDance（仅在 926 版 x64 上测试）
* MikuMikuEffect（仅在 037 版 x64 上测试）
* Direct3D 9，支持 Shader Model 3.0（ps_3_0）

## 快速开始

* 从 github 页面下载 zip 压缩包。
* 解压该压缩包。
* 将 `FXAA.x` 拖放到 MMD 窗口（没有用于改变效果的控制器）。
